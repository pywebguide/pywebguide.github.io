1. Greeting

Level: Easy

Write a function greet(name) that returns the string Hello, Name!. Extra spaces around the name must be removed. If the name is empty, return Hello, guest!.

  1. Hint 1. The easiest way to join text and a variable is an f-string: f"Hello, {name}!".
  2. Hint 2. name.strip() removes the spaces at both ends.
  3. Hint 3. An empty string counts as false in a condition: name or 'guest' gives “guest” when the name is empty.
Show solution
def greet(name):
    name = name.strip()
    return f"Hello, {name or 'guest'}!"

2. Word count

Level: Easy

Write count_words(text): return a dictionary where the key is a word in lower case and the value is how many times it appears.

  1. Hint 1. Start with an empty dictionary counts = {} and loop over the words.
  2. Hint 2. text.lower().split() lowercases the text and splits it on any spaces and line breaks.
  3. Hint 3. counts.get(word, 0) + 1 increases the counter even when the word is not in the dictionary yet.
Show solution
def count_words(text):
    counts = {}
    for word in text.lower().split():
        counts[word] = counts.get(word, 0) + 1
    return counts

3. Strong password

Level: Easy

Write is_strong(password). A password is strong if it has at least 8 characters, at least one digit and at least one letter. Return True or False.

  1. Hint 1. len(password) gives the length of the string.
  2. Hint 2. any(ch.isdigit() for ch in password) returns True if the password contains a digit.
  3. Hint 3. For letters there is ch.isalpha(). Join the three conditions with and.
Show solution
def is_strong(password):
    has_digit = any(ch.isdigit() for ch in password)
    has_letter = any(ch.isalpha() for ch in password)
    return len(password) >= 8 and has_digit and has_letter

4. An address from a title

Level: Medium

Websites turn an article title into part of the address: My First Site → my-first-site. Write slugify(title) for Latin letters: keep letters and digits in lower case and replace everything else with a hyphen. Merge several hyphens in a row into one and remove hyphens at the ends.

  1. Hint 1. Go through the characters of title.lower(): a letter or digit (ch.isalnum()) stays, anything else becomes "-".
  2. Hint 2. "-".join(...) over the non-empty pieces after split("-") joins them without extra hyphens.
  3. Hint 3. With the re module: re.sub(r"[^a-z0-9]+", "-", text).strip("-").
Show solution
def slugify(title):
    chars = [ch if ch.isalnum() else "-" for ch in title.lower()]
    parts = "".join(chars).split("-")
    return "-".join(part for part in parts if part)

8. Longest word

Level: Medium

Write longest(words): return the longest word in the list. If there are several, return the first one. For an empty list return an empty string.

  1. Hint 1. Keep the best word in a variable best = "" and compare lengths with len().
  2. Hint 2. To keep the first word when lengths are equal, compare strictly: len(word) > len(best).
Show solution
def longest(words):
    best = ""
    for word in words:
        if len(word) > len(best):
            best = word
    return best

9. No duplicates

Level: Medium

  1. Hint 1. You can check whether an item is already in the list with item not in result.
  2. Hint 2. set() removes duplicates but may change the order, so a loop is needed here.

def unique(items):

    for item in items:
        if item not in result:

    return result

11. Parsing an address

Level: Medium

Write parse_query(query). It turns the string a=1&b=2 into the dictionary {"a": "1", "b": "2"}. Skip parts without an = sign. A value may contain =.

  1. Hint 1. First split the string into pairs: query.split("&").
  2. Hint 2. Skip a pair without = with the check if "=" in part.

12. A simple router

Level: Medium

Finish handle(method, path). It looks up a handler in the ROUTES dictionary and returns a “code, text” pair. If there is no such address, return (404, "Not Found"). If the address exists but the method does not match, return (405, "Method Not Allowed").

  1. Hint 1. Check in order: first whether the address exists, then whether the method does.
  2. Hint 2. path not in ROUTES means there is no such address: that is 404.
  3. Hint 3. The address's methods are in ROUTES[path]. If the method is not there, it is 405; otherwise return 200 and the text.
Show solution
ROUTES = {
    "/": {"GET": "Home"},
    "/tasks": {"GET": "Task list", "POST": "Task created"},
}

def handle(method, path):
    if path not in ROUTES:
        return 404, "Not Found"
    if method not in ROUTES[path]:
        return 405, "Method Not Allowed"
    return 200, ROUTES[path][method]

13. Checking form data

Level: Hard

Write validate_user(data). The function takes a dictionary and returns a list of errors. The name field is required, and age must be a whole number from 1 to 120. Error texts: "name" and "age". If everything is correct, return an empty list.

  1. Hint 1. The field may be missing: data.get("name", "") returns an empty string instead of an error.
  2. Hint 2. isinstance(age, int) checks for a whole number, 1 <= age <= 120 checks the range.
  3. Hint 3. In Python True also counts as an int. Filter it out separately: isinstance(age, bool).
Show solution
def validate_user(data):
    errors = []
    if not str(data.get("name", "")).strip():
        errors.append("name")
    age = data.get("age")
    if not isinstance(age, int) or isinstance(age, bool) or not 1 <= age <= 120:
        errors.append("age")
    return errors

14. A JSON response

Write tasks_json(tasks). The function takes a list of dictionaries and returns a JSON string with only the tasks whose done is False. Non-English letters (like é) must stay readable. The import is already there.

15. Your own template

Level: Medium

A template is text with gaps. Write render(template, data): it replaces every gap {{ name }} with the value from the data dictionary. There may or may not be spaces inside the braces. If the key is not in the dictionary, put an empty string.

  1. Hint 1. The regular expression r"\{\{\s*(\w+)\s*\}\}" finds all the gaps.
  2. Hint 2. re.sub(pattern, function, text) calls the function for every gap it finds and puts in its answer.
  3. Hint 3. Inside the function the gap's name is match.group(1), and str(data.get(name, "")) gets the value.
Show solution
import re

def render(template, data):
    def value(match):
        return str(data.get(match.group(1), ""))
    return re.sub(r"\{\{\s*(\w+)\s*\}\}", value, template)

16. Pages of a list

Level: Medium

A long list is shown in parts. Write paginate(items, page, per_page): return the items of page number page (numbering starts at 1). If there is no page with that number, or the number is less than 1, return an empty list.

  1. Hint 1. The first item of the page is at position (page - 1) * per_page.
  2. Hint 2. The slice items[start:start + per_page] shortens itself if there are fewer items.
  3. Hint 3. Check a page number below 1 separately, otherwise a negative slice returns extra items.
Show solution
def paginate(items, page, per_page):
    if page < 1:
        return []
    start = (page - 1) * per_page
    return items[start:start + per_page]

18. File type

Level: Medium

A server tells the browser the file type in the Content-Type header. Write content_type(filename): for .html return text/html, for .css text/css, for .js text/javascript, for .json application/json, and for anything else application/octet-stream. Letter case in the name does not matter.

  1. Hint 1. The extension is the part after the last dot: filename.rsplit(".", 1)[-1].
  2. Hint 2. Lowercase the name with .lower() and take the type from a dictionary with .get() and a fallback.
Show solution
def content_type(filename):
    types = {"html": "text/html", "css": "text/css", "js": "text/javascript", "json": "application/json"}
    extension = filename.lower().rsplit(".", 1)[-1]
    return types.get(extension, "application/octet-stream")

19. Address with parameters

Level: Medium

Write build_url(path, params): add the parameters from a dictionary to the path. "/search" and {"q": "flask", "page": 2} must give /search?q=flask&page=2. If the dictionary is empty, return the path without a question mark.

  1. Hint 1. params.items() gives key and value pairs. Turn each one into a string f"{key}={value}".
  2. Hint 2. Join the pairs with "&".join(pairs) and add them to the path after ?.
Show solution
def build_url(path, params):
    if not params:
        return path
    pairs = [f"{key}={value}" for key, value in params.items()]
    return path + "?" + "&".join(pairs)

26. Looks like an email

Level: Hard

Write is_email(value): a rough check of an email address. The address has no spaces, exactly one @ sign, at least one character before it, and after it a dot that is neither first nor last.

  1. Hint 1. value.count("@") counts how many times a character appears.
  2. Hint 2. Split the address into two parts: name, domain = value.split("@"), and check each one separately.
Show solution
def is_email(value):
    if " " in value or value.count("@") != 1:
        return False
    name, domain = value.split("@")
    if not name or "." not in domain:
        return False
    return not domain.startswith(".") and not domain.endswith(".")

27. Safe insert

Level: Medium

Write add_task(db, title): it adds a row to the tasks table and returns its id. Use the ? parameter: text with a quote must not break the query.

  2. Hint 2. The values are passed as the second argument, a tuple: db.execute(query, (title,)). The comma after title is required.

def add_task(db, title):

    return cursor.lastrowid

Level: Hard

Make DELETE /tasks/<int:task_id>. If the task is in the TASKS dictionary, delete it and return an empty response with code 204. If it is not there, return {"error": "not found"} with code 404.

  1. Hint 1. A delete route is declared with @app.delete(...). del TASKS[task_id] removes an item from a dictionary.
  2. Hint 2. An empty response with a code: return "", 204.
Show solution
from flask import Flask

app = Flask(__name__)
TASKS = {1: "Buy bread", 2: "Learn Flask"}

@app.delete("/tasks/<int:task_id>")
def delete_task(task_id):
    if task_id not in TASKS:
        return {"error": "not found"}, 404
    del TASKS[task_id]
    return "", 204
