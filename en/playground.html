Home / Sandbox

Python right in the browser

Write code and press “Run”. Nothing to install: the code runs on your device and is not sent anywhere.

Editor

Ctrl+Enter runs the code. Your draft is saved in this browser.

What to know

The sandbox runs on Pyodide: Python built for the browser.

  • On the first run the browser downloads about 5 MB from jsDelivr. The Flask example also loads packages from PyPI.
  • A real server cannot be started here. Instead, the Flask app receives requests through test_client().
  • input() does not work in the browser. Set the values right in the code.
  • Code stops after 10 seconds, so an infinite loop will not freeze the page.
