  1. Lesson 0. How this course works

    Why. Before writing code, it helps to understand three things: what a program is, why we learn Python and how to study on this page.

    What a program is. A program is an instruction for a computer. It is like a recipe: a cook follows the steps in order, first chopping, then cooking. A computer also runs commands one by one, from top to bottom.

    Why Python. Python code reads almost like ordinary English text, with few extra symbols. People use Python to build websites, process data and automate boring work. That is why it is often chosen as a first language.

    How to study. Every lesson has an explanation, examples and exercises. Click “Run” under an example, and Python will run the code right here, in the browser. You can change the code however you like: the computer won't break.

    Exercises with checking. Write a solution and click “Check”. If it doesn't work out, open the hints one by one. There is a ready solution too, but try on your own first.

    Progress. The “Lesson done” tick is saved in this browser. Look up unfamiliar words in the glossary.

    Try it: run both examples of this lesson. They are already real programs.

    Common question: do I need to install anything?

    No. Python loads into the browser by itself the first time you run code, it takes a few seconds. You will need to install Python on your computer later, for your own project, and there is a separate lesson about it.

    Common question: do I need to be good at maths and English?

    No. School arithmetic is enough. Python has few English words, and we explain what they mean in the lessons.

    In short:

    • a program is commands that the computer runs one by one, from top to bottom;
    • code here runs right in the browser, nothing to install;
    • making mistakes is not scary: try, change and run again.
    Example 1. A recipe step by step
    print("Step 1: I take a cup")

print("Step 3: I drink the tea")
    Example 2. Python can count
    print(2 + 2)

    In the second example the first line calculates, and the second prints the text as is: Python doesn't calculate anything in quotes.

  2. Lesson 1. Your first program

    Why. Any program, even a big website, is made of simple commands. Let's start with the most important one — the command that shows a result.

    The print command shows on the screen what is in the brackets. Text is written in quotes: print("Hello!"). Numbers can be written without quotes: print(2026).

    Order. Each command is written on a new line. Python runs them from top to bottom: what is higher gets printed earlier.

    Several values. One print can list several values separated by commas. Python puts spaces between them itself: print("I am", 16, "years old") prints I am 16 years old.

    An empty line. print() with nothing in the brackets prints an empty line. It is handy for separating one part of the output from another.

    Comments. Everything after the # sign is a note for people. Python skips it. Comments help explain what the code does.

    Try it: write your name in quotes and click “Run”. Then swap the two lines and see how the output changes.

    Common mistake: a missing quote or bracket

    Quotes and brackets always come in pairs. If you write print("Hello!), Python can't find the end of the text: SyntaxError: unterminated string literal Check that every opening quote and bracket has a closing one.

    Common mistake: Print with a capital letter

    Python tells capital and small letters apart. Print and print are different words for it, and it doesn't know the first one: NameError: name 'Print' is not defined Python commands are written in small letters.

    In short:

    • print(...) shows a result: text in quotes, numbers without quotes;
    • commands run from top to bottom, each on a new line;
    • # starts a comment, and quotes and brackets always come in pairs.
    Example 1. First commands
    # This is a comment: Python will skip it
print("Hello!")
print("This is my first program")
    Example 2. Several values
    print("My name is", "Aruzhan")
print("I am", 16, "years old")
print()
print("Learning to program since", 2026)

  3. Lesson 2. Numbers: Python as a calculator

    Why. Websites count all the time: the price in a cart, test scores, how many days are left until an exam. So first let's learn to count.

    Operations. Python adds +, subtracts -, multiplies * and divides /. You can print the result right away: print(2 + 3).

    Whole and decimal numbers. There are whole numbers, for example 7, and decimal ones, for example 7.5. The fractional part is separated with a dot, not a comma. Ordinary division / always gives a decimal number: 10 / 2 equals 5.0.

    Whole division and remainder. Imagine 17 sweets packed 5 to a box. 17 // 5 answers how many full boxes you get: 3. 17 % 5 answers how many sweets are left over: 2.

    Powers and order of operations. 2 ** 3 is 2 cubed, that is 8. The order of operations is as in maths: first multiplication and division, then addition and subtraction. Brackets change the order: (2 + 3) * 4 equals 20.

    Rounding. round(3.14159, 2) keeps two digits after the dot: 3.14.

    A number and text are different things. 2 + 2 gives 4, but "2" + "2" gives "22": that is glued text, not a sum.

    Try it: calculate how many minutes there are in a week. Then check how the remainder works: what does 10 % 3 give?

    Common mistake: a comma instead of a dot

    A decimal number needs a dot. If you write print(2,5), there will be no error, but Python will read it as two numbers and print 2 5. Correct: print(2.5).

    Common mistake: division by zero

    You can't divide by zero in Python either. The command print(5 / 0) stops the program: ZeroDivisionError: division by zero Check that the divisor isn't zero.

    In short:

    • + - * / are the usual operations, the fractional part is separated with a dot;
    • // — how many whole times, % — the remainder, ** — a power;
    • numbers are written without quotes: "2" in quotes is already text.
    Example 1. A calculator
    print(7 + 5)
print(7 - 5)
print(7 * 5)
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 10)
    Example 2. Shopping
    print("Three notebooks at 450 tenge:", 3 * 450)
print("With a pen for 200:", 3 * 450 + 200)
print("Change from 2000:", 2000 - (3 * 450 + 200))
print("Average grade:", round((5 + 4 + 5) / 3, 1))

  4. Lesson 3. Variables: how to remember a value

    Why. A program has to remember data: a student's name, test scores, the total in a cart. That is what variables are for.

    What a variable is. A variable is a labelled box. You put a value in the box and then refer to it by the label. name = "Anya" means: put the text "Anya" in the box labelled name.

    The = sign in Python means “put”, not “equals”. The box name goes on the left, and what goes into it on the right.

    A value can change. score = score + 10 means: take what is in score, add 10 and put it back. The short way to write the same thing is score += 10.

    How to name variables. Use Latin letters, digits and the _ sign. A name can't start with a digit. Choose clear names: user_age is better than a.

    Value types. Every value has a type: str — text, int — a whole number, float — a decimal. type(...) tells you the type. int("16"), str(16) and float("2.5") turn one into another.

    Keyboard input. On a computer input("What is your name? ") asks a person and waits for an answer. The answer always comes as text, so a number is read like this: int(input()). In the browser on this site input() doesn't work, so we write values right in the code. And on websites data comes from forms, which get a lesson of their own.

    Try it: put in your own name and age and run again. Add 5 more to the score.

    Common mistake: a typo in a name

    If you create name and then write nmae, Python won't understand what you mean: NameError: name 'nmae' is not defined Check that the name is spelled the same everywhere, down to the letter.

    Common mistake: a number as text

    "16" + 1 won't work: text on the left, a number on the right. TypeError: can only concatenate str (not "int") to str First turn the text into a number: int("16") + 1 gives 17.

    In short:

    • a variable is a labelled box: name = "Anya", the = sign means “put”;
    • a value can change: score += 10;
    • type() tells the type, int(), str(), float() change it.
    Example 1. Boxes with data
    name = "Anya"
age = 18
score = 0

print("My name is", name)
print("In a year I will be", age + 1)

score = score + 10
score += 5
print("Score:", score)
    Example 2. Text or a number
    age_text = "16"
age = int(age_text)

print(type(age_text))
print(type(age))
print("In a year:", age + 1)
print("Glued text:", age_text + "1")

  5. Lesson 4. Strings: working with text

    Why. Almost everything on a website is text: a student's name, a heading, a message in a form. To work with text, you need to be able to store it, join it and fix it.

    What a string is. In Python text is called a string. It is letters standing in a row, like beads on a thread. A string is written in quotes: "Hello".

    Quotes are the borders of the text. Without them Python will think that Hello is a variable name and report an error.

    Joining strings is done with the + sign: "Hello, " + "Aruzhan" gives Hello, Aruzhan. Put the space in yourself: Python won't add it.

    An f-string is the handiest way to insert a value into text. Imagine a postcard with a gap for a name. The letter f before the quotes tells Python: “there are gaps here”. The gaps themselves are curly braces: f"Hello, {name}!". Python fills in the value of the variable.

    Methods are commands that every string has. They are written after a dot:

    • .strip() removes extra spaces at the start and at the end;
    • .title() makes the first letter capital: aruzhan → Aruzhan;
    • .upper() makes all letters capital, .lower() — small.

    Length and letters by number. len(name) counts how many characters a string has. And you can take one letter by its number in square brackets. Numbers start from zero: name[0] is the first letter, name[1] is the second.

    Try it: in the first example put in your name with extra spaces — the result won't change. Replace .title() with .upper(). In the second example change the city and the age.

    Common mistake: joining text with a number

    You can't add a string and a number with the + sign. The command print("I am " + 18) stops the program with an error: TypeError: can only concatenate str (not "int") to str Python doesn't understand what you wanted: to add numbers or to join text. Use an f-string: print(f"I am {18}"). It turns the number into text by itself.

    Common mistake: a string doesn't change by itself

    A method doesn't fix the string, it returns a new one. So after name.strip() the old spaces stay in name. You need to save the result: name = name.strip().

    In short:

    • text in quotes is a string, strings are joined with the + sign;
    • an f-string puts values into text: f"Hello, {name}!";
    • the methods .strip(), .title(), .upper() return a new string, len() counts characters, name[0] gives the first letter.
    Example 1. Tidying up a name
    name = "   aruzhan   "

clean = name.strip()
print(clean.title())
print("Characters in the name:", len(clean))
print("First letter:", clean[0].upper())
print("Hello, " + clean.title() + "!")
    Example 2. A postcard with gaps
    name = "Yerlan"
city = "Astana"
age = 16

print(f"Hello, {name}!")
print(f"You are from {city}, and you are {age}.")
print(f"In a year you will be {age + 1}.")

    Level: Easy

    2. Hint 2. .upper() gives capital letters, and methods can be written one after another: name.strip().upper().

    Show the solution

    1. Hint 1. First remove the spaces and save the result: first = first.strip(), and the same for last.

  6. Lesson 5. Conditions: if this, then that

    Why. A website keeps choosing: whether to let a user in, whether to accept an answer, whether there is enough money for a purchase. Conditions are for choosing.

    The word if means “if”. After it come the condition and a colon. The lines below it, indented by four spaces, run only if the condition is true.

    The word else means “otherwise”. Its lines run if the condition is false. And elif means “and if not, check this”. You can write as many such checks as you like, Python goes through them from top to bottom and stops at the first true one.

    Indentation shows which lines belong to the condition. It is not decoration: without it Python won't understand what to run.

    Comparisons. > greater, < less, >= and <= — greater than or equal and less than or equal. Equality is checked with two signs: ==. Not equal — !=. Text can be compared too: password == "qwerty".

    True and false. The answer to a comparison is True or False. Check it yourself: print(5 > 3) prints True.

    Several conditions. and is true when both are true. or needs just one. not flips the answer.

    Try it: in the first example set the temperature to 10, then 30. In the second change the age and the parents' permission.

    Common mistake: one = sign instead of two

    One = sign puts a value into a variable, and comparison uses two: ==. If you write if x = 5:, Python will tell you right away: SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?

    Common mistake: a missing indent or colon

    After a condition you need a colon, and the lines inside need an indent of four spaces. Otherwise Python stops: IndentationError: expected an indented block after 'if' statement on line 2 Put the colon and move the line to the right with Tab or four spaces.

    In short:

    • if — if, elif — else if, else — otherwise; after the condition a colon and an indent;
    • equality is checked with ==, and one = puts a value into a variable;
    • and — both conditions, or — at least one, not — the opposite.
    Example 1. What to wear
    temperature = -5

if temperature < 0:
    print("It's freezing outside, wear a hat")
elif temperature < 15:
    print("It's cool, take a jacket")
else:
    print("It's warm, a T-shirt will do")

print(temperature < 0)
    Example 2. Can I go hiking
    age = 15
parents_allow = True

if age >= 16 or parents_allow:
    print("You can go hiking")
else:
    print("Not yet")

if age >= 14 and age <= 17:
    print("You are in the teenagers' group")

  7. Mini-project 1. A discount calculator

    What we'll build. A program for a shop till: it calculates the discount and prints a receipt. This is how the cart of any online shop works, only there the server does the same thing.

    You'll need: numbers (lesson 2), variables (lesson 3), f-strings (lesson 4) and conditions (lesson 5).

    The shop's rules:

    • if the purchase is 5000 tenge or more, the discount is 10%;
    • students get another 5% on top;
    • discounts add up: a student buying for 6000 gets 15%.

    Step-by-step plan:

    1. create a variable discount = 0 — the discount in percent;
    2. with two separate ifs add 10 and 5 to it if the conditions are true;
    3. calculate the amount to pay and round it to a whole number: round(...);
    4. print a three-line receipt as in the “How it should look” example.

    Why two separate ifs and not elif. elif only fires if the previous condition is false. Here the discounts must add up, so each condition is checked on its own.

    What you can add: free delivery from 10 000 tenge, a 20% birthday discount, a line “You saved: … tenge”.

    How it should look
    Total: 6000 tenge
Discount: 15%
To pay: 5100 tenge

    Project: a receipt with a discount

    Level: Medium

    A purchase of 6000 tenge, the customer is a student. Calculate the discount by the shop's rules and print the receipt exactly as in the example.

    1. Hint 1. The first condition: if price >= 5000: and under it discount += 10.
    2. Hint 2. The second is a separate if, not elif: if is_student: and discount += 5.
    3. Hint 3. The amount to pay: to_pay = round(price - price * discount / 100).
    4. Hint 4. The receipt: print(f"Total: {price} tenge"), then the discount with a % sign and the amount to pay the same way.
    Show the solution
    price = 6000
is_student = True
discount = 0

if price >= 5000:
    discount += 10
if is_student:
    discount += 5

to_pay = round(price - price * discount / 100)

print(f"Total: {price} tenge")
print(f"Discount: {discount}%")
print(f"To pay: {to_pay} tenge")

  8. Lesson 6. Lists: many values in one variable

    Why. On websites almost everything is a list: a news feed, the students of a class, items in a cart. Keeping each value in its own variable is awkward, so they are collected in a list.

    What a list is. A list is a row of values in square brackets separated by commas: ["apple", "pear", "plum"]. Imagine a train: each value rides in its own carriage.

    Carriage numbers start from zero, like the letters in a string. fruits[0] is the first element, fruits[1] is the second. From the end you count with negative numbers: fruits[-1] is the last.

    How many elements there are is shown by the familiar len(fruits).

    A list can change. fruits[1] = "kiwi" replaces the second element. .append("banana") adds to the end, .remove("pear") removes by value.

    Is it in the list? The word in checks this: "plum" in fruits gives True or False. Handy in conditions.

    Lists of numbers. sum() adds up all the numbers, min() and max() find the smallest and largest, sorted() returns them in order.

    Try it: add your own product to the first list and remove another one. In the second example add one more grade.

    Common mistake: numbers start from zero

    In a list of three elements the numbers are 0, 1 and 2. There is no element number 3: IndexError: list index out of range The number of the last element is one less than the length. Or just write [-1].

    Common mistake: the wrong method

    You add to a list with the .append() method. If you write .add(), Python answers that a list has no such thing: AttributeError: 'list' object has no attribute 'add'

    In short:

    • a list is values in square brackets: ["a", "b"], numbers start from zero;
    • .append() adds, .remove() removes, in checks whether a value is there;
    • len(), sum(), min(), max() and sorted() work with the whole list at once.
    Example 1. A shopping list
    shopping = ["bread", "milk", "apples"]

print(shopping[0])
print(shopping[-1])

shopping.append("cheese")
shopping.remove("milk")
print(shopping)
print("Items in total:", len(shopping))
print("Is there bread?", "bread" in shopping)
    Example 2. Grades for the term
    grades = [5, 4, 5, 3, 5, 4]

print("Number of grades:", len(grades))
print("Sum:", sum(grades))
print("Best:", max(grades), "worst:", min(grades))
print("Average:", round(sum(grades) / len(grades), 2))
print("In order:", sorted(grades))

  9. Lesson 7. Loops: one action many times

    Why. A website shows a feed of a hundred posts, but the code for one post is written once. A loop repeats it for each one.

    The for loop means “for each”. for fruit in fruits: reads: “for each fruit in the list of fruits do…”. Python takes the elements one by one, puts the current one into the fruit variable and runs the indented lines.

    Repeating several times is done with range. range(5) gives the numbers 0, 1, 2, 3, 4 — five of them, starting from zero. range(1, 6) gives the numbers from 1 to 5: the last number is not included.

    Accumulating. A common trick: create a variable before the loop and change it inside. For example, total = 0, and in the loop total += price. After the loop total holds the sum.

    The while loop means “while”. It repeats lines while the condition is true. It is needed when you don't know in advance how many repeats there will be: for example, saving until you have the amount you need.

    To leave early use the break command: the loop ends at once.

    Try it: in the first example add your own fruit and change range(1, 4) to range(1, 11). In the second change the amount you save each week.

    Common mistake: an endless loop

    If nothing changes inside while, the condition is always true and the loop never ends. The program “hangs”. Check that the variable from the condition changes in the loop: for example, there is money += 150.

    Common mistake: one number short

    range(1, 10) gives the numbers from 1 to 9, not to 10. Python won't show an error, the last number just won't be in the answer. To reach 10, write range(1, 11).

    In short:

    • for x in list: repeats the indented lines for each element;
    • range(1, 6) is the numbers from 1 to 5, the last one is not included;
    • while condition: repeats while the condition is true, and something must change inside.
    Example 1. For each
    fruits = ["apple", "pear", "plum"]

for fruit in fruits:
    print("I love", fruit)

for number in range(1, 4):
    print("Repeat number", number)

total = 0
for price in [450, 200, 1200]:
    total += price
print("Total:", total)
    Example 2. Saving up for headphones
    money = 0
weeks = 0

while money < 1000:
    money += 150
    weeks += 1

print("Weeks needed:", weeks)
print("Saved:", money)

  10. Lesson 8. Functions: your own command

    Why. The same action is often needed in different places: calculating a discounted price, greeting a user. To avoid copying code, you give it a name and call it by that name.

    What a function is. A function is your own command. You have already used ready-made ones: print, len, round. Now let's learn to make our own.

    How to define one. The word def starts the definition. Then come the function name, brackets and a colon: def greet(name):. The function's lines are indented, as in conditions and loops.

    Parameters are the empty places in the brackets. When the function is called, they are filled with values: greet("Anya") puts "Anya" into name.

    Defining is not running. The code inside def works only when the function is called: the name and brackets, greet("Anya").

    return hands back the result. A function is like a coffee machine: you give it beans, it gives back coffee. return means “here is the finished result, take it”. You can save it in a variable or use it further: total = price_with_discount(1000, 10).

    print and return are different things. print only shows a value on the screen. return hands it back to the program so you can keep working with it.

    A default value. def greet(name="guest"): — if no name is passed, it will be “guest”.

    Try it: call greet with your own name. In the second example change the discount and see how the total changes.

    Common mistake: print instead of return

    If a function prints the result instead of returning it, you can't keep working with it: the function returns the empty value None. Trying to add a number to it ends like this: TypeError: unsupported operand type(s) for +: 'NoneType' and 'int' Write return inside the function, and print the result outside: print(f(3)).

    Common mistake: forgetting the brackets when calling

    print(greet) without brackets doesn't call the function, it prints something like <function greet at 0x…>. For the function to work you need brackets: greet() or greet("Anya").

    In short:

    • def name(parameters): defines a function, and it runs when called: name(...);
    • return hands back the result, print only shows it;
    • a parameter can have a default value: name="guest".
    Example 1. A greeting
    def greet(name="guest"):
    return f"Hello, {name}!"

print(greet("Anya"))
print(greet("Marat"))
print(greet())

  12. Lesson 9. Dictionaries: find a value by its name

    Why. A website user has a name, an age, a city. It is convenient to store them not by number, as in a list, but by name: “name — Aruzhan”, “city — Almaty”. That is what dictionaries are for.

    What a dictionary is. A dictionary stores “key — value” pairs in curly braces: {"bread": 200, "milk": 450}. It is like the contacts in a phone: you find the number by the name. Or like a price list: the price by the product name.

    To get a value use its key in square brackets: prices["bread"] gives 200.

    To add or change: prices["cheese"] = 1500. If the key wasn't there, it appears, and if it was, the value is replaced. To delete a pair: del prices["bread"].

    To get safely. prices.get("coffee", 0) returns the price of coffee, and if it isn't in the dictionary, returns 0 instead of an error. You can check whether a key exists with the familiar word in: "bread" in prices.

    To go through a dictionary. for name, price in prices.items(): takes the pairs in turn: the key goes into name, the value into price.

    A list of dictionaries is the usual way to store many similar records: products, students, messages. This is exactly the form in which websites pass data to each other, it is called JSON.

    Try it: add your own product with a price, change the price of milk. In the second example add one more student.

    Common mistake: there is no such key

    If you ask for a key that isn't in the dictionary, the program stops: KeyError: 'coffee' Check the spelling: "Bread" and "bread" are different keys. If the key may be missing, use .get().

    Common mistake: a number instead of a key

    A dictionary has no numbers like a list: prices[0] looks for the key 0 and won't find it. Use the name: prices["bread"].

    In short:

    • a dictionary is “key: value” pairs in curly braces, a value is found by its key;
    • d[key] = value adds or changes, .get(key, fallback) doesn't fail if the key is missing;
    • for k, v in d.items(): goes through the pairs, and a list of dictionaries stores many records.

  14. Lesson 10. Errors: how to read and catch them

    Why. Everyone makes errors, even experienced programmers. A user types letters instead of a number, a record is missing, the internet goes down. A good program doesn't “crash” in such cases, it calmly explains what is wrong.

    How to read an error message. Python writes several lines, and the most important is the last one. It has the error type and a short explanation, for example ValueError: invalid literal for int(). The line with line 3 shows where to look. On this site a “What it means” hint also appears under the error.

    Errors you have already met:

    • SyntaxError — the code is written incorrectly: a missing quote, bracket, colon;
    • NameError — there is no such name, often a typo;
    • TypeError — the operation doesn't fit the type, for example text plus a number;
    • IndexError and KeyError — there is no element with such a number or key;
    • ValueError — the value doesn't fit: int("abc").

    To catch an error use try and except. It means: “try to do this, and if such an error happens, do that”. The program won't stop.

    Catch a specific error: except ValueError:, not everything at once. Otherwise except will hide a real typo too, and you'll spend a long time figuring out why the program misbehaves.

    Try it: in the first example add your own answer to the list, for example "twenty". In the second divide by zero and see what the function answers.

    Common mistake: catching absolutely everything

    An empty except: without an error name catches anything, even a typo in a variable name. The program “silently” does the wrong thing, and the cause will be hard to find. Always write which error you expect: except ValueError:.

    Common mistake: reading the message from the top

    Beginners are often scared by a long message and read its first line. Start from the last one: it says what happened, for example ValueError: invalid literal for int() with base 10: 'abc' This means “'abc' can't be turned into a whole number”.

    In short:

    • in an error message the main thing is the last line: the error type and the explanation;
    • try: — try, except Type: — what to do if such an error happened;
    • catch specific errors, not all of them at once.
    Example 1. Answers from a form
    answers = ["16", "abc", "20", ""]

for text in answers:
    try:
        age = int(text)
        print("Age:", age)
    except ValueError:
        print(f"“{text}” is not a number, skipping")
    Example 2. Safe division
    def divide(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return "you can't divide by zero"

print(divide(10, 4))
print(divide(10, 0))

  15. Lesson 11. Modules: ready-made tools

    Why. You don't have to write everything yourself. Python comes with a whole library of ready-made tools: random numbers, maths, dates. These sets are called modules.

    How to connect one. A module is connected with the import command at the start of the program: import random. After that its tools are available after a dot: random.randint(1, 6).

    To take one thing write: from datetime import date. Then you just write date, without the module name.

    Three useful modules:

    • random — chance: randint(1, 6) rolls a die, choice(list) picks a random element;
    • math — maths: sqrt(16) is a square root, pi is the number π;
    • datetime — dates: date.today() is today's date, and the difference of two dates shows how many days are between them.

    Modules from the internet. Besides the built-in ones, there are thousands of modules by other people, called packages. They are installed with the pip install command. This is how Flask and Django are installed, we'll cover it in the first project.

    Try it: run the first example several times: the answers will differ. In the second change the event date to your birthday.

    Common mistake: forgetting import

    If you write random.randint(1, 6) right away without connecting the module, Python doesn't know it and even tells you what's wrong: NameError: name 'random' is not defined. Did you forget to import 'random'? Add import random at the start of the program.

    Common mistake: a typo in the module name

    The module name must be exact. import randon ends with an error: ModuleNotFoundError: No module named 'randon'

    In short:

    • a module is a set of ready-made tools, connected with import;
    • import random and random.randint(), or from datetime import date and just date;
    • built-in modules come with Python, the rest are installed with pip install.

  16. Mini-project 4. Guess the number

    What we'll build. The computer picks a number from 1 to 100 and then guesses it itself. The trick is that it will guess in 7 tries or fewer, whatever number was picked. This is a real algorithm, called halving or binary search. This is how searching in databases works, and even the “hot and cold” game.

    You'll need: conditions (lesson 5), the while loop (lesson 7), functions (lesson 8) and the random module (lesson 11).

    How to guess. The number is somewhere between low = 1 and high = 100. We name the middle: (low + high) // 2. If we guessed it, we're done. If the secret is bigger, everything below the middle can be thrown away: low = middle + 1. If it is smaller, we throw away the upper half: high = middle - 1. Each try halves the range, so 100 numbers run out very quickly.

    Step-by-step plan:

    1. in the function guess_number(secret, low=1, high=100) create a try counter tries = 0;
    2. make a while True: loop — “repeat until we say stop”;
    3. in the loop add a try and name the middle;
    4. if you guessed it, return the number of tries at once: return ends both the loop and the function. Otherwise move low or high.

    What you can add: printing each try (“trying 50 — higher”), and also a check that 7 tries really are enough for 100 numbers: go through all the numbers from 1 to 100 with a loop and find the largest number of tries.

    How it looks step by step
    import random

secret = random.randint(1, 100)
low = 1
high = 100
tries = 0

while True:
    tries += 1
    guess = (low + high) // 2
    if guess == secret:
        print(f"Try {tries}: {guess} — got it!")
        break
    elif guess < secret:
        print(f"Try {tries}: {guess} — higher")
        low = guess + 1
    else:
        print(f"Try {tries}: {guess} — lower")
        high = guess - 1

    Project: a guessing function

    Level: Hard

    Write a function guess_number(secret, low=1, high=100) that guesses secret by halving and returns how many tries it took. For example, guess_number(50) guesses on the first try and returns 1.

    1. Hint 1. The “How it looks step by step” example is almost a ready solution. The only difference: instead of print and break you need return tries.
    2. Hint 2. Inside while True: the first line is tries += 1, the second guess = (low + high) // 2.
    3. Hint 3. if guess == secret: return tries.
    4. Hint 4. elif guess < secret: low = guess + 1, otherwise high = guess - 1.
    Show the solution

    tries = 0
    while True:
        tries += 1
        guess = (low + high) // 2
        if guess == secret:
            return tries
        elif guess < secret:
            low = guess + 1
        else:
            high = guess - 1

  17. Lesson 12. How this connects to websites

    Why. You have learned the basics of Python. Now let's put them together and see how a website is built from these bricks.

    How a website works. You type an address in the browser, and the browser sends a request to a server. A server is a computer running a program, for example in Python. It looks at the address, picks the right function, and that function returns a response: the text of the page. More on the “How a website works” page.

    Where your lessons are here:

    • functions — each page of the site: a function receives a request and returns a page;
    • a dictionary — “address → function”: this is how the site chooses what to show;
    • f-strings — put data into the page: “Hello, {name}!”;
    • lists and loops — a feed of posts, a task list, products in a catalogue;
    • conditions — whether the user is logged in, whether the password is correct;
    • errors — a “404: not found” page instead of the site crashing;
    • modules — Flask and Django, ready-made tools for websites.

    Flask. The second example is the same site on Flask. The line @app.route("/") says: “this address opens this function”. It is really the same dictionary of addresses, only Flask creates it for you.

    Try it: in the first example change the address to "/", then to "/tasks", then to one that doesn't exist. Add your own task to the list.

    Common mistake: there is no such page

    If you open an address that isn't in the dictionary, pages[address] fails with KeyError. A real site doesn't do that: it shows a “404: not found” page. In the example pages.get(address, not_found) does this.

    In short:

    • a website is a program: it receives an address and returns a page;
    • pages are functions, addresses are dictionary keys, data is put in with f-strings;
    • Flask and Django do the same thing, only more conveniently; next you'll build your first project on them.
