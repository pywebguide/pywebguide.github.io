Final test

15 questions on the whole course. Answer 12 or more correctly, and you can download a learning certificate. The number of attempts is unlimited.

Questions

After checking, an explanation appears under each question.

1. Where does the server-side code of a website run?

The backend runs on the server: it receives the request, runs the logic and returns a response.

2. What does routing do?

In Flask it is the @app.route decorator, in Django the urlpatterns list.

3. Why do you need a virtual environment?

Every project can have its own library versions, and they will not get in each other's way.

4. Which framework gives you an ORM and an admin panel out of the box?

Django comes with an ORM and an admin. Flask is minimal, and Jinja is a template language.

5. What is a migration in Django?

The makemigrations command creates such a file, and migrate applies it to the database.

6. What is the right way to pass a value from the user into SQL?

Parameters protect against SQL injection. Putting the value into the string lets the query itself be changed.

7. What does {{ name }} do in a Jinja template?

Auto-escaping protects against XSS. The |safe filter turns it off.

8. Why redirect after a form is submitted successfully?

This technique is called Post/Redirect/Get.

9. How should user passwords be stored?

A hash cannot be reversed, and salt and slowing down make guessing harder. Fast hashes like md5 are not suitable for passwords.

10. What does a CSRF token in a form protect against?

Another site does not know the secret token, so its request is rejected.

11. Which status code fits after a record is created successfully?

201 Created means a new resource has been created.

12. Which HTTP method usually deletes a record in a REST API?

GET only reads data and must not change anything.

13. What does app.test_client() do in Flask?

That is why tests run fast and need no running server.

14. What does the git commit command do?

git push sends the code to GitHub.

15. What must not be left on a public server?

In debug mode visitors see settings and pieces of code, and a leaked key lets people forge sessions.

Congratulations! You passed the test

You can always open the certificate again on the “My progress” page.

The certificate is created right in the browser, and the name is not sent or stored anywhere. This is a learning certificate for self-assessment, not an official document.
