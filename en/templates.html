How the server builds pages

A template is HTML with places for data. A form is a way to get data from the user. We look at both; examples with a “Run” button execute right in the browser.

Jinja templates

Flask uses Jinja, and Django's template language is very similar to it.

  • {{ value }} outputs data and escapes HTML automatically.
  • {% if %} and {% for %} add conditions and loops.
  • {% extends %} and {% block %} give all pages a shared frame.
Flask: a loop and a condition in a template 
from flask import Flask, render_template_string

app = Flask(__name__)

PAGE = """
<h1>Задачи: {{ tasks|length }}</h1>
{% for task in tasks %}
  <p>{{ loop.index }}. {{ task.title }}{% if task.done %} (готово){% endif %}</p>
{% else %}
  <p>Задач пока нет</p>
{% endfor %}
"""

@app.route("/")
def index():
    tasks = [
        {"title": "Купить ракетку", "done": True},
        {"title": "Прочитать про шаблоны", "done": False},
    ]
    return render_template_string(PAGE, tasks=tasks)

print(app.test_client().get("/").text)

test_client() sends a request to the app without a real server. Tests are written the same way.

Template inheritance

The header and footer are described once, and pages replace only their own block.

templates/base.html 
<!doctype html>
<html lang="ru">
<head><title>{% block title %}Сайт{% endblock %}</title></head>
<body>
  <nav><a href="/">Главная</a></nav>
  {% block content %}{% endblock %}
</body>
</html>
templates/index.html 
{% extends "base.html" %}

{% block title %}Задачи{% endblock %}

{% block content %}
  <h1>Мои задачи</h1>
{% endblock %}

In Flask the files live in the templates folder, and render_template("index.html") returns the page. In Django render(request, "index.html") does the same.

Why escaping matters

If you output the user's text as it is, they can put their own script on the page. This is called XSS.

Escaping and the dangerous safe filter 
from flask import Flask, render_template_string, request

app = Flask(__name__)

@app.route("/")
def index():
    name = request.args.get("name", "гость")
    safe = render_template_string("<p>{{ name }}</p>", name=name)
    danger = render_template_string("<p>{{ name|safe }}</p>", name=name)
    return f"Правильно: {safe}\nОпасно:    {danger}"

response = app.test_client().get("/", query_string={"name": "<script>alert(1)</script>"})
print(response.text)

The |safe filter turns the protection off. Use it only for HTML you wrote yourself.

Forms in Flask

Form data is in request.form. The server must check it itself: checks in the browser are easy to bypass.

Flask: checking form data 
from flask import Flask, redirect, render_template_string, request, url_for

app = Flask(__name__)
tasks = []

PAGE = """
{% if error %}<p>{{ error }}</p>{% endif %}
<form method="post"><input name="title"><button>Добавить</button></form>
<ul>{% for task in tasks %}<li>{{ task }}</li>{% endfor %}</ul>
"""

@app.route("/", methods=["GET", "POST"])
def index():
    error = None
    if request.method == "POST":
        title = request.form.get("title", "").strip()
        if not title:
            error = "Введите название"
        elif len(title) > 100:
            error = "Слишком длинное название"
        else:
            tasks.append(title)
            return redirect(url_for("index"))
    return render_template_string(PAGE, tasks=tasks, error=error)

client = app.test_client()
print("Пустая форма:", "Введите название" in client.post("/", data={"title": " "}).text)
response = client.post("/", data={"title": "Первая задача"})
print("После добавления статус:", response.status_code, "переход на", response.location)
print("Задачи:", tasks)

After a successful POST, send a redirect. Otherwise, when the page is refreshed, the browser repeats the submission and the task is added again.

CSRF protection

Another site can quietly submit a form on behalf of a logged-in user. The defence is a secret token in every form.

Django

Protection is on by default. Add the {% csrf_token %} tag to every POST form, otherwise the server responds with error 403.

Flask

There is no built-in protection. The usual choice is the Flask-WTF extension: CSRFProtect(app) and a hidden token field in the form.

Forms in Django

A form class describes the fields, checks the data and can render itself as HTML.

tasks/forms.py 
from django import forms

class TaskForm(forms.Form):
    title = forms.CharField(label="Задача", max_length=100)
tasks/views.py 
from django.shortcuts import redirect, render

from .forms import TaskForm
from .models import Task

def index(request):
    form = TaskForm(request.POST or None)
    if form.is_valid():
        Task.objects.create(title=form.cleaned_data["title"])
        return redirect("index")
    return render(request, "index.html", {"form": form, "tasks": Task.objects.all()})
templates/index.html 
<form method="post">
  {% csrf_token %}
  {{ form.as_p }}
  <button>Добавить</button>
</form>
