HTML и CSS

Пять уроков о том, из чего сделана любая страница: теги, ссылки, формы и оформление. В последнем уроке Python сам собирает HTML. Нажимайте «Показать», чтобы сразу увидеть результат.

Лучше начинать после уроков «Python с нуля»: последний урок использует функции и циклы. Незнакомые слова есть в словаре.

0 из 5 уроков пройдено

  1. Урок 1. Что такое HTML: теги и скелет страницы

    Зачем. Когда вы открываете сайт, сервер на Python отвечает браузеру текстом на языке HTML. Браузер читает этот текст и рисует страницу. Чтобы сделать свой сайт, нужно знать, как этот текст устроен.

    Что такое HTML. Это язык разметки, а не программа. В нём нет условий и циклов. HTML просто подписывает части текста: «это заголовок», «это абзац», «это важное слово».

    Теги. Подпись называется тегом и пишется в угловых скобках. Обычно теги парные: открывающий <p> и закрывающий </p> со слешем. Текст между ними — содержимое. Тег вместе с содержимым называют элементом.

    Самые нужные теги:

    • <h1>…<h6> — заголовки, <h1> главный и обычно один на странице;
    • <p> — абзац текста;
    • <strong> — важные слова, браузер покажет их жирным, <em> — выделение курсивом;
    • <br> — перенос строки. Это одиночный тег, закрывать его не нужно.

    Вложенность. Теги складывают друг в друга, как коробки: <p>Это <strong>важно</strong></p>. Закрывают в обратном порядке: сначала внутренний, потом внешний.

    Скелет страницы. У каждой страницы одинаковый каркас: строка <!doctype html>, затем <html>, внутри него <head> со служебными сведениями, например заголовком вкладки <title>, и <body> — всё, что видно на странице.

    Попробуйте: нажмите «Показать» под примерами. Поменяйте текст заголовка, добавьте ещё один абзац и снова нажмите «Показать».

    Частая ошибка: забыли закрыть тег

    Если не закрыть <strong>, браузер сделает жирным весь текст до конца страницы. Ошибку он не покажет, просто страница будет выглядеть странно. Проверьте, что у каждого парного тега есть закрывающий со слешем.

    Частая ошибка: перепутанный порядок закрытия

    <p><strong>текст</p></strong> — неправильно: коробки «перекрещиваются». Правильно закрывать от внутренней к внешней: <p><strong>текст</strong></p>.

    Коротко:

    • HTML подписывает части текста тегами: <h1>, <p>, <strong>;
    • парный тег закрывают слешем, вложенные теги закрывают в обратном порядке;
    • скелет страницы: <html>, внутри <head> для служебного и <body> для видимого.
    Пример 1. Первые теги
    <h1>Привет, я Аружан</h1>
<p>Я учусь делать сайты на <strong>Python</strong>.</p>
<p>Это мой второй абзац.<br>А это новая строка в нём.</p>
<h2>Мои планы</h2>
<p>Сделать <em>свой</em> первый сайт.</p>
    Пример 2. Полный скелет страницы
    <!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <title>Моя визитка</title>
</head>
<body>
  <h1>Ерлан Нурланов</h1>
  <p>Учусь программировать в Астане.</p>
</body>
</html>

  2. Урок 2. Списки, ссылки и картинки

    Зачем. Меню сайта — это список ссылок. Карточка товара — картинка с подписью. Эти три тега встречаются почти на каждой странице.

    Списки. <ul> — список с точками, <ol> — с номерами. Каждый пункт пишут в <li>. Это как список в Python, только для показа на странице.

    Ссылки. <a href="адрес">текст</a>. В атрибуте href пишут, куда ведёт ссылка, а между тегами — текст, на который нажимают.

    Атрибуты — это дополнительные сведения внутри открывающего тега: имя="значение". У ссылки это href, у картинки — src и alt.

    Полный и короткий адрес. https://www.python.org ведёт на другой сайт. about.html — на страницу этого же сайта, путь считается от текущей страницы.

    Картинки. <img src="адрес" alt="описание"> — одиночный тег. src — откуда взять картинку. alt — текст вместо картинки: его читают программы для незрячих, и он виден, если картинка не загрузилась. Пишите в нём, что изображено.

    Попробуйте: добавьте в меню свой пункт со ссылкой. В примере с картинкой поменяйте width на 150.

    Частая ошибка: адрес без https://

    <a href="www.python.org"> браузер поймёт как страницу этого же сайта с названием «www.python.org» и откроет ошибку 404. Адрес другого сайта пишите полностью: https://www.python.org.

    Частая ошибка: картинка без alt

    Без alt незрячий пользователь услышит только «изображение» или имя файла. Описывайте суть: не «картинка1», а «Питон на старой гравюре». Если картинка чисто украшение, пишите пустой alt="".

    Коротко:

    • <ul> и <ol> — списки, пункты в <li>;
    • <a href="..."> — ссылка, адрес другого сайта пишут с https://;
    • <img src="..." alt="..."> — картинка, и alt обязателен.
    Пример 1. Меню из ссылок
    <h2>Меню</h2>
<ul>
  <li><a href="https://pywebguide.github.io/">Главная</a></li>
  <li><a href="https://pywebguide.github.io/start.html">Python с нуля</a></li>
  <li><a href="https://www.python.org">Сайт Python</a></li>
</ul>
<h2>План на неделю</h2>
<ol>
  <li>Пройти уроки HTML</li>
  <li>Сделать визитку</li>
</ol>
    Пример 2. Картинка с подписью
    <img src="https://pywebguide.github.io/assets/img/snakes.webp"
     alt="Старая гравюра: восемь змей, среди них сетчатый питон"
     width="300">
<p>Язык Python назван не в честь змеи, а в честь комедийного шоу.</p>

  3. Урок 3. Формы: как сайт получает данные

    Зачем. Регистрация, поиск, отзыв, заказ — всё это формы. Именно через форму данные от человека попадают на сервер, к вашей программе на Python.

    Тег <form> собирает поля вместе. В атрибуте action пишут, куда отправить данные, а в method — как.

    Поля. <input> — одиночный тег для ввода. Его вид задаёт type: text — текст, email — почта, password — пароль точками, number — число, checkbox — галочка. Для длинного текста есть <textarea>, для отправки — <button>.

    Атрибут name — самое важное. Это имя, под которым значение придёт на сервер. В Flask оно станет ключом словаря: request.form["email"]. Без name поле не отправится вообще.

    Подпись <label>. Связывайте подпись с полем: у поля id="email", у подписи for="email". Тогда клик по подписи ставит курсор в поле, а программы для незрячих читают подпись вслух.

    GET и POST. method="get" кладёт данные в адрес страницы, так работает поиск: ?q=python. method="post" отправляет их скрыто, в теле запроса: так отправляют пароли и отзывы.

    Попробуйте: добавьте в форму поле для возраста с type="number". В окне предпросмотра отправка выключена, но поля работают: в них можно печатать.

    Частая ошибка: поле без name

    Если забыть name, браузер покажет поле и даже даст в него писать, но на сервер значение не придёт. В Python request.form["email"] упадёт с KeyError. Проверьте, что у каждого поля есть name.

    Частая ошибка: пароль через GET

    С method="get" пароль окажется прямо в адресной строке и в истории браузера. Для форм с паролями и личными данными всегда используйте method="post".

    Коротко:

    • <form> собирает поля, method="post" — для личных данных, get — для поиска;
    • <input type="..." name="...">: по name значение придёт на сервер;
    • <label for="id"> связывает подпись с полем.
    Пример 1. Регистрация
    <form action="/register" method="post">
  <p>
    <label for="name">Имя</label><br>
    <input id="name" name="name" type="text" placeholder="Аружан" required>
  </p>
  <p>
    <label for="email">Почта</label><br>
    <input id="email" name="email" type="email">
  </p>
  <p>
    <label for="password">Пароль</label><br>
    <input id="password" name="password" type="password">
  </p>
  <button type="submit">Зарегистрироваться</button>
</form>
    Пример 2. Что получит сервер
    # Так данные формы выглядят на сервере (Flask: request.form)
form = {"name": "Аружан", "email": "aru@example.com", "password": "секрет"}

print("Новый пользователь:", form["name"])
print("Почта:", form["email"])
print("Есть пароль?", "password" in form)

  4. Урок 4. CSS: внешний вид страницы

    Зачем. HTML говорит, что на странице: заголовок, абзац, кнопка. А CSS — как это выглядит: цвета, размеры, отступы. Этот сайт оформлен именно на CSS.

    Где писать. Проще всего — в теге <style> в начале страницы. На больших сайтах CSS выносят в отдельный файл.

    Правило CSS состоит из селектора и свойств в фигурных скобках: h1 { color: navy; }. Читается так: «у всех h1 цвет тёмно-синий». После каждого свойства ставят точку с запятой.

    Селекторы:

    • по тегу: p { ... } — все абзацы;
    • по классу: .card { ... } — все элементы с class="card". Это самый частый способ;
    • по id: #top { ... } — один элемент с id="top".

    Полезные свойства. color — цвет текста, background — фон, font-size — размер шрифта, font-weight: bold — жирность, text-align: center — выравнивание. padding — отступ внутри рамки, margin — снаружи, border — рамка, border-radius — скругление углов.

    Цвета задают словом (red) или кодом: #ffd249 — это жёлтый этого сайта.

    Попробуйте: поменяйте цвет фона карточки на #a4f6f8 и скругление на 20px.

    Частая ошибка: точка в атрибуте class

    Точку пишут только в CSS: .card { ... }. В HTML класс указывают без неё: class="card". С точкой class=".card" правило не сработает.

    Частая ошибка: забыли точку с запятой

    В color: red background: yellow; нет точки с запятой после red, и браузер пропустит оба свойства. Ошибку он не покажет: стиль просто не применится. Ставьте ; после каждого свойства.

    Коротко:

    • HTML — что на странице, CSS — как это выглядит;
    • правило: селектор { свойство: значение; }, класс в CSS пишут с точкой;
    • padding — отступ внутри, margin — снаружи.
    Пример 1. Оформляем текст
    <style>
  h1 { color: #2f6694; font-size: 40px; }
  p { font-size: 18px; color: #333333; }
  .important { background: #ffd249; font-weight: bold; }
</style>

<h1>Курс PyWeb Guide</h1>
<p>Обычный абзац.</p>
<p class="important">А этот абзац выделен классом.</p>
    Пример 2. Карточка товара
    <style>
  .card {
    width: 220px;
    padding: 16px;
    margin: 12px;
    background: #ffc4ef;
    border: 2px solid #0d0d0d;
    border-radius: 12px;
  }
  .price { font-size: 24px; font-weight: bold; }
</style>

<div class="card">
  <h2>Тетрадь</h2>
  <p class="price">450 тенге</p>
</div>

  5. Урок 5. Как Python собирает HTML

    Зачем. На настоящем сайте HTML не пишут вручную для каждого пользователя. Его собирает программа на сервере: подставляет имя, список задач, цены. Этот урок соединяет всё, что вы знаете о Python и HTML.

    HTML — это просто строка. Для Python страница — обычный текст. Значит, её можно собрать f-строкой: f"<h1>Привет, {name}!</h1>".

    Списки превращаются циклом. Чтобы показать список задач, программа проходит по нему и для каждой задачи добавляет строку <li>. Так делают ленты, каталоги и меню.

    Опасность: чужой код в странице. Если вставить в HTML текст пользователя как есть, он может написать туда свой тег, например <script>, и этот код выполнится у других посетителей. Такая атака называется XSS. Защита — функция html.escape: она превращает < в безопасное &lt;, и браузер покажет символ, а не выполнит тег.

    Шаблоны. Склеивать большие страницы строками неудобно. Поэтому во Flask и Django используют шаблоны: HTML-файл с пропусками {{ name }} и циклами {% for %}. Они сами вызывают escape для каждого значения. Подробнее — на странице «Шаблоны и формы».

    Попробуйте: в первом примере добавьте задачу в список. Во втором поменяйте текст комментария и сравните вывод с escape и без него.

    Частая ошибка: вставить текст пользователя без escape

    Комментарий <script>alert(1)</script>, вставленный как есть, станет частью страницы. Любой текст, который пришёл от пользователя, пропускайте через html.escape() или используйте шаблоны, которые делают это сами.

    Частая ошибка: забыли закрыть тег после цикла

    Если в цикле добавлять <li>, а </ul> забыть после цикла, список «растянется» на всю страницу. Открывающий тег — до цикла, закрывающий — после.

    Коротко:

    • для Python HTML — обычная строка: её собирают f-строками и циклами;
    • текст пользователя всегда пропускайте через html.escape;
    • во Flask и Django это делают шаблоны, и это следующий шаг.
    Пример 1. Страница из списка
    name = "Аружан"
tasks = ["выучить теги", "сделать форму", "оформить CSS"]

page = f"<h1>Задачи: {name}</h1>\n<ul>\n"
for task in tasks:
    page += f"  <li>{task}</li>\n"
page += "</ul>"

print(page)
    Пример 2. Защита через escape
    import html

comment = "<script>alert('взлом')</script>"

print("Опасно:   ", f"<p>{comment}</p>")
print("Безопасно:", f"<p>{html.escape(comment)}</p>")

    Задание: карточка товара из Python

    Уровень: Лёгкая

    Напишите функцию card(name, price). Она возвращает HTML карточки: <div class="card"><h2>Тетрадь</h2><p>450 тенге</p></div> для card("Тетрадь", 450).

    1. Подсказка 1. Соберите строку f-строкой и верните её через return.
    2. Подсказка 2. return f'<div class="card"><h2>{name}</h2><p>{price} тенге</p></div>'. Внешние кавычки одинарные, потому что внутри есть двойные.
    Показать решение
    def card(name, price):
    return f'<div class="card"><h2>{name}</h2><p>{price} тенге</p></div>'

    Задание посложнее: безопасный список

    Уровень: Средняя

    Напишите функцию render_list(items), которая возвращает список HTML: <ul><li>хлеб</li><li>молоко</li></ul>. Каждый пункт пропустите через html.escape, ведь пункты мог написать пользователь.

    1. Подсказка 1. Начните строку до цикла: result = "<ul>".
    2. Подсказка 2. В цикле: result += f"<li>{html.escape(item)}</li>".
    3. Подсказка 3. После цикла закройте список и верните: return result + "</ul>".
    Показать решение
    import html


def render_list(items):
    result = "<ul>"
    for item in items:
        result += f"<li>{html.escape(item)}</li>"
    return result + "</ul>"
