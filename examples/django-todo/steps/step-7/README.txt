Список задач на Django — код после шага 7 из 10 (PyWeb Guide)
https://pywebguide.github.io/project.html#django

Так выглядит проект, если шаги 1–7 сделаны правильно. Сверьте с ним свои файлы
или распакуйте и продолжайте с шага 8.
Полный код проекта: https://pywebguide.github.io/examples/django-todo.zip

Окружение и зависимости — как в шаге 1:
    python -m venv .venv
    .venv\Scripts\activate          (macOS и Linux: source .venv/bin/activate)
    pip install -r requirements.txt
Запуск: python manage.py runserver
