Қорытынды тест

Бүкіл курс бойынша 15 сұрақ. 12 немесе одан көп сұраққа дұрыс жауап беріңіз, сонда оқу сертификатын жүктеп алуға болады. Әрекет саны шектелмеген.

Сұрақтар

Тексергеннен кейін әр сұрақтың астында түсіндірме шығады.

1. Сайттың серверлік бөлігінің коды қайда орындалады?

Backend серверде жұмыс істейді: сұрауды қабылдайды, логиканы орындайды және жауап қайтарады.

2. Маршруттау не істейді?

Flask-та бұл @app.route декораторы, Django-да — urlpatterns тізімі.

3. Виртуалды орта не үшін керек?

Әр жобаның кітапханаларының өз нұсқалары болуы мүмкін, және олар бір-біріне кедергі келтірмейді.

4. Қай фреймворк ORM мен әкімші панелін бірден береді?

Django ORM-мен және әкімші панелімен бірге келеді. Flask минималистік, ал Jinja — үлгілер тілі.

5. Django-дағы миграция деген не?

makemigrations командасы осындай файлды жасайды, ал migrate оны дерекқорға қолданады.

6. Пайдаланушыдан келген мәнді SQL-ға қалай дұрыс беру керек?

Параметрлер SQL-инъекциялардан қорғайды. Жолға қою сұраудың өзін өзгертуге мүмкіндік береді.

7. Jinja үлгісіндегі {{ name }} не істейді?

Автоэкрандау XSS-тен қорғайды. Оны |safe сүзгісі өшіреді.

8. Форма сәтті жіберілгеннен кейін неге қайта бағыттау жасау керек?

Бұл тәсіл Post/Redirect/Get деп аталады.

9. Пайдаланушылардың құпиясөздерін қалай сақтау керек?

Хеш кері қайтарылмайды, ал тұз бен баяулату іріктеуді қиындатады. md5 сияқты жылдам хештер құпиясөзге жарамайды.

10. Формадағы CSRF токені неден қорғайды?

Бөгде сайт құпия токенді білмейді, сондықтан оның сұрауы қабылданбайды.

11. Жазба сәтті жасалғаннан кейін қай жауап коды сәйкес келеді?

201 Created жаңа ресурстың жасалғанын білдіреді.

12. REST API-да жазбаны әдетте қай HTTP әдісі жояды?

GET тек деректерді оқиды және ештеңені өзгертпеуі керек.

13. Flask-та app.test_client() не істейді?

Сондықтан тесттер жылдам жұмыс істейді және серверді іске қосуды қажет етпейді.

14. git commit командасы не істейді?

Кодты GitHub-қа git push жібереді.

15. Ашық серверде нені қалдыруға болмайды?

Жөндеу режимінде келушілер баптаулар мен код үзінділерін көреді, ал ашылған кілт сессияларды жасауға мүмкіндік береді.

Сертификатты әрқашан «Менің прогресім» бетінде қайта ашуға болады.
