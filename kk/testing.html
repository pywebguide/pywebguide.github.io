Басты бет / Тесттер

Кодты бұзбай қалай өзгертуге болады

Тест — сіздің бағдарламаңызды тексеретін шағын бағдарлама. Қолмен басып шығуға тура келетін нәрсені ол бірнеше секундта табады.

Тест қалай құрылған

Кез келген тест дерлік үш бөліктен тұрады: деректерді дайындау, әрекетті орындау, нәтижені тексеру.

assert арқылы ең қарапайым тексерістер 
def add_vat(price, rate=0.12):
    return round(price * (1 + rate), 2)

def test_add_vat():
    assert add_vat(100) == 112.0

def test_custom_rate():
    assert add_vat(200, rate=0.2) == 240.0

test_add_vat()
test_custom_rate()
print("Все тесты прошли")

Мысалдағы күтілетін мәнді өзгертіп, қайта іске қосыңыз: құлаған тесттің қалай көрінетінін көресіз.

pytest

Python-дағы ең танымал тест кітапханасы. Ол test_*.py файлдарын және test_* функцияларын өзі табады.

Терминал 
pip install pytest
pytest
pytest -k vat
pytest -x
test_prices.py 
import pytest

from prices import add_vat

@pytest.mark.parametrize("price, expected", [
    (100, 112.0),
    (0, 0.0),
    (19.99, 22.39),
])
def test_add_vat(price, expected):
    assert add_vat(price) == expected

def test_negative_price():
    with pytest.raises(ValueError):
        add_vat(-1)

parametrize бір тестті әртүрлі деректермен іске қосады. raises кодтың қате туралы дұрыс хабарлайтынын тексереді. Екінші тестте функция теріс бағаны өзі қабылдамауы керек.

Flask тесттері

Тесттік клиент қосымшаға серверсіз және браузерсіз сұрау жібереді.

Flask: бет пен API-ды тексеру 
from flask import Flask

app = Flask(__name__)

@app.get("/")
def home():
    return "Главная"

@app.get("/api/ping")
def ping():
    return {"status": "ok"}

def test_home():
    response = app.test_client().get("/")
    assert response.status_code == 200
    assert "Главная" in response.text

def test_ping():
    assert app.test_client().get("/api/ping").json == {"status": "ok"}

def test_unknown_page():
    assert app.test_client().get("/nope").status_code == 404

test_home()
test_ping()
test_unknown_page()
print("Все тесты прошли")

Нақты жобада бұл функциялар test_app.py файлында жатады, ал оларды pytest командасы іске қосады.

Django тесттері

Django бөлек уақытша дерекқор жасайды, сондықтан нақты деректер зардап шекпейді.

tasks/tests.py 
from django.test import TestCase
from django.urls import reverse

from .models import Task

class TaskTests(TestCase):
    def test_list_shows_task(self):
        Task.objects.create(title="Проверить тесты")
        response = self.client.get(reverse("index"))
        self.assertEqual(response.status_code, 200)
        self.assertContains(response, "Проверить тесты")

    def test_add_task(self):
        response = self.client.post(reverse("index"), {"title": "Новая"})
        self.assertRedirects(response, reverse("index"))
        self.assertEqual(Task.objects.count(), 1)
Терминал 
python manage.py test
python manage.py test tasks

Алдымен нені тестілеу керек

Мақсат — жүз пайыз қамту емес, маңызды нәрсені қорғау.

Тексерген жөн

  • Негізгі сценарий: құру, өзгерту, жою
  • Қате және бос деректер
  • Қол жеткізу: бөтен деректер және кірусіз беттер
  • Табылған әр қате: алдымен тест, содан кейін түзету

Тексермеуге болады

  • Фреймворктің өз коды
  • Логикасы жоқ қарапайым баптаулар
  • Беттегі элементтердің дәл орналасуы
