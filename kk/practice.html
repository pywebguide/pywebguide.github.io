Басты бет / Есептер

Автоматты тексерілетін есептер

Шешіміңізді жазып, «Тексеру» батырмасын басыңыз. Код браузерде орындалып, жасырын тесттерден өтеді. Тест өтпесе, ол нені тексергенін, не күтілгенін және не шыққанын көресіз. Тығырыққа тірелсеңіз — кеңесті ашыңыз. Шешілген есептер осы браузерде есте сақталады.

Сіздің нәтижеңіз

Алғашқы тексеру Python-ды жүктейді: шамамен 5 МБ, бұл бірнеше секундқа созылады.

Python негіздері

Функциялар, жолдар және сөздіктер: кез келген сұрау өңдегіші осыларға сүйенеді.

1. Сәлемдесу

Деңгейі: Жеңіл

greet(name) функциясын жазыңыз, ол Сәлем, Есім! жолын қайтарсын. Есімнің айналасындағы артық бос орындарды алып тастау керек. Есім бос болса, Сәлем, қонақ! қайтарыңыз.

  1. Кеңес 1. Мәтінді айнымалымен f-жол арқылы біріктіру оңай: f"Сәлем, {name}!".
  2. Кеңес 2. Шеттердегі бос орындарды name.strip() алып тастайды.
  3. Кеңес 3. Шартта бос жол жалған болып саналады: есім бос болса, name or 'қонақ' «қонақ» қайтарады.
Шешімін көрсету
def greet(name):
    name = name.strip()
    return f"Сәлем, {name or 'қонақ'}!"

2. Сөздерді санау

Деңгейі: Жеңіл

count_words(text) функциясын жазыңыз: кілті кіші әріппен жазылған сөз, ал мәні оның неше рет кездескені болатын сөздікті қайтарыңыз.

  1. Кеңес 1. Бос сөздіктен counts = {} бастап, сөздерді циклмен аралап шығыңыз.
  2. Кеңес 2. text.lower().split() мәтінді кіші әріпке айналдырып, кез келген бос орын мен жол ауыстыру бойынша бөледі.
  3. Кеңес 3. counts.get(word, 0) + 1 сөз сөздікте әлі жоқ болса да санауышты арттырады.
Шешімін көрсету
def count_words(text):
    counts = {}
    for word in text.lower().split():
        counts[word] = counts.get(word, 0) + 1
    return counts

3. Сенімді құпиясөз

Деңгейі: Жеңіл

is_strong(password) функциясын жазыңыз. Құпиясөзде кемінде 8 таңба, кемінде бір цифр және кемінде бір әріп болса, ол сенімді. True немесе False қайтарыңыз.

  1. Кеңес 1. Жолдың ұзындығын len(password) береді.
  2. Кеңес 2. Құпиясөзде цифр болса, any(ch.isdigit() for ch in password) True қайтарады.
  3. Кеңес 3. Әріптер үшін ch.isalpha() бар. Үш шартты and арқылы біріктіріңіз.
Шешімін көрсету
def is_strong(password):
    has_digit = any(ch.isdigit() for ch in password)
    has_letter = any(ch.isalpha() for ch in password)
    return len(password) >= 8 and has_digit and has_letter

4. Тақырыптан мекенжай жасау

Деңгейі: Орташа

Сайттар мақала тақырыбын мекенжайдың бір бөлігіне айналдырады: Менің алғашқы сайтым → menin-algashky-saytym. Латын әріптеріне арналған slugify(title) функциясын жазыңыз: әріптер мен цифрларды кіші әріппен қалдырыңыз, қалғанының бәрін сызықшамен ауыстырыңыз. Қатар тұрған бірнеше сызықшаны біреуге біріктіріп, шеттердегі сызықшаларды алып тастаңыз.

  1. Кеңес 1. title.lower() таңбаларын аралаңыз: әріп немесе цифр (ch.isalnum()) қалады, қалғаны "-" болады.
  2. Кеңес 2. Бөліктерді артық сызықшасыз біріктіруге split("-") кейінгі бос емес бөліктер бойынша "-".join(...) көмектеседі.
  3. Кеңес 3. Егер re модулімен жазсаңыз: re.sub(r"[^a-z0-9]+", "-", text).strip("-").
Шешімін көрсету
def slugify(title):
    chars = [ch if ch.isalnum() else "-" for ch in title.lower()]
    parts = "".join(chars).split("-")
    return "-".join(part for part in parts if part)

5. Сатып алулар қосындысы

Деңгейі: Жеңіл

total(prices) функциясын жазыңыз: ол бағалар тізімін алып, олардың қосындысын қайтарады. Бос тізім үшін 0 қайтарыңыз.

  1. Кеңес 1. result = 0 айнымалысын жасап, for циклінде әр бағаны оған қосыңыз.
  2. Кеңес 2. Қысқа жол: кірістірілген sum(prices) функциясы дәл соны істейді.
Шешімін көрсету
def total(prices):
    result = 0
    for price in prices:
        result += price
    return result

6. Тек жұп сандар

Деңгейі: Жеңіл

only_even(numbers) функциясын жазыңыз: тек жұп сандар сол ретпен қалған жаңа тізімді қайтарыңыз.

  1. Кеңес 1. 2-ге бөлгендегі қалдық нөлге тең болса, сан жұп: n % 2 == 0.
  2. Кеңес 2. Бос тізімнен бастап, сәйкес сандарды .append(n) арқылы қосыңыз.
Шешімін көрсету
def only_even(numbers):
    return [n for n in numbers if n % 2 == 0]

7. Қысқа аңдатпа

Деңгейі: Жеңіл

truncate(text, limit) функциясын жазыңыз. Мәтін limit таңбадан ұзын болмаса, оны сол күйінде қайтарыңыз. Әйтпесе алғашқы limit таңбаны және үш нүктені ... қайтарыңыз.

  1. Кеңес 1. Жолдың алғашқы таңбаларын кесінді береді: text[:limit].
  2. Кеңес 2. Алдымен ұзындықты тексеріңіз: if len(text) <= limit.
Шешімін көрсету
def truncate(text, limit):
    if len(text) <= limit:
        return text
    return text[:limit] + "..."

8. Ең ұзын сөз

Деңгейі: Орташа

longest(words) функциясын жазыңыз: тізімдегі ең ұзын сөзді қайтарыңыз. Ондай сөз бірнешеу болса, біріншісін қайтарыңыз. Бос тізім үшін бос жол қайтарыңыз.

  1. Кеңес 1. Ең жақсы сөзді best = "" айнымалысында сақтап, ұзындықтарды len() арқылы салыстырыңыз.
  2. Кеңес 2. Ұзындығы тең болғанда бірінші сөз қалуы үшін қатаң салыстырыңыз: len(word) > len(best).
Шешімін көрсету
def longest(words):
    best = ""
    for word in words:
        if len(word) > len(best):
            best = word
    return best

9. Қайталаусыз

Деңгейі: Орташа

unique(items) функциясын жазыңыз: қайталанбайтын элементтер тізімін қайтарыңыз. Алғашқы кездесу реті сақталуы керек.

  1. Кеңес 1. Элементтің тізімде бар-жоғын item not in result арқылы тексеруге болады.
  2. Кеңес 2. set() қайталауларды жояды, бірақ рет өзгеруі мүмкін, сондықтан мұнда цикл керек.
Шешімін көрсету
def unique(items):
    result = []
    for item in items:
        if item not in result:
            result.append(item)
    return result

10. Инициалдар

Деңгейі: Орташа

initials(full_name) функциясын жазыңыз: аты мен тегінен инициалдар жасаңыз. Aru Bekova мәнінен A. B. шығуы керек. Әріптерді бас әріпке айналдырыңыз, артық бос орындарды есепке алмаңыз.

  1. Кеңес 1. full_name.split() жолды сөздерге бөледі және артық бос орындарды өзі алып тастайды.
  2. Кеңес 2. Сөздің бірінші әрпі — part[0], оны .upper() бас әріпке айналдырады. Бөліктерді " ".join(...) арқылы жинаңыз.
Шешімін көрсету
def initials(full_name):
    parts = full_name.split()
    return " ".join(part[0].upper() + "." for part in parts)

11. Мекенжайды талдау

Деңгейі: Орташа

parse_query(query) функциясын жазыңыз. Ол a=1&b=2 жолын {"a": "1", "b": "2"} сөздігіне айналдырады. = белгісі жоқ бөліктерді өткізіп жіберіңіз. Мәннің ішінде = болуы мүмкін.

  1. Кеңес 1. Алдымен жолды жұптарға бөліңіз: query.split("&").
  2. Кеңес 2. = жоқ жұпты if "=" in part тексерісімен өткізіп жіберіңіз.
  3. Кеңес 3. part.split("=", 1) тек бірінші = белгісі бойынша бөледі, қалғандары мәнде қалады.
Шешімін көрсету
def parse_query(query):
    result = {}
    for part in query.split("&"):
        if "=" in part:
            key, value = part.split("=", 1)
            result[key] = value
    return result

12. Қарапайым маршрутизатор

Деңгейі: Орташа

handle(method, path) функциясын аяқтаңыз. Ол ROUTES сөздігінен өңдегішті іздеп, «код, мәтін» жұбын қайтарады. Мекенжай жоқ болса, (404, "Not Found") қайтарыңыз. Мекенжай бар, бірақ әдіс сәйкес келмесе, (405, "Method Not Allowed") қайтарыңыз.

  1. Кеңес 1. Ретімен тексеріңіз: алдымен мекенжай бар ма, содан кейін әдіс бар ма.
  2. Кеңес 2. path not in ROUTES мұндай мекенжайдың жоқ екенін білдіреді: бұл 404.
  3. Кеңес 3. Мекенжайдың әдістері ROUTES[path] ішінде жатыр. Әдіс онда болмаса — 405, әйтпесе 200 мен мәтінді қайтарыңыз.
Шешімін көрсету
ROUTES = {
    "/": {"GET": "Басты бет"},
    "/tasks": {"GET": "Тапсырмалар тізімі", "POST": "Тапсырма жасалды"},
}

def handle(method, path):
    if path not in ROUTES:
        return 404, "Not Found"
    if method not in ROUTES[path]:
        return 405, "Method Not Allowed"
    return 200, ROUTES[path][method]

13. Форма деректерін тексеру

Деңгейі: Күрделі

validate_user(data) функциясын жазыңыз. Функция сөздікті қабылдап, қателер тізімін қайтарады. name өрісі міндетті, age өрісі 1-ден 120-ға дейінгі бүтін сан болуы керек. Қате мәтіндері: "name" және "age". Бәрі дұрыс болса, бос тізім қайтарыңыз.

  1. Кеңес 1. Өріс болмауы мүмкін: data.get("name", "") қатенің орнына бос жол қайтарады.
  2. Кеңес 2. Бүтін санды isinstance(age, int), ауқымды 1 <= age <= 120 тексереді.
  3. Кеңес 3. Python-да True да int болып саналады. Оны бөлек сүзіп тастаңыз: isinstance(age, bool).
Шешімін көрсету
def validate_user(data):
    errors = []
    if not str(data.get("name", "")).strip():
        errors.append("name")
    age = data.get("age")
    if not isinstance(age, int) or isinstance(age, bool) or not 1 <= age <= 120:
        errors.append("age")
    return errors

14. JSON түріндегі жауап

Деңгейі: Орташа

tasks_json(tasks) функциясын жазыңыз. Функция сөздіктер тізімін алып, тек done мәні False болатын тапсырмалары бар JSON жолын қайтарады. Кирилл әріптері оқылатын күйде қалуы керек. Импорт бар.

  1. Кеңес 1. Орындалмаған тапсырмаларды іріктеңіз: [task for task in tasks if not task["done"]].
  2. Кеңес 2. Тізімді JSON жолына json.dumps(...) функциясы айналдырады.
  3. Кеңес 3. Кирилл әріптері \u041a сияқты кодтарға айналмауы үшін ensure_ascii=False қосыңыз.
Шешімін көрсету
import json

def tasks_json(tasks):
    active = [task for task in tasks if not task["done"]]
    return json.dumps(active, ensure_ascii=False)

15. Өз үлгіңіз

Деңгейі: Орташа

Үлгі — бос орындары бар мәтін. render(template, data) функциясын жазыңыз: ол әр {{ атау }} бос орнын data сөздігіндегі мәнмен ауыстырады. Жақшаның ішінде бос орын болуы да, болмауы да мүмкін. Сөздікте кілт жоқ болса, бос жол қойыңыз.

  1. Кеңес 1. Барлық бос орындарды табуға r"\{\{\s*(\w+)\s*\}\}" тұрақты өрнегі көмектеседі.
  2. Кеңес 2. re.sub(үлгі, функция, мәтін) әр табылған бос орын үшін функцияны шақырып, оның жауабын қояды.
  3. Кеңес 3. Функцияның ішінде бос орынның атауы match.group(1) ішінде, ал мәнді str(data.get(атау, "")) алады.
Шешімін көрсету
import re

def render(template, data):
    def value(match):
        return str(data.get(match.group(1), ""))
    return re.sub(r"\{\{\s*(\w+)\s*\}\}", value, template)

16. Тізім беттері

Деңгейі: Орташа

Ұзын тізімді бөліп-бөліп көрсетеді. paginate(items, page, per_page) функциясын жазыңыз: page нөмірлі беттің элементтерін қайтарыңыз (нөмірлеу 1-ден басталады). Мұндай нөмірлі бет болмаса немесе нөмір 1-ден кіші болса, бос тізім қайтарыңыз.

  1. Кеңес 1. Беттің бірінші элементі (page - 1) * per_page орнында тұр.
  2. Кеңес 2. Элементтер аз болса, items[start:start + per_page] кесіндісі өзі қысқарады.
  3. Кеңес 3. 1-ден кіші бет нөмірін бөлек тексеріңіз, әйтпесе теріс кесінді артық нәрсе қайтарады.
Шешімін көрсету
def paginate(items, page, per_page):
    if page < 1:
        return []
    start = (page - 1) * per_page
    return items[start:start + per_page]

17. Күй мәтіні

Деңгейі: Жеңіл

status_text(code) функциясын жазыңыз: жауап коды бойынша оның атауын қайтарыңыз. 200 — OK, 201 — Created, 404 — Not Found, 500 — Internal Server Error. Қалған кодтар үшін Unknown қайтарыңыз.

  1. Кеңес 1. Жұптарды сөздікте сақтаған ыңғайлы: {200: "OK", 404: "Not Found"}.
  2. Кеңес 2. Код сөздікте болмаса, names.get(code, "Unknown") қосалқы мәнді қайтарады.
Шешімін көрсету
def status_text(code):
    names = {200: "OK", 201: "Created", 404: "Not Found", 500: "Internal Server Error"}
    return names.get(code, "Unknown")

18. Файл типі

Деңгейі: Орташа

Сервер браузерге файл типін Content-Type тақырыбында хабарлайды. content_type(filename) функциясын жазыңыз: .html үшін text/html, .css үшін text/css, .js үшін text/javascript, .json үшін application/json, қалғандары үшін application/octet-stream қайтарыңыз. Атаудағы әріптердің регистрі маңызды емес.

  1. Кеңес 1. Кеңейтім — соңғы нүктеден кейінгі бөлік: filename.rsplit(".", 1)[-1].
  2. Кеңес 2. Атауды .lower() арқылы кіші әріпке келтіріп, типті сөздіктен .get() арқылы қосалқы мәнмен алыңыз.
Шешімін көрсету
def content_type(filename):
    types = {"html": "text/html", "css": "text/css", "js": "text/javascript", "json": "application/json"}
    extension = filename.lower().rsplit(".", 1)[-1]
    return types.get(extension, "application/octet-stream")

19. Параметрлі мекенжай

Деңгейі: Орташа

build_url(path, params) функциясын жазыңыз: жолға сөздіктегі параметрлерді қосыңыз. "/search" пен {"q": "flask", "page": 2} мәндерінен /search?q=flask&page=2 шығуы керек. Сөздік бос болса, жолды сұрақ белгісінсіз қайтарыңыз.

  1. Кеңес 1. Кілт пен мән жұптарын params.items() береді. Әрқайсысын f"{key}={value}" жолына айналдырыңыз.
  2. Кеңес 2. Жұптарды "&".join(pairs) арқылы біріктіріп, жолға ? белгісінен кейін қосыңыз.
Шешімін көрсету
def build_url(path, params):
    if not params:
        return path
    pairs = [f"{key}={value}" for key, value in params.items()]
    return path + "?" + "&".join(pairs)

20. Cookie талдау

Деңгейі: Орташа

parse_cookie(header) функциясын жазыңыз: theme=dark; lang=kk тақырып жолын {"theme": "dark", "lang": "kk"} сөздігіне айналдырыңыз. Бос жол үшін бос сөздік қайтарыңыз. Мәннің ішінде = белгісі кездесуі мүмкін.

  1. Кеңес 1. Алдымен жолды ; бойынша бөліңіз, содан кейін әр бөліктің бос орындарын .strip() арқылы алып тастаңыз.
  2. Кеңес 2. part.split("=", 1) тек бірінші теңдік белгісі бойынша бөледі, сондықтан a=b мәні бүтін қалады.
Шешімін көрсету
def parse_cookie(header):
    result = {}
    for part in header.split(";"):
        if "=" in part:
            key, value = part.strip().split("=", 1)
            result[key] = value
    return result

26. Поштаға ұқсай ма

Деңгейі: Күрделі

is_email(value) функциясын жазыңыз: пошта мекенжайын шамамен тексеру. Мекенжайда бос орын жоқ, дәл бір @ белгісі бар, оның алдында кемінде бір таңба бар, ал одан кейін басында да, соңында да тұрмаған нүкте бар.

  1. Кеңес 1. Таңбаның неше рет кездесетінін value.count("@") санайды.
  2. Кеңес 2. Мекенжайды екі бөлікке бөліңіз: name, domain = value.split("@"), және әрқайсысын бөлек тексеріңіз.
Шешімін көрсету
def is_email(value):
    if " " in value or value.count("@") != 1:
        return False
    name, domain = value.split("@")
    if not name or "." not in domain:
        return False
    return not domain.startswith(".") and not domain.endswith(".")

Деңгейі: Орташа

GET /search жасаңыз. Мекенжайда бос емес q параметрі болса, {"q": мәні} қайтарыңыз. Параметр жоқ немесе тек бос орындардан тұрса, 400 кодымен {"error": "q"} қайтарыңыз.

  1. Кеңес 1. Параметрді request.args.get("q", "") оқиды: параметр болмаса, екінші мән қайтарылады.
  2. Кеңес 2. Жауап коды екінші мән ретінде қойылады: return {"error": "q"}, 400.
Шешімін көрсету
from flask import Flask, request

app = Flask(__name__)

@app.get("/search")
def search():
    q = request.args.get("q", "").strip()
    if not q:
        return {"error": "q"}, 400
    return {"q": q}

40. Нөмір бойынша жою

Деңгейі: Күрделі

DELETE /tasks/<int:task_id> жасаңыз. Тапсырма TASKS сөздігінде болса, оны жойып, 204 кодымен бос жауап қайтарыңыз. Болмаса, 404 кодымен {"error": "not found"} қайтарыңыз.

  1. Кеңес 1. Жою маршруты @app.delete(...) арқылы жарияланады. Сөздіктен элементті del TASKS[task_id] алып тастайды.
  2. Кеңес 2. Коды бар бос жауап: return "", 204.
Шешімін көрсету
from flask import Flask

app = Flask(__name__)
TASKS = {1: "Buy bread", 2: "Learn Flask"}

@app.delete("/tasks/<int:task_id>")
def delete_task(task_id):
    if task_id not in TASKS:
        return {"error": "not found"}, 404
    del TASKS[task_id]
    return "", 204
