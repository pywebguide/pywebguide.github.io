Құпиялылық саясаты

Қысқаша: сайттың өз дерекқоры жоқ. Форма арқылы жіберілген хабарламалар GitHub-та жарияланады және оларды бәрі көреді, ал хостинг келушілердің IP-мекенжайларын жазады. Жеке аккаунты бар нұсқаның сервері бар, ол не сақтайтыны төменде сипатталған.

Сайтқа кім жауап береді

PyWeb Guide — оқу жобасы. Авторы: Жангужин Е. Е. Онымен GitHub-тағы Issues бөлімі арқылы байланысуға болады; ондағы хабарламаларды бәрі көреді, сондықтан оларда жеке деректерді көрсетпеңіз. GitHub аккаунты болмаса, тікелей жазуға болады: мұндай хатты тек автор көреді.

Браузеріңізде не сақталады

Сайт localStorage — браузеріңіздің қоймасын пайдаланады. Бұл жазбалар серверге жіберілмейді, автор оларды көрмейді:

  • pyweb_messages — «Байланыс» бетіндегі формадан жіберілген хабарламалардың көшірмелері;
  • pyweb_progress — оқудың белгіленген қадамдары;
  • pyweb_theme — таңдалған безендіру тақырыбы;
  • pyweb_tasks және pyweb_task_* — шешілген есептер және шешімдердің жобалары;
  • pyweb_playground — құмсалғыштағы код жобасы;
  • pyweb_exam — қорытынды тесттің ең жақсы нәтижесі;
  • pyweb_os — командалары бар қойындыларда қай жүйені (Windows немесе macOS пен Linux) таңдағаныңыз.

Хабарламаларды «Байланыс» бетіндегі «Сақталған хабарламаларды тазалау» батырмасы жояды. Қалғанының бәрі, соның ішінде кэш те, браузер баптауларында осы сайттың деректерін тазалау арқылы жойылады.

Сонымен қатар браузер сайт интернетсіз әрі жылдамырақ ашылуы үшін беттердің, стильдердің, скриптердің және Python файлдарының көшірмелерін өз кэшінде (Cache Storage) сақтайды. Бұл сайттың кәдімгі файлдары, оларда сіздің деректеріңіз жоқ.

«Менің прогресім» бетіндегі прогресс файлы тікелей браузерде жасалады және тек белгілерді қамтиды. Сертификаттағы есім сақталмайды: басып шығаратын парақ браузерде жиналады және ешқайда жіберілмейді.

Форманы жібергенде не болады

Форма есіміңіз бен мәтініңіз көрсетілген GitHub Issues бөлімінде жазба жасау бетін ашады. GitHub-та жасауды растамайынша, ештеңе жарияланбайды. Содан кейін хабарлама мен GitHub профиліңізді бәрі көреді, ал оларды GitHub өз ережелері бойынша өңдейді.

Хостинг не жазады

Сайт GitHub Pages-те орналасқан. GitHub деректері бойынша, сайтқа кіргенде келушінің IP-мекенжайы қауіпсіздік мақсатында жазылып, сақталады. Дереккөз — GitHub Pages анықтамасы, толығырақ — GitHub құпиялылық саясатында.

Аккаунты бар нұсқа

Курсты pywebguide.pythonanywhere.com мекенжайындағы аккаунты бар жеке нұсқада да өтуге болады. Аккаунт тек прогресті құрылғылар арасында тасымалдау үшін керек: онсыз да курс дәл солай жұмыс істейді. Бұл нұсқа өз серверінде мыналарды сақтайды:

  • тіркелсеңіз, логин мен құпиясөз. Құпиясөз тек хеш түрінде сақталады, оны ешкім, тіпті автор да оқи алмайды;
  • прогресіңіз: белгіленген қадамдар, шешілген есептер және қорытынды тесттің ең жақсы нәтижесі. Олар аккаунтқа кірген кезде ғана сақталады;
  • «Байланыс» бетіндегі форма хабарламалары: аты, мәтіні, күні және аккаунтқа кірген болсаңыз — аккаунт. Оларды тек автор көреді, олар жарияланбайды;
  • сәтсіз кіру әрекеттері: логин, IP-мекенжай және браузер. Бұл құпиясөзді іріктеуден қорғау: бес қатеден кейін кіру бір сағатқа бұғатталады, ал сәтті кіргеннен кейін санауыш нөлденеді. Сәтті кірулер жазылмайды.

Форма хабарламаларының санын шектеу үшін сервер бір сағат бойы сіздің IP-мекенжайыңыздан қанша хабарлама келгенін есте сақтайды. Бұл сан дерекқорда емес, тек сервер жадында сақталады.

Бұл нұсқа екі техникалық cookie орнатады: кіруді есте сақтау үшін sessionid (екі аптаға дейін) және формаларды қолдан жасаудан қорғау үшін csrftoken. Жарнамалық және бақылайтын cookie жоқ.

Сервер PythonAnywhere хостингінде орналасқан, оның серверлері АҚШ-та. Кез келген хостинг сияқты, ол журналдарға келушілердің IP-мекенжайы мен браузерін жазады.

Аккаунтты прогреспен бірге немесе өз хабарламаларыңызды жою үшін аккаунтқа кіріп, бұл нұсқаның «Байланыс» бетіндегі форма арқылы жазыңыз. Автор деректерді жояды.

Python-ды браузерде іске қосу

Кодты іске қосу немесе тексеру батырмасын басқаннан кейін ғана браузер Python-ды (Pyodide) jsDelivr сервисінен, ал Flask мысалдары үшін PyPI-дан пакеттерді де жүктейді. Бұл сервистер кез келген сайт сияқты IP-мекенжайыңызды және браузер деректерін алады. Кодтың өзі сіздің құрылғыңызда орындалады және ешқайда жіберілмейді. Сертификаттағы есім де браузерде қалады және сақталмайды.

Cookies және кіру статистикасы

Сайт cookies орнатпайды және жарнама көрсетпейді. Аккаунты бар нұсқаның техникалық cookie-лері жоғарыда сипатталған.

Қандай беттерді оқитынын және курсты қай жерде тастап кететінін түсіну үшін сайт кірулерді GoatCounter арқылы санайды. Ол cookies пайдаланбайды және келесі кірулерде сізді танымайды. Ашылған беттің мекенжайы мен тақырыбы, сіз келген сайт, IP-мекенжай бойынша ел, экран өлшемі, браузер және операциялық жүйе есепке алынады. IP-мекенжайдың өзі сақталмайды. Толығырақ — GoatCounter саясатында.

Сайт оқу оқиғаларын да дәл осылай санайды: сабақ немесе қадам өтілді деп белгіленді, код алғаш рет іске қосылды, есеп шешілді. Оларда есімдер де, жауаптар да жоқ, тек бет ашылғандағыдай мәліметтер жіберіледі. Оқиғаны екі рет санамау үшін жіберілген оқиғалар тізімі сіздің браузеріңізде сақталады (pyweb_events кілті).

Браузерде бақылауға тыйым салу немесе жарнама бұғаттағышы қосулы болса, кіру есепке алынбауы мүмкін, ал сайт бұдан бұрынғыдай жұмыс істейді.

Сайт бойынша іздеу

Іздеу сіздің браузеріңізде жұмыс істейді: индекс осы сайттан жүктеледі, ал сұраулар ешқайда жіберілмейді.

Сыртқы сілтемелер

Сайтта құжаттамаға және басқа сыртқы ресурстарға сілтемелер бар. Өткеннен кейін сол ресурстардың ережелері қолданылады.
