Басты бет / Python туралы

Сайт қалай жұмыс істейді

Қарапайым синтаксис, қуатты экожүйе және жетілген фреймворктер Python-ды веб-әзірлеуге кірудің ыңғайлы тіліне айналдырады.

Енді ғана бастап жатырсыз ба? Алдымен «Нөлден» сабақтарын өтіңіз, ал бейтаныс сөздерді сөздіктен қараңыз.

Backend-әзірлеу деген не

Backend — қосымшаның серверде жұмыс істейтін бөлігі: ол сұрауларды қабылдайды, логиканы өңдейді, дерекқорға жүгінеді және жауап жібереді.

Сұрауларды өңдеу

Фреймворк HTTP-сұрауды қабылдап, оны қай код өңдеуі керегін анықтайды.

Дерекқор

Қосымша пайдаланушыларды, тауарларды, мақалаларды және басқа деректерді ORM немесе SQL арқылы оқиды және сақтайды.

Жауапты қалыптастыру

Сервер HTML, JSON немесе файл қайтарады — соңында пайдаланушы көретін нәрсе осы.

Логика және қауіпсіздік

Деректерді тексеру, қол жеткізу құқықтары, қателерді өңдеу және дұрыс жауап дайындау.

Python серверде қандай міндеттерді шешеді

Сервер сұрауларды қабылдайды, деректермен жұмыс істейді және жауап қайтарады. Ол үшін Python-дағы код мыналарды істейді.

  • Бет мекенжайын қажетті функциямен сәйкестендіреді (маршруттау).
  • Пайдаланушы жіберген деректерді, мысалы формадан келгенін, тексереді.
  • Дерекқорға деректерді жазады және одан оқиды.
  • Қол жеткізу құқықтарын және пайдаланушылардың кіруін тексереді.
  • HTML-беттерді үлгілерден құрастырады.
  • Басқа бағдарламаларға деректерді JSON форматында береді.

Пайдаланушының сұрауы қалай өтеді

Басудан сервер жауабына дейінгі жеңілдетілген тізбек.

1

Браузер

Пайдаланушы бетті ашады немесе форманы жібереді.

2

HTTP-сұрау

Сұрау серверге кетеді: әдіс, мекенжай және деректер.

3

Фреймворк

Django немесе Flask қажетті маршрут пен өңдегішті табады.

4

Логика және ДҚ

Код деректерді тексеріп, ақпаратты оқиды немесе сақтайды.

5

Жауап

Сервер бетті, JSON-ды немесе қатені қайтарады.

Сұраудың жолы қадам бойынша

«Тапсырма қосу» батырмасын басқаннан кейін секундтың бір бөлігінде не болады.

БраузерHTML, CSS, JS
Веб-серверnginx, WSGI
ҚосымшаFlask, Django
ДерекқорSQLite, PostgreSQL
  1. Браузер сұрау жібереді. Форма тақырыптары, cookie және форма деректері бар POST /tasks сұрауына айналады.
  2. Веб-сервер оны қабылдайды. Ол HTTPS-байланысты аяқтайды, статикалық файлдарды өзі береді, ал қалғанын WSGI арқылы қосымшаға жібереді.
  3. Фреймворк маршрутты табады. /tasks мекенжайы мен POST әдісі сіздің функцияңызды көрсетеді, ол сұрау объектісін алады.
  4. Функция деректерді тексереді. Пайдаланушы кірді ме, CSRF токені бар ма, атауы бос емес пе. Қате болса, бірден 400 немесе 403 жауабы қайтарылады.
  5. Дерекқор жазбаны сақтайды. Параметрлері бар INSERT INTO tasks ... орындалады, дерекқор жаңа жолдың нөмірін қайтарады.
  6. Қосымша жауап дайындайды. Бұл тізімге қайта бағыттау, үлгіден алынған HTML немесе API үшін JSON.
  7. Веб-сервер жауапты жібереді. Жауаптың коды, тақырыптары және денесі желі арқылы кері кетеді.
  8. Браузер нәтижені көрсетеді. Ол қайта бағыттауды орындайды, бетті құрады және CSS, JavaScript пен суреттерді жүктейді.

Python-ның вебтегі күшті жақтары

Тілдің серверлік әзірлеу үшін танымал таңдау болып қала беруінің негізгі себептері.

Python неліктен веб-әзірлеуді бастауға жақсы келеді
Ерекшелігі Неліктен маңызды
Оқуға оңай синтаксис Кодты командада қолдау және талдау оңайырақ, жаңадан бастағандарға кіру жеңіл.
Дайын фреймворктер Django мен Flask серверлік әзірлеудің типтік міндеттерінің көбін шешеді.
Кітапханалар экожүйесі Дерекқорды, аутентификацияны, API құралдарын және аналитиканы қосу оңай.
Деректерді талдаумен байланыс Бір тілді веб үшін де, автоматтандыру мен деректерді талдау үшін де қолдануға болады.

Код мысалдары

Flask-тағы ең қарапайым сервер және SQLite-пен негізгі жұмыс — кірудің екі маңызды нүктесі.

Flask: ең қарапайым сервер 
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Привет, это Python-сервер!"

if __name__ == "__main__":
    app.run()
SQLite: деректермен негізгі жұмыс 
import sqlite3

conn = sqlite3.connect("app.db")
cursor = conn.cursor()

cursor.execute(
    "CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT)"
)

cursor.execute(
    "INSERT INTO users (name) VALUES ('Айгерим')"
)

conn.commit()
conn.close()

Маңызды: мысалдар оқу мақсатында, бұл жобада сервер іске қосылмайды. Мұндағы кодты тек оқып, көшіруге болады.

Терминдердің шағын сөздігі

Веб-әзірлеу бойынша материалдарды сенімдірек оқуға көмектесетін ұғымдар.

Backend

Сұрауларды өңдейтін, деректерді сақтайтын және жауап қайтаратын қосымшаның серверлік бөлігі.

Frontend

Сайттың клиенттік бөлігі: интерфейс, батырмалар, формалар және пайдаланушы браузерде көретін нәрсенің бәрі.

HTTP

Браузер мен сервер сұраулар мен жауаптар алмасатын хаттама.

ORM

Дерекқормен SQL-сұрауларды қолмен жазудың орнына объектілер мен код арқылы жұмыс істеуге мүмкіндік беретін құрал.

API

Бір бағдарлама басқа бағдарламадан деректер немесе функциялар ала алатын интерфейс.

SQLite

Оқу және шағын жобаларда жиі қолданылатын жеңіл дерекқор.

Практикалық тексеру тізімі

Осы бөлімді оқығаннан кейін не істеуге болады.

  • Сервердің браузерден айырмашылығын түсіндіру.
  • Қосымшаға дерекқор не үшін қажет екенін түсіну.
  • Flask-та қарапайым серверді іске қосу.
  • Бір маршрут жасап, мәтін қайтару.
  • SQLite-та кесте жасап, оған жазба қосу.
  • Қандай міндеттерді қолмен емес, фреймворкпен шешкен дұрыс екенін салыстыру.

Өзіңізді тексеріңіз

Бөлім бойынша төрт сұрақ. Жауап бергеннен кейін түсіндірме шығады.

1. Сайттың backend бөлігінің коды қайда орындалады?

Backend серверде жұмыс істейді: сұрауды қабылдайды, логиканы орындайды және жауап қайтарады. Браузерде frontend жұмыс істейді — HTML, CSS және JavaScript.

2. Фреймворктегі маршруттау не істейді?

Маршрут мекенжайды (мысалы, / немесе /about) Python функциясымен байланыстырады. Flask-та бұл @app.route декораторы, Django-да — urlpatterns тізімі.

3. Сервер басқа бағдарламаларға деректерді әдетте қандай форматта береді?

JSON — «кілт: мән» мәтіндік форматы, оны JavaScript те, мобильді қосымшалар да оңай оқиды. API осылай жұмыс істейді.

4. Пайдаланушы бетті ашқанда алдымен не болады?

Тізбек браузерден басталады: сұрау → фреймворк маршрутты табады → логика және дерекқор → жауап. Жоғарыдағы «Пайдаланушының сұрауы қалай өтеді» сызбасын қараңыз.
