Python нөлден

Ешқашан бағдарламаламағандарға арналған 13 сабақ. Код тікелей осы бетте іске қосылады: «Іске қосу» батырмасын басып, оны өзгертіп, қайта іске қосыңыз. Қателесу қорқынышты емес, ештеңе бұзылмайды.

Алғаш іске қосқанда браузер Python-ды жүктейді, бұл бірнеше секундқа созылады. Бейтаныс сөздер сөздікте бар (әзірге орыс тілінде).

17 сабақ пен жобаның 0 өтілді

  1. 0-сабақ. Бұл курс қалай құрылған

    Не үшін. Код жазбас бұрын үш нәрсені түсінген пайдалы: бағдарлама деген не, неге Python үйренеміз және осы бетте қалай оқу керек.

    Бағдарлама деген не. Бағдарлама — компьютерге арналған нұсқаулық. Ол рецептке ұқсайды: аспаз қадамдарды ретімен орындайды, алдымен турайды, сосын пісіреді. Компьютер де командаларды кезекпен, жоғарыдан төмен қарай орындайды.

    Неге Python. Python коды ағылшын тіліндегі қарапайым мәтін сияқты оқылады, онда артық белгілер аз. Python-да сайттар жасайды, деректерді өңдейді және іш пыстыратын жұмысты автоматтандырады. Сондықтан оны жиі бірінші тіл ретінде таңдайды.

    Қалай оқу керек. Әр сабақта түсіндірме, мысалдар және тапсырмалар бар. Мысалдың астындағы «Іске қосу» батырмасын басыңыз, сонда Python кодты осы жерде, браузерде орындайды. Кодты қалағаныңызша өзгертуге болады: компьютер бұзылмайды.

    Тексерілетін тапсырмалар. Шешімді жазып, «Тексеру» батырмасын басыңыз. Шықпаса, кеңестерді бір-бірден ашыңыз. Дайын шешім де бар, бірақ алдымен өзіңіз байқап көріңіз.

    Прогресс. «Сабақ өтілді» белгісі осы браузерде сақталады. Таныс емес сөздерді сөздіктен іздеңіз.

    Байқап көріңіз: осы сабақтың екі мысалын да іске қосыңыз. Бұл — нағыз бағдарламалар.

    Жиі сұрақ: бірдеңе орнату керек пе?

    Жоқ. Python алғаш іске қосқанда браузерге өзі жүктеледі, бұл бірнеше секунд алады. Python-ды компьютерге кейінірек, өз жобаңыз үшін орнату керек болады, бұл туралы бөлек сабақ бар.

    Жиі сұрақ: математика мен ағылшын тілін жақсы білу керек пе?

    Жоқ. Мектептегі арифметика жеткілікті. Python-да ағылшын сөздері аз, олардың мағынасын сабақтарда түсіндіреміз.

    Қысқаша:

    • бағдарлама — компьютер кезекпен, жоғарыдан төмен қарай орындайтын командалар;
    • мұнда код тікелей браузерде іске қосылады, ештеңе орнатудың қажеті жоқ;
    • қателесу қорқынышты емес: байқап көріңіз, өзгертіңіз және қайта іске қосыңыз.
    1-мысал. Қадамдық рецепт
    print("1-қадам: кесені аламын")
print("2-қадам: шай құямын")
print("3-қадам: шай ішемін")
    2-мысал. Python санай алады
    print(2 + 2)
print("2 + 2")

    Екінші мысалда бірінші жол есептейді, ал екіншісі мәтінді сол күйінде шығарады: тырнақшадағының бәрін Python есептемейді.

  2. 1-сабақ. Алғашқы бағдарлама

    Не үшін. Кез келген бағдарлама, тіпті үлкен сайт та қарапайым командалардан құралады. Ең маңыздысынан — нәтижені көрсететін командадан бастайық.

    print командасы жақшадағыны экранға шығарады. Мәтін тырнақшаға жазылады: print("Сәлем!"). Сандарды тырнақшасыз жазуға болады: print(2026).

    Реті. Әр команда жаңа жолдан жазылады. Python оларды жоғарыдан төмен қарай орындайды: жоғарыдағысы ертерек шығады.

    Бірнеше мән. Бір print ішінде бірнеше мәнді үтір арқылы тізбелеуге болады. Python олардың арасына бос орынды өзі қояды: print("Маған", 16, "жас") Маған 16 жас деп шығарады.

    Бос жол. Жақшасында ештеңе жоқ print() бос жол шығарады. Шығарылымның бір бөлігін екіншісінен бөлу үшін ыңғайлы.

    Түсіндірмелер. # белгісінен кейінгінің бәрі — адамға арналған жазба. Python оны өткізіп жібереді. Түсіндірмелер кодтың не істейтінін түсіндіруге көмектеседі.

    Байқап көріңіз: тырнақшаға өз атыңызды жазып, «Іске қосу» батырмасын басыңыз. Сосын екі жолдың орнын ауыстырып, шығарылым қалай өзгеретінін қараңыз.

    Жиі қате: тырнақша немесе жақша ұмытылған

    Тырнақшалар мен жақшалар әрқашан жұп болады. print("Сәлем!) деп жазсаңыз, Python мәтіннің соңын таппайды: SyntaxError: unterminated string literal Әр ашатын тырнақша мен жақшаның жабатыны бар екенін тексеріңіз.

    Жиі қате: бас әріппен жазылған Print

    Python бас әріп пен кіші әріпті ажыратады. Ол үшін Print пен print — әртүрлі сөздер, ал біріншісін ол білмейді: NameError: name 'Print' is not defined Python командалары кіші әріппен жазылады.

    Қысқаша:

    • print(...) нәтижені көрсетеді: мәтін тырнақшада, сандар тырнақшасыз;
    • командалар жоғарыдан төмен қарай, әрқайсысы жаңа жолдан орындалады;
    • # түсіндірмені бастайды, ал тырнақшалар мен жақшалар әрқашан жұп болады.
    1-мысал. Алғашқы командалар
    # Бұл түсіндірме: Python оны өткізіп жібереді
print("Сәлем!")
print("Бұл менің алғашқы бағдарламам")
    2-мысал. Бірнеше мән
    print("Менің атым", "Аружан")
print("Маған", 16, "жас")
print()
print("Бағдарламалауды үйреніп жүргеніме:", 2026, "жылдан бері")

    Тапсырма: өзіңізді таныстырыңыз

    Деңгейі: Жеңіл

    Екі жол шығаратын бағдарлама жазыңыз: алдымен Сәлем!, ал оның астында Мен Python үйреніп жүрмін.

    1. 1-кеңес. Әрқайсысы өз жолында тұрған екі print командасы керек.
    2. 2-кеңес. Мәтінді тырнақшаға тапсырмадағыдай дәл жазыңыз: print("Сәлем!").
    Шешімін көрсету
    print("Сәлем!")
print("Мен Python үйреніп жүрмін")

    Күрделірек тапсырма: қателерді табыңыз

    Деңгейі: Орташа

    Бағдарламада үш қате бар, сондықтан ол іске қосылмайды. Бағдарлама Менің атым Ерлан және Маған 16 жас деп шығаратындай етіп оларды түзетіңіз.

    1. 1-кеңес. Бірінші команданың бірінші әрпіне қараңыз.
    2. 2-кеңес. Бірінші жолдағы мәтіннің ашатын тырнақшасы бар. Ал жабатыны ше?
    3. 3-кеңес. print ішіндегі мәндер үтірмен бөлінеді. 16 мен "жас" арасында үтір жоқ.
    Шешімін көрсету
    print("Менің атым Ерлан")
print("Маған", 16, "жас")

  3. 2-сабақ. Сандар: Python — калькулятор

    Не үшін. Сайттар үнемі есептейді: себеттегі бағаны, тест ұпайларын, емтиханға дейін қанша күн қалғанын. Сондықтан алдымен санауды үйренейік.

    Амалдар. Python + қосады, - азайтады, * көбейтеді және / бөледі. Нәтижені бірден шығаруға болады: print(2 + 3).

    Бүтін және бөлшек сандар. Бүтін сандар болады, мысалы 7, және бөлшек сандар, мысалы 7.5. Бөлшек бөлігі үтірмен емес, нүктемен бөлінеді. Қарапайым бөлу / әрқашан бөлшек сан береді: 10 / 2 5.0 болады.

    Бүтін бөлу және қалдық. 17 кәмпитті қорапқа 5-тен салып жатыр деп елестетіңіз. 17 // 5 қанша толық қорап шығатынын айтады: 3. 17 % 5 қанша кәмпит қалатынын айтады: 2.

    Дәреже және амалдар реті. 2 ** 3 — 2-нің кубы, яғни 8. Амалдар реті математикадағыдай: алдымен көбейту мен бөлу, сосын қосу мен азайту. Жақшалар ретті өзгертеді: (2 + 3) * 4 20 болады.

    Дөңгелектеу. round(3.14159, 2) нүктеден кейін екі таңба қалдырады: 3.14.

    Сан мен мәтін — әртүрлі нәрсе. 2 + 2 4 береді, ал "2" + "2" "22" береді: бұл қосынды емес, желімделген мәтін.

    Байқап көріңіз: бір аптада қанша минут бар екенін есептеңіз. Сосын қалдықтың қалай жұмыс істейтінін тексеріңіз: 10 % 3 не береді?

    Жиі қате: нүктенің орнына үтір

    Бөлшек санға нүкте керек. print(2,5) деп жазсаңыз, қате болмайды, бірақ Python мұны екі сан деп түсініп, 2 5 деп шығарады. Дұрысы: print(2.5).

    Жиі қате: нөлге бөлу

    Python-да да нөлге бөлуге болмайды. print(5 / 0) командасы бағдарламаны тоқтатады: ZeroDivisionError: division by zero Бөлгіштің нөлге тең емес екенін тексеріңіз.

    Қысқаша:

    • + - * / — қарапайым амалдар, бөлшек бөлігі нүктемен бөлінеді;
    • // — неше бүтін рет, % — қалдық, ** — дәреже;
    • сандар тырнақшасыз жазылады: тырнақшадағы "2" — бұл енді мәтін.
    1-мысал. Калькулятор
    print(7 + 5)
print(7 - 5)
print(7 * 5)
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 10)
    2-мысал. Дүкендегі сатып алу
    print("450 теңгеден үш дәптер:", 3 * 450)
print("200 теңгелік қаламмен:", 3 * 450 + 200)
print("2000-нан қайтарым:", 2000 - (3 * 450 + 200))
print("Орташа баға:", round((5 + 4 + 5) / 3, 1))

    Тапсырма: тәуліктегі секундтар

    Деңгейі: Жеңіл

    Тәулікте 24 сағат, сағатта 60 минут, минутта 60 секунд бар. Тәулікте неше секунд бар екенін шығарыңыз. Python өзі есептесін.

    1. 1-кеңес. Үш санды көбейту керек: сағатты, минутты және секундты.
    2. 2-кеңес. Өрнекті тікелей print ішіне жазыңыз: print(24 * 60 * 60).
    Шешімін көрсету
    print(24 * 60 * 60)

    Күрделірек тапсырма: кәмпиттерді тең бөлу

    Деңгейі: Орташа

    47 кәмпитті 6 баланың арасында тең бөледі. Екі жол шығарыңыз: әрқайсысы неше кәмпит алады және нешеуі қалады. Әрқайсысына: 7 және Қалады: 5 шығуы керек.

    1. 1-кеңес. «Әрқайсысына қанша» — бұл бүтін бөлу: 47 // 6.
    2. 2-кеңес. «Қанша қалады» — бұл қалдық: 47 % 6.
    3. 3-кеңес. Мәтін мен санды үтір арқылы тізбелеңіз: print("Әрқайсысына:", 47 // 6).
    Шешімін көрсету
    print("Әрқайсысына:", 47 // 6)
print("Қалады:", 47 % 6)

  4. 3-сабақ. Айнымалылар: мәнді қалай есте сақтау керек

    Не үшін. Бағдарлама деректерді есте сақтауы керек: оқушының атын, тест ұпайларын, себеттегі соманы. Ол үшін айнымалылар бар.

    Айнымалы деген не. Айнымалы — жазуы бар қорап. Қорапқа мән салады, сосын оған жазуы арқылы жүгінеді. name = "Аня" мынаны білдіреді: "Аня" мәтінін name деп жазылған қорапқа сал.

    Python-дағы = белгісі «тең» емес, «салу» дегенді білдіреді. Сол жақта қораптың аты, оң жақта оған не салынатыны жазылады.

    Мәнді өзгертуге болады. score = score + 10 мынаны білдіреді: score ішіндегіні ал, 10 қос және қайта сал. Қысқаша дәл соны былай жазады: score += 10.

    Айнымалыларды қалай атау керек. Латын әріптерін, цифрларды және _ белгісін қолданыңыз. Ат цифрдан басталмайды. Түсінікті аттар таңдаңыз: user_age a-дан жақсы.

    Мәндердің түрлері. Әр мәннің түрі бар: str — мәтін, int — бүтін сан, float — бөлшек сан. Түрін type(...) арқылы білуге болады. Біреуін екіншісіне int("16"), str(16) және float("2.5") айналдырады.

    Пернетақтадан енгізу. Компьютерде input("Атыңыз кім? ") адамнан сұрап, жауап күтеді. Жауап әрқашан мәтін болып келеді, сондықтан санды былай алады: int(input()). Осы сайттағы браузерде input() жұмыс істемейді, сондықтан мәндерді тікелей кодқа жазамыз. Ал сайттарда деректер формалардан келеді, олар туралы бөлек сабақ болады.

    Байқап көріңіз: өз атыңыз бен жасыңызды қойып, қайта іске қосыңыз. Ұпайларға тағы 5 қосыңыз.

    Жиі қате: аттағы қате

    name жасап, сосын nmae деп жазсаңыз, Python не туралы айтылып тұрғанын түсінбейді: NameError: name 'nmae' is not defined Аттың барлық жерде әрпіне дейін бірдей жазылғанын тексеріңіз.

    Жиі қате: мәтін түріндегі сан

    "16" + 1 жұмыс істемейді: сол жақта мәтін, оң жақта сан. TypeError: can only concatenate str (not "int") to str Алдымен мәтінді санға айналдырыңыз: int("16") + 1 17 береді.

    Қысқаша:

    • айнымалы — жазуы бар қорап: name = "Аня", = белгісі «салу» дегенді білдіреді;
    • мәнді өзгертуге болады: score += 10;
    • түрін type() арқылы біледі, int(), str(), float() арқылы өзгертеді.
    1-мысал. Деректері бар қораптар
    name = "Аня"

def count_expensive(cart, limit):

    for price in cart:

            n += 1
    return n


def apply_discount(cart, percent):

    for price in cart:

    return new

    Не үшін. Қателер барлығында болады, тіпті тәжірибелі бағдарламашыларда да. Пайдаланушы санның орнына әріп енгізеді, керекті жазба жоқ, интернет жоғалды. Жақсы бағдарлама мұндайда «құламайды», нені дұрыс емес екенін сабырмен түсіндіреді.

    Қате туралы хабарламаны қалай оқу керек. Python бірнеше жол жазады, солардың ең маңыздысы — соңғысы. Онда қатенің түрі мен қысқа түсіндірме бар, мысалы ValueError: invalid literal for int(). line 3 жазылған жол қай жерден іздеу керегін көрсетеді. Бұл сайтта қатенің астында «Бұл нені білдіреді» деген кеңес те шығады.

    • SyntaxError — код дұрыс жазылмаған: тырнақша, жақша, қос нүкте жоқ;
    • NameError — мұндай ат жоқ, көбіне бұл жазудағы қате;
    • TypeError — әрекет түрге сәйкес келмейді, мысалы мәтін қосу сан;
    • IndexError және KeyError — мұндай нөмірі немесе кілті бар элемент жоқ;
    • ValueError — мән сәйкес келмейді: int("abc").

    Байқап көріңіз: бірінші мысалда тізімге өз жауабыңызды қосыңыз, мысалы "жиырма". Екіншісінде нөлге бөліп, функцияның не жауап беретінін қараңыз.

    Жиі қате: мүлдем бәрін ұстау

    Қатенің атауы жоқ бос except: кез келген нәрсені, тіпті айнымалы атындағы жазу қатесін де ұстайды. Бағдарлама «үнсіз» басқа нәрсе істейді, ал себебін табу қиын болады. Қандай қате күтетініңізді әрқашан жазыңыз: except ValueError:.

    Жиі қате: хабарламаны жоғарыдан оқу

    Жаңадан бастағандар ұзын хабарламадан жиі қорқып, оның бірінші жолын оқиды. Соңғысынан бастаңыз: онда не болғаны жазылған, мысалы ValueError: invalid literal for int() with base 10: 'abc' Бұл «'abc' бүтін санға айналдыруға болмайды» дегенді білдіреді.

  16. 4-шағын жоба. Санды тап

    Не жасаймыз. Компьютер 1-ден 100-ге дейінгі санды ойлайды, сосын оны өзі табады. Айласы мынада: қандай сан ойланса да, ол 7 немесе одан аз әрекетпен табады. Бұл нағыз алгоритм, оны қақ бөлу немесе екілік іздеу деп атайды. Дерекқорлардағы іздеу, тіпті «ыстық — суық» ойыны да осылай жұмыс істейді.

    Не керек болады: шарттар (5-сабақ), while циклы (7-сабақ), функциялар (8-сабақ) және random модулі (11-сабақ).

    Қалай табу керек. Сан low = 1 мен high = 100 арасында бір жерде. Ортасын атаймыз: (low + high) // 2. Тапсақ — бітті. Ойланған сан үлкенірек болса, ортадан кішінің бәрін алып тастауға болады: low = орта + 1. Кішірек болса — жоғарғы жартысын алып тастаймыз: high = орта - 1. Әр әрекет аралықты қақ бөледі, сондықтан 100 сан өте тез таусылады.

    Қадамдық жоспар:

    1. guess_number(secret, low=1, high=100) функциясында әрекеттер санауышын жасаңыз: tries = 0;
    2. while True: циклын жасаңыз — «тоқта дегенше қайтала»;
    3. циклда бір әрекет қосып, ортасын атаңыз;
    4. тапсаңыз, әрекеттер санын бірден қайтарыңыз: return циклды да, функцияны да аяқтайды. Әйтпесе low немесе high жылжытыңыз.

    Не қосуға болады: әр әрекетті шығару («50-ді байқаймын — үлкенірек»), сондай-ақ 100 санға шынымен 7 әрекет жететінін тексеру: 1-ден 100-ге дейінгі барлық сандарды циклмен аралап, әрекеттердің ең үлкен санын табыңыз.

    Қадам бойынша қалай көрінеді
    import random

secret = random.randint(1, 100)
low = 1
high = 100
tries = 0

while True:
    tries += 1
    guess = (low + high) // 2
    if guess == secret:
        print(f"{tries}-әрекет: {guess} — таптым!")
        break
    elif guess < secret:
        print(f"{tries}-әрекет: {guess} — үлкенірек керек")
        low = guess + 1
    else:
        print(f"{tries}-әрекет: {guess} — кішірек керек")
        high = guess - 1

    Жоба: табатын функция

    Деңгейі: Күрделі

    secret санын қақ бөлу арқылы тауып, неше әрекетпен тапқанын қайтаратын guess_number(secret, low=1, high=100) функциясын жазыңыз. Мысалы, guess_number(50) бірінші әрекеттен табады да, 1 қайтарады.

    1. 1-кеңес. «Қадам бойынша қалай көрінеді» мысалы — дерлік дайын шешім. Айырмашылық біреу: print пен break орнына return tries керек.
    2. 2-кеңес. while True: ішінде бірінші жол tries += 1, екіншісі guess = (low + high) // 2.
    3. 3-кеңес. if guess == secret: return tries.
    4. 4-кеңес. elif guess < secret: low = guess + 1, әйтпесе high = guess - 1.
    Шешімін көрсету
    def guess_number(secret, low=1, high=100):
    tries = 0
    while True:
        tries += 1
        guess = (low + high) // 2
        if guess == secret:
            return tries
        elif guess < secret:
            low = guess + 1
        else:
            high = guess - 1

  17. 12-сабақ. Бұның сайттарға қандай қатысы бар

    Не үшін. Сіз Python негіздерін өттіңіз. Енді оларды біріктірейік: осы кірпіштерден сайт қалай шығатынын көрейік.

    Сайт қалай жұмыс істейді. Сіз браузерде мекенжайды тересіз, ал браузер серверге сұрау жібереді. Сервер — бағдарлама жұмыс істеп тұрған компьютер, мысалы Python-да. Ол мекенжайға қарап, керекті функцияны таңдайды, ал ол жауап қайтарады: беттің мәтінін. Толығырақ — «Сайт қалай жұмыс істейді» бетінде.

    Мұнда сіздің сабақтарыңыз қайда:

    • функциялар — сайттың әр беті: функция сұрау алып, бетті қайтарады;
    • сөздік — «мекенжай → функция»: сайт нені көрсету керегін осылай таңдайды;
    • f-жолдар — деректерді бетке қояды: «Сәлем, {name}!»;
    • тізімдер мен циклдар — жазбалар таспасы, істер тізімі, каталогтағы тауарлар;
    • шарттар — пайдаланушы кірді ме, құпиясөз дұрыс па;
    • қателер — сайттың құлауының орнына «404: табылмады» беті;
    • модульдер — Flask пен Django, сайттарға арналған дайын құралдар.

    Flask. Екінші мысалда дәл сол сайт Flask-та. @app.route("/") жолы: «бұл мекенжай осы функцияны ашады» дейді. Шын мәнінде бұл сол мекенжайлар сөздігі, тек Flask оны сіз үшін жасайды.

    Байқап көріңіз: бірінші мысалда мекенжайды "/", сосын "/tasks", сосын жоқ мекенжайға өзгертіңіз. Тізімге өз ісіңізді қосыңыз.

    Жиі қате: мұндай бет жоқ

    Сөздікте жоқ мекенжайды ашсаңыз, pages[address] KeyError қатесімен құлайды. Нағыз сайт олай істемейді: ол «404: табылмады» бетін көрсетеді. Мысалда мұны pages.get(address, not_found) жасайды.

    Қысқаша:

    • сайт — бағдарлама: мекенжайды алып, бетті қайтарады;
    • беттер — функциялар, мекенжайлар — сөздік кілттері, деректер f-жолдармен қойылады;
    • Flask пен Django дәл соны істейді, тек ыңғайлырақ; әрі қарай олармен бірінші жобаны құрастырасыз.
    1-мысал. Функциялар мен сөздіктен жасалған сайт
    tasks = ["нан сатып алу", "сабақ оқу"]

def home():
    return "Басты бет"

def task_list():
    lines = ""
    for task in tasks:
        lines += f"- {task}\n"
    return f"Менің істерім ({len(tasks)}):\n{lines}"

def not_found():
    return "404: бет табылмады"

pages = {"/": home, "/tasks": task_list}

address = "/tasks"
print("Сіз аштыңыз:", address)
print(pages.get(address, not_found)())

    1. 1-кеңес. Мекенжайды in сөзімен тексеріңіз: if address in pages:.
    2. 2-кеңес. Функцияны алып, бірден шақырыңыз: return pages[address]().
