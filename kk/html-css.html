Басты бет / HTML және CSS

HTML және CSS

Кез келген бет неден жасалатыны туралы бес сабақ: тегтер, сілтемелер, формалар және безендіру. Соңғы сабақта Python HTML-ді өзі құрастырады. Нәтижені бірден көру үшін «Көрсету» батырмасын басыңыз.

«Python нөлден» сабақтарынан кейін бастаған дұрыс: соңғы сабақта функциялар мен циклдер қолданылады. Таныс емес сөздер сөздікте бар.

5 сабақтың 0 өтілді

  1. 1-сабақ. HTML деген не: тегтер және беттің қаңқасы

    Не үшін. Сайтты ашқанда Python-дағы сервер браузерге HTML тіліндегі мәтінмен жауап береді. Браузер бұл мәтінді оқып, бетті салады. Өз сайтыңызды жасау үшін бұл мәтіннің қалай құрылғанын білу керек.

    HTML деген не. Бұл — бағдарлама емес, белгілеу тілі. Онда шарттар да, циклдер де жоқ. HTML мәтіннің бөліктеріне жай ғана белгі қояды: «бұл — тақырып», «бұл — абзац», «бұл — маңызды сөз».

    Тегтер. Белгі тег деп аталады және бұрыштық жақшаға жазылады. Әдетте тегтер жұп болады: ашатын <p> және қиғаш сызығы бар жабатын </p>. Олардың арасындағы мәтін — мазмұн. Тег мазмұнымен бірге элемент деп аталады.

    Ең керекті тегтер:

    • <h1>…<h6> — тақырыптар, <h1> — басты тақырып, ол бетте әдетте біреу болады;
    • <p> — мәтін абзацы;
    • <strong> — маңызды сөздер, браузер оларды қалың етіп көрсетеді, <em> — көлбеу қаріппен бөлу;
    • <br> — жаңа жолға көшу. Бұл жалқы тег, оны жабудың қажеті жоқ.

    Ішкі орналасу. Тегтер бір-бірінің ішіне қораптар сияқты салынады: <p>Бұл <strong>маңызды</strong></p>. Оларды кері ретпен жабады: алдымен ішкісін, содан кейін сыртқысын.

    Беттің қаңқасы. Әр беттің қаңқасы бірдей: <!doctype html> жолы, содан кейін <html>, оның ішінде қызметтік мәліметтері бар <head>, мысалы қойындының тақырыбы <title>, және <body> — бетте көрінетіннің бәрі.

    Байқап көріңіз: мысалдардың астындағы «Көрсету» батырмасын басыңыз. Тақырып мәтінін өзгертіп, тағы бір абзац қосыңыз да, «Көрсету» батырмасын қайта басыңыз.

    Жиі қате: тегті жабуды ұмыттыңыз

    <strong> тегін жаппасаңыз, браузер беттің соңына дейінгі бүкіл мәтінді қалың етеді. Ол қатені көрсетпейді, бет жай ғана оғаш көрінеді. Әр жұп тегтің қиғаш сызығы бар жабатын тегі бар екенін тексеріңіз.

    Жиі қате: жабу реті шатасқан

    <p><strong>мәтін</p></strong> — дұрыс емес: қораптар «қиылысып» кетеді. Ішкісінен сыртқысына қарай жабу керек: <p><strong>мәтін</strong></p>.

    Қысқаша:

    • HTML мәтіннің бөліктерін тегтермен белгілейді: <h1>, <p>, <strong>;
    • жұп тег қиғаш сызықпен жабылады, ішкі тегтер кері ретпен жабылады;
    • беттің қаңқасы: <html>, оның ішінде қызметтік бөлік үшін <head> және көрінетін бөлік үшін <body>.
    1-мысал. Алғашқы тегтер
    <h1>Сәлем, мен Аружанмын</h1>
<p>Мен <strong>Python</strong> тілінде сайт жасауды үйреніп жүрмін.</p>
<p>Бұл менің екінші абзацым.<br>Ал бұл оның ішіндегі жаңа жол.</p>
<h2>Жоспарларым</h2>
<p><em>Өз</em> алғашқы сайтымды жасау.</p>
    2-мысал. Беттің толық қаңқасы
    <!doctype html>
<html lang="kk">
<head>
  <meta charset="utf-8">
  <title>Менің визиткам</title>
</head>
<body>
  <h1>Ерлан Нұрланов</h1>
  <p>Астанада бағдарламалауды үйреніп жүрмін.</p>
</body>
</html>

    Тапсырма: алғашқы бет

    Деңгейі: Жеңіл

    Белгілеуді жазыңыз: Менің алғашқы сайтым деген басты тақырып және оның астында кез келген мәтіні бар екі абзац.

    1. 1-кеңес. Тақырып: <h1>Менің алғашқы сайтым</h1>.
    2. 2-кеңес. Әр абзац өз тегтерінде болады: <p>...</p>.
    Шешімін көрсету
    <h1>Менің алғашқы сайтым</h1>
<p>Мұнда мен өзім туралы айтамын.</p>
<p>Ал мұнда — жоспарларым туралы.</p>

    Күрделірек тапсырма: визитка қаңқасы

    Деңгейі: Орташа

    Беттің толық қаңқасын құрастырыңыз: html, оның ішінде қойынды тақырыбы Визитка болатын head және басты тақырыбы — сіздің атыңыз болатын body.

    1. 1-кеңес. Бірінші жолдан басқаның бәрі <html>...</html> ішінде тұрады.
    2. 2-кеңес. <head> ішіне <title>Визитка</title> салыңыз.
    3. 3-кеңес. <body> ішіне — атыңыз жазылған <h1>. 2-мысал дәл осылай құрылған.
    Шешімін көрсету
    <!doctype html>
<html lang="kk">
<head>
  <meta charset="utf-8">
  <title>Визитка</title>
</head>
<body>
  <h1>Дана Смағұлова</h1>
</body>
</html>

  2. 2-сабақ. Тізімдер, сілтемелер және суреттер

    Не үшін. Сайт мәзірі — сілтемелер тізімі. Тауар карточкасы — жазуы бар сурет. Бұл үш тег әр бетте дерлік кездеседі.

    Тізімдер. <ul> — нүктелі тізім, <ol> — нөмірлі тізім. Әр тармақ <li> ішіне жазылады. Бұл Python-дағы тізім сияқты, тек бетте көрсетуге арналған.

    Сілтемелер. <a href="мекенжай">мәтін</a>. href атрибутына сілтеменің қайда апаратыны, ал тегтердің арасына басатын мәтін жазылады.

    Атрибуттар — ашатын тегтің ішіндегі қосымша мәліметтер: атау="мән". Сілтемеде бұл href, суретте — src және alt.

    Толық және қысқа мекенжай. https://www.python.org басқа сайтқа апарады. about.html — осы сайттың бетіне, жол ағымдағы беттен бастап есептеледі.

    Суреттер. <img src="мекенжай" alt="сипаттама"> — жалқы тег. src — суретті қайдан алу керек. alt — суреттің орнына тұратын мәтін: оны зағиптарға арналған бағдарламалар оқиды, ал сурет жүктелмесе, ол көрінеді. Онда суретте не бейнеленгенін жазыңыз.

    Байқап көріңіз: мәзірге сілтемесі бар өз тармағыңызды қосыңыз. Сурет мысалында width мәнін 150-ге өзгертіңіз.

    Жиі қате: https:// жоқ мекенжай

    Браузер <a href="www.python.org"> сілтемесін осы сайттағы «www.python.org» деп аталатын бет деп түсініп, 404 қатесін ашады. Басқа сайттың мекенжайын толық жазыңыз: https://www.python.org.

    Жиі қате: alt жоқ сурет

    alt болмаса, зағип пайдаланушы тек «сурет» немесе файл атауын естиді. Мәнін сипаттаңыз: «сурет1» емес, «Ескі гравюрадағы питон». Сурет тек әшекей болса, бос alt="" жазыңыз.

    Қысқаша:

    • <ul> және <ol> — тізімдер, тармақтар <li> ішінде;
    • <a href="..."> — сілтеме, басқа сайттың мекенжайы https:// арқылы жазылады;
    • <img src="..." alt="..."> — сурет, ал alt міндетті.

  3. 3-сабақ. Формалар: сайт деректерді қалай алады

    Не үшін. Тіркелу, іздеу, пікір, тапсырыс — мұның бәрі формалар. Адамнан келетін деректер серверге, сіздің Python-дағы бағдарламаңызға дәл форма арқылы жетеді.

    <form> тегі өрістерді біріктіреді. action атрибутына деректерді қайда жіберу керегі, ал method атрибутына қалай жіберу керегі жазылады.

    Өрістер. <input> — енгізуге арналған жалқы тег. Оның түрін type анықтайды: text — мәтін, email — пошта, password — нүктемен көрінетін құпиясөз, number — сан, checkbox — белгі. Ұзын мәтін үшін <textarea>, жіберу үшін <button> бар.

    name атрибуты — ең маңыздысы. Бұл — мән серверге қандай атаумен келетіні. Flask-та ол сөздіктің кілті болады: request.form["email"]. name болмаса, өріс мүлдем жіберілмейді.

    <label> жазуы. Жазуды өріспен байланыстырыңыз: өрісте id="email", жазуда for="email". Сонда жазуды басқанда курсор өріске қойылады, ал зағиптарға арналған бағдарламалар жазуды дауыстап оқиды.

    GET және POST. method="get" деректерді бет мекенжайына салады, іздеу осылай жұмыс істейді: ?q=python. method="post" оларды сұраныстың денесінде жасырын жібереді: құпиясөздер мен пікірлер осылай жіберіледі.

    Байқап көріңіз: формаға type="number" түріндегі жас өрісін қосыңыз. Алдын ала қарау терезесінде жіберу өшірулі, бірақ өрістер жұмыс істейді: оларға жазуға болады.

    Жиі қате: name жоқ өріс

    name жазуды ұмытсаңыз, браузер өрісті көрсетеді, тіпті оған жазуға да мүмкіндік береді, бірақ мән серверге жетпейді. Python-да request.form["email"] KeyError қатесімен құлайды. Әр өрісте name бар екенін тексеріңіз.

    Жиі қате: GET арқылы құпиясөз

    method="get" болса, құпиясөз тікелей мекенжай жолында және браузер тарихында қалады. Құпиясөз бен жеке деректері бар формалар үшін әрқашан method="post" қолданыңыз.

    Қысқаша:

    • <form> өрістерді біріктіреді, method="post" — жеке деректер үшін, get — іздеу үшін;
    • <input type="..." name="...">: мән серверге name бойынша келеді;
    • <label for="id"> жазуды өріспен байланыстырады.
    1-мысал. Тіркелу
    <form action="/register" method="post">
  <p>
    <label for="name">Аты</label><br>
    <input id="name" name="name" type="text" placeholder="Аружан" required>
  </p>
  <p>
    <label for="email">Пошта</label><br>
    <input id="email" name="email" type="email">
  </p>
  <p>
    <label for="password">Құпиясөз</label><br>
    <input id="password" name="password" type="password">
  </p>
  <button type="submit">Тіркелу</button>
</form>
    2-мысал. Сервер не алады
    # Форма деректері серверде осылай көрінеді (Flask: request.form)
form = {"name": "Аружан", "email": "aru@example.com", "password": "құпия"}

print("Жаңа пайдаланушы:", form["name"])
print("Пошта:", form["email"])
print("Құпиясөз бар ма?", "password" in form)

    Тапсырма: жаңалықтарға жазылу

    Деңгейі: Жеңіл

    Жазылу формасын жасаңыз: type="email" және name="email" бар бір пошта өрісі және жіберу батырмасы.

    1. 1-кеңес. Өріс: <input type="email" name="email">.
    2. 2-кеңес. Өрісті және <button type="submit">Жазылу</button> батырмасын <form>...</form> ішіне салыңыз.
    Шешімін көрсету
    <form action="/subscribe" method="post">
  <input type="email" name="email" placeholder="Поштаңыз">
  <button type="submit">Жазылу</button>
</form>

    Күрделірек тапсырма: кіру формасы

    Деңгейі: Орташа

    method="post" бар кіру формасын жасаңыз: for және id арқылы байланысқан жазуы бар логин өрісі (name="username"), құпиясөз өрісі (name="password", type="password") және батырма.

    1. 1-кеңес. Жазу мен өріс: <label for="username">Логин</label> және <input id="username" name="username">.
    2. 2-кеңес. Құпиясөз: <input name="password" type="password">. Бұл — формадағы екінші өріс.
    3. 3-кеңес. Және батырма: <button type="submit">Кіру</button>.
    Шешімін көрсету
    <form action="/login" method="post">
  <label for="username">Логин</label>
  <input id="username" name="username" type="text">
  <input name="password" type="password">
  <button type="submit">Кіру</button>
</form>

  4. 4-сабақ. CSS: беттің сыртқы түрі

    Не үшін. HTML бетте не бар екенін айтады: тақырып, абзац, батырма. Ал CSS мұның қалай көрінетінін айтады: түстер, өлшемдер, шегіністер. Осы сайттың өзі CSS-пен безендірілген.

    Қайда жазу керек. Ең оңайы — беттің басындағы <style> тегінде. Үлкен сайттарда CSS бөлек файлға шығарылады.

    CSS ережесі селектордан және бұйра жақшадағы қасиеттерден тұрады: h1 { color: navy; }. Бұл былай оқылады: «барлық h1 күңгірт көк түсті». Әр қасиеттен кейін нүктелі үтір қойылады.

    Селекторлар:

    • тег бойынша: p { ... } — барлық абзацтар;
    • класс бойынша: .card { ... } — class="card" бар барлық элементтер. Бұл ең жиі тәсіл;
    • id бойынша: #top { ... } — id="top" бар бір элемент.

    Пайдалы қасиеттер. color — мәтін түсі, background — фон, font-size — қаріп өлшемі, font-weight: bold — қалыңдық, text-align: center — туралау. padding — жиектің ішіндегі шегініс, margin — сыртындағы, border — жиек, border-radius — бұрыштарды дөңгелектеу.

    Түстер сөзбен (red) немесе кодпен беріледі: #ffd249 — осы сайттың сары түсі.

    Байқап көріңіз: карточка фонын #a4f6f8 түсіне, ал дөңгелектеуді 20px мәніне өзгертіңіз.

    Жиі қате: class атрибутындағы нүкте

    Нүкте тек CSS-та жазылады: .card { ... }. HTML-де класс нүктесіз көрсетіледі: class="card". Нүктемен class=".card" жазсаңыз, ереже жұмыс істемейді.

    Жиі қате: нүктелі үтірді ұмыттыңыз

    color: red background: yellow; ішінде red сөзінен кейін нүктелі үтір жоқ, сондықтан браузер екі қасиетті де өткізіп жібереді. Ол қатені көрсетпейді: стиль жай ғана қолданылмайды. Әр қасиеттен кейін ; қойыңыз.

    Қысқаша:

    • HTML — бетте не бар, CSS — ол қалай көрінеді;
    • ереже: селектор { қасиет: мән; }, CSS-та класс нүктемен жазылады;
    • padding — ішкі шегініс, margin — сыртқы шегініс.
    1-мысал. Мәтінді безендіреміз
    <style>
  h1 { color: #2f6694; font-size: 40px; }
  p { font-size: 18px; color: #333333; }
  .important { background: #ffd249; font-weight: bold; }
</style>

<h1>PyWeb Guide курсы</h1>
<p>Қарапайым абзац.</p>
<p class="important">Ал бұл абзац класпен бөлінген.</p>
    2-мысал. Тауар карточкасы
    <style>
  .card {
    width: 220px;
    padding: 16px;
    margin: 12px;
    background: #ffc4ef;
    border: 2px solid #0d0d0d;
    border-radius: 12px;
  }
  .price { font-size: 24px; font-weight: bold; }
</style>

<div class="card">
  <h2>Дәптер</h2>
  <p class="price">450 теңге</p>
</div>

    Тапсырма: көк тақырып

    Деңгейі: Жеңіл

    h1 тақырыбы #2f6694 түсті болуы үшін CSS ережесін қосыңыз.

    1. 1-кеңес. Селектор — жай ғана тегтің атауы: h1 { ... }.
    2. 2-кеңес. Мәтін түсінің қасиеті: color: #2f6694;.
    Шешімін көрсету
    <style>
  h1 { color: #2f6694; }
</style>
<h1>Менің сайтым</h1>

    Күрделірек тапсырма: өз карточкаңыз

    Деңгейі: Орташа

    Ішінде тақырыбы бар <div class="card"> блогын және фоны (background), ішкі шегінісі (padding) және бұрыштарды дөңгелектеуі (border-radius) бар .card ережесін жасаңыз.

    1. 1-кеңес. CSS-та класс нүктемен жазылады: .card { ... }.
    2. 2-кеңес. Ереженің ішінде: background: #ffc4ef; padding: 16px; border-radius: 12px;.
    3. 3-кеңес. HTML-де — нүктесіз: <div class="card"><h2>Дәптер</h2></div>.
    Шешімін көрсету
    <style>
  .card { background: #ffc4ef; padding: 16px; border-radius: 12px; }
</style>
<div class="card">
  <h2>Дәптер</h2>
</div>

  5. 5-сабақ. Python HTML-ді қалай құрастырады

    Не үшін. Нағыз сайтта HTML әр пайдаланушы үшін қолмен жазылмайды. Оны серверде бағдарлама құрастырады: атты, тапсырмалар тізімін, бағаларды қояды. Бұл сабақ Python мен HTML туралы білетініңіздің бәрін біріктіреді.

    HTML — жай ғана жол. Python үшін бет — қарапайым мәтін. Демек, оны f-жолмен құрастыруға болады: f"<h1>Сәлем, {name}!</h1>".

    Тізімдер циклге айналады. Тапсырмалар тізімін көрсету үшін бағдарлама оны аралап шығып, әр тапсырма үшін <li> жолын қосады. Таспалар, каталогтар мен мәзірлер осылай жасалады.

    Қауіп: беттегі бөгде код. Пайдаланушының мәтінін HTML-ге сол күйінде қойсаңыз, ол оған өз тегін жазуы мүмкін, мысалы <script>, және бұл код басқа келушілерде орындалады. Мұндай шабуыл XSS деп аталады. Қорғаныс — html.escape функциясы: ол < белгісін қауіпсіз &lt; түріне айналдырады, сонда браузер тегті орындамай, таңбаны көрсетеді.

    Үлгілер. Үлкен беттерді жолдардан желімдеу ыңғайсыз. Сондықтан Flask пен Django-да үлгілер қолданылады: {{ name }} бос орындары мен {% for %} циклдері бар HTML файлы. Олар әр мән үшін escape функциясын өздері шақырады. Толығырақ — «Үлгілер мен формалар» бетінде.

    Байқап көріңіз: бірінші мысалда тізімге тапсырма қосыңыз. Екіншісінде пікір мәтінін өзгертіп, нәтижені escape арқылы және онсыз салыстырыңыз.

    Жиі қате: пайдаланушы мәтінін escape-сіз қою

    Сол күйінде қойылған <script>alert(1)</script> пікірі беттің бөлігіне айналады. Пайдаланушыдан келген кез келген мәтінді html.escape() арқылы өткізіңіз немесе мұны өздері жасайтын үлгілерді қолданыңыз.

    Жиі қате: циклден кейін тегті жабуды ұмыттыңыз

    Циклде <li> қосып, циклден кейін </ul> жазуды ұмытсаңыз, тізім бүкіл бетке «созылып» кетеді. Ашатын тег — циклге дейін, жабатыны — циклден кейін.

    Қысқаша:

    • Python үшін HTML — қарапайым жол: оны f-жолдармен және циклдермен құрастырады;
    • пайдаланушы мәтінін әрқашан html.escape арқылы өткізіңіз;
    • Flask пен Django-да мұны үлгілер жасайды, және бұл — келесі қадам.
    1-мысал. Тізімнен жасалған бет
    name = "Аружан"
tasks = ["тегтерді үйрену", "форма жасау", "CSS-пен безендіру"]

page = f"<h1>Тапсырмалар: {name}</h1>\n<ul>\n"
for task in tasks:
    page += f"  <li>{task}</li>\n"
page += "</ul>"

print(page)
    2-мысал. escape арқылы қорғау
    import html

comment = "<script>alert('бұзу')</script>"

print("Қауіпті:    ", f"<p>{comment}</p>")
print("Қауіпсіз:   ", f"<p>{html.escape(comment)}</p>")

    Тапсырма: Python-нан тауар карточкасы

    Деңгейі: Жеңіл

    card(name, price) функциясын жазыңыз. Ол card("Дәптер", 450) үшін карточканың HTML-ін қайтарады: <div class="card"><h2>Дәптер</h2><p>450 теңге</p></div>.

    1. 1-кеңес. Жолды f-жолмен құрастырып, оны return арқылы қайтарыңыз.
    2. 2-кеңес. return f'<div class="card"><h2>{name}</h2><p>{price} теңге</p></div>'. Сыртқы тырнақшалар жалқы, өйткені ішінде қос тырнақшалар бар.
    Шешімін көрсету
    def card(name, price):
    return f'<div class="card"><h2>{name}</h2><p>{price} теңге</p></div>'

    Күрделірек тапсырма: қауіпсіз тізім

    Деңгейі: Орташа

    HTML тізімін қайтаратын render_list(items) функциясын жазыңыз: <ul><li>нан</li><li>сүт</li></ul>. Әр тармақты html.escape арқылы өткізіңіз, өйткені тармақтарды пайдаланушы жазуы мүмкін.

    1. 1-кеңес. Жолды циклге дейін бастаңыз: result = "<ul>".
    2. 2-кеңес. Циклде: result += f"<li>{html.escape(item)}</li>".
    3. 3-кеңес. Циклден кейін тізімді жауып, қайтарыңыз: return result + "</ul>".
    Шешімін көрсету
    import html


def render_list(items):
    result = "<ul>"
    for item in items:
        result += f"<li>{html.escape(item)}</li>"
    return result + "</ul>"
