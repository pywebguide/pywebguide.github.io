Екінші жоба: блог API-ы

Flask пен SQLite-та блогқа арналған API жинаймыз: деректерді тексеру, тесттер және JavaScript-тегі қарапайым беті бар. Дерекқорлар мен REST API туралы бөлімдердегі білім керек болады. Шамамен бір сағат уақыт кетеді.

Не шығады

Бүкіл код бір app.py файлына сыяды. Соңғы мысалды тікелей осы бетте іске қосуға болады.

Жоба қадамдары

Өткеніңізді белгілеңіз: прогресс браузерде сақталады.

  1. 1-қадам. Жоба жасаңыз

    Алғашқы жобадағыдай жаңа қалта және өз ортасы.

    Терминал 
    mkdir blog-api
cd blog-api
python -m venv .venv
.venv\Scripts\activate
pip install flask pytest

    macOS пен Linux-та ортаны source .venv/bin/activate командасы іске қосады.

  2. 2-қадам. Дерекқорды қосыңыз

    Байланыс сұрау уақытына ашылып, соңында жабылады. Кесте әлі жоқ болса, алғаш іске қосқанда жасалады. create_app функциясы тесттерге бөлек дерекқорды қолдануға мүмкіндік береді.

    app.py 
    import sqlite3

from flask import Flask, g, jsonify, request

SCHEMA = """
CREATE TABLE IF NOT EXISTS posts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    body TEXT NOT NULL,
    created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
)
"""

def create_app(database="blog.db"):
    app = Flask(__name__)

    def db():
        if "db" not in g:
            g.db = sqlite3.connect(database)
            g.db.row_factory = sqlite3.Row
            g.db.execute(SCHEMA)
        return g.db

    @app.teardown_appcontext
    def close_db(error):
        connection = g.pop("db", None)
        if connection is not None:
            connection.close()

    # маршруты из следующих шагов идут здесь

    return app

  3. 3-қадам. Деректерді тексеруді қосыңыз

    Функция не таза деректерді, не қате мәтінін қайтарады. Оны create_app үстіне шығарыңыз, сонда оны бөлек тексеру оңай болады.

    app.py 
    def validate_post(data):
    if not isinstance(data, dict):
        return None, "Нужен JSON-объект"
    title = str(data.get("title", "")).strip()
    body = str(data.get("body", "")).strip()
    if not title or len(title) > 120:
        return None, "Заголовок обязателен, не длиннее 120 символов"
    if not body:
        return None, "Текст обязателен"
    return {"title": title, "body": body}, None

  4. 4-қадам. Тізім мен жазба жасауды іске асырыңыз

    Мәндер ? белгілері арқылы беріледі. Сөйтіп дерекқор сұрауды SQL-инъекциялардан өзі қорғайды. Пайдаланушының деректерін SQL-ға ешқашан f-жол арқылы қоймаңыз.

    app.py 
        @app.get("/posts")
    def list_posts():
        rows = db().execute("SELECT * FROM posts ORDER BY id DESC").fetchall()
        return jsonify([dict(row) for row in rows])

    @app.post("/posts")
    def create_post():
        post, error = validate_post(request.get_json(silent=True))
        if error:
            return {"error": error}, 400
        cursor = db().execute(
            "INSERT INTO posts (title, body) VALUES (?, ?)",
            (post["title"], post["body"]),
        )
        db().commit()
        row = db().execute("SELECT * FROM posts WHERE id = ?", (cursor.lastrowid,)).fetchone()
        return dict(row), 201

  5. 5-қадам. Оқуды, өзгертуді және жоюды іске асырыңыз

    Жазба жоқ болса, құламаймыз, 404 қатесін қайтарамыз.

    app.py 
        @app.get("/posts/<int:post_id>")
    def get_post(post_id):
        row = db().execute("SELECT * FROM posts WHERE id = ?", (post_id,)).fetchone()
        if row is None:
            return {"error": "Запись не найдена"}, 404
        return dict(row)

    @app.put("/posts/<int:post_id>")
    def update_post(post_id):
        post, error = validate_post(request.get_json(silent=True))
        if error:
            return {"error": error}, 400
        cursor = db().execute(
            "UPDATE posts SET title = ?, body = ? WHERE id = ?",
            (post["title"], post["body"], post_id),
        )
        db().commit()
        if cursor.rowcount == 0:
            return {"error": "Запись не найдена"}, 404
        return get_post(post_id)

    @app.delete("/posts/<int:post_id>")
    def delete_post(post_id):
        cursor = db().execute("DELETE FROM posts WHERE id = ?", (post_id,))
        db().commit()
        if cursor.rowcount == 0:
            return {"error": "Запись не найдена"}, 404
        return "", 204

    Өз компьютеріңізде іске қосу: flask --app "app:create_app()" run --debug.

  6. 6-қадам. Тесттер жазыңыз

    pytest командасымен іске қосыңыз. tmp_path фикстурасы уақытша қалта береді, сондықтан тесттер нақты дерекқорға тимейді.

    test_app.py 
    import pytest

from app import create_app

@pytest.fixture
def client(tmp_path):
    return create_app(tmp_path / "test.db").test_client()

def test_create_and_read(client):
    created = client.post("/posts", json={"title": "Привет", "body": "Текст"})
    assert created.status_code == 201
    post_id = created.json["id"]
    assert client.get(f"/posts/{post_id}").json["title"] == "Привет"

def test_empty_title_rejected(client):
    assert client.post("/posts", json={"title": " ", "body": "Текст"}).status_code == 400

def test_delete(client):
    post_id = client.post("/posts", json={"title": "А", "body": "Б"}).json["id"]
    assert client.delete(f"/posts/{post_id}").status_code == 204
    assert client.get(f"/posts/{post_id}").status_code == 404

  7. 7-қадам. Бет қосыңыз

    Файлды static қалтасына салыңыз, ол /static/index.html мекенжайында ашылады. Жазба мәтіні textContent арқылы шығарылады, сондықтан ол арқылы бөгде скрипт енгізу мүмкін емес.

    static/index.html 
    <!doctype html>
<html lang="ru">
<meta charset="utf-8">
<title>Блог</title>
<h1>Блог</h1>
<form id="form">
  <input name="title" placeholder="Заголовок" required>
  <textarea name="body" placeholder="Текст" required></textarea>
  <button>Опубликовать</button>
</form>
<div id="posts"></div>
<script>
  const posts = document.getElementById("posts");
  const form = document.getElementById("form");

  async function load() {
    const items = await (await fetch("/posts")).json();
    posts.replaceChildren(...items.map((post) => {
      const article = document.createElement("article");
      const title = document.createElement("h2");
      const body = document.createElement("p");
      title.textContent = post.title;
      body.textContent = post.body;
      article.append(title, body);
      return article;
    }));
  }

  form.addEventListener("submit", async (event) => {
    event.preventDefault();
    const response = await fetch("/posts", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(Object.fromEntries(new FormData(form))),
    });
    if (response.ok) {
      form.reset();
      load();
    }
  });

  load();
</script>
</html>

Бүкіл код және іске қосу

Мұнда бүкіл app.py файлы және соңында қысқа тексеріс. Дерекқор уақытша файлда жасалады.

app.py толығымен 
import sqlite3
import tempfile
from pathlib import Path

from flask import Flask, g, jsonify, request

SCHEMA = """
CREATE TABLE IF NOT EXISTS posts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    body TEXT NOT NULL,
    created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
)
"""

def validate_post(data):
    if not isinstance(data, dict):
        return None, "Нужен JSON-объект"
    title = str(data.get("title", "")).strip()
    body = str(data.get("body", "")).strip()
    if not title or len(title) > 120:
        return None, "Заголовок обязателен, не длиннее 120 символов"
    if not body:
        return None, "Текст обязателен"
    return {"title": title, "body": body}, None

def create_app(database="blog.db"):
    app = Flask(__name__)

    def db():
        if "db" not in g:
            g.db = sqlite3.connect(database)
            g.db.row_factory = sqlite3.Row
            g.db.execute(SCHEMA)
        return g.db

    @app.teardown_appcontext
    def close_db(error):
        connection = g.pop("db", None)
        if connection is not None:
            connection.close()

    @app.get("/posts")
    def list_posts():
        rows = db().execute("SELECT * FROM posts ORDER BY id DESC").fetchall()
        return jsonify([dict(row) for row in rows])

    @app.post("/posts")
    def create_post():
        post, error = validate_post(request.get_json(silent=True))
        if error:
            return {"error": error}, 400
        cursor = db().execute(
            "INSERT INTO posts (title, body) VALUES (?, ?)",
            (post["title"], post["body"]),
        )
        db().commit()
        row = db().execute("SELECT * FROM posts WHERE id = ?", (cursor.lastrowid,)).fetchone()
        return dict(row), 201

    @app.get("/posts/<int:post_id>")
    def get_post(post_id):
        row = db().execute("SELECT * FROM posts WHERE id = ?", (post_id,)).fetchone()
        if row is None:
            return {"error": "Запись не найдена"}, 404
        return dict(row)

    @app.put("/posts/<int:post_id>")
    def update_post(post_id):
        post, error = validate_post(request.get_json(silent=True))
        if error:
            return {"error": error}, 400
        cursor = db().execute(
            "UPDATE posts SET title = ?, body = ? WHERE id = ?",
            (post["title"], post["body"], post_id),
        )
        db().commit()
        if cursor.rowcount == 0:
            return {"error": "Запись не найдена"}, 404
        return get_post(post_id)

    @app.delete("/posts/<int:post_id>")
    def delete_post(post_id):
        cursor = db().execute("DELETE FROM posts WHERE id = ?", (post_id,))
        db().commit()
        if cursor.rowcount == 0:
            return {"error": "Запись не найдена"}, 404
        return "", 204

    return app

# Проверка без настоящего сервера
with tempfile.TemporaryDirectory() as folder:
    client = create_app(Path(folder) / "blog.db").test_client()
    print("Пустой заголовок:", client.post("/posts", json={"title": "", "body": "x"}).status_code)
    created = client.post("/posts", json={"title": "Первая запись", "body": "Привет!"})
    print("Создана:", created.status_code, created.json["title"])
    post_id = created.json["id"]
    print("Изменена:", client.put(f"/posts/{post_id}", json={"title": "Новая", "body": "Текст"}).json["title"])
    print("Список:", [post["title"] for post in client.get("/posts").json])
    print("Удалена:", client.delete(f"/posts/{post_id}").status_code)
    print("Снова читаем:", client.get(f"/posts/{post_id}").status_code)

Өз бетіңізше не қосуға болады

Бұл идеялар басқа бөлімдердегі материалды бекітеді.

  • Беттеп шығару: ?limit=10&offset=20 параметрлері және LIMIT ? OFFSET ? SQL-ы.
  • Автордың кіруі: жазбаларды тек авторизациядан кейін жасауға және жоюға болады.
  • LIKE ? арқылы тақырып бойынша іздеу.
  • PythonAnywhere-де жариялау: WSGI-файлда application = create_app("/home/username/blog-api/blog.db") деп көрсетіңіз.
