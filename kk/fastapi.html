FastAPI-дағы алғашқы API

Сол «тапсырмалар тізімі» қосымшасы, бірақ беттерсіз: сервер JSON қабылдап, JSON қайтарады. FastAPI деректерді Pydantic модельдері бойынша тексереді, дұрыс кодтармен өзі жауап береді және API-ді сынап көруге болатын құжаттама жасайды. Шамамен 40 минут.

HTTP әдістері, JSON және жауап кодтары туралы «REST API» бөлімінде айтылған — алдымен соны қараңыз.

Не қажет болады

Жоба бос бумадан басталады және алғашқы жобаға тәуелді емес.

Дайын кодты жүктеу (zip, 2 КБ) GitHub-та қарау

  • Python 3.12 немесе жаңарағы: python --version командасы.
  • GET, POST, DELETE әдістері мен 200, 201, 404 кодтарын түсіну — «REST API» бөлімі.
  • Өтілген алғашқы жоба салыстыру үшін пайдалы, бірақ міндетті емес.

Сұрауларды браузерден жібереміз. GET үшін мекенжай жолы жеткілікті, ал POST пен DELETE-ті FastAPI өзі жасайтын /docs бетінен жіберу ыңғайлы — бұл Windows, macOS және Linux-та бірдей. Өтілген қадамдар осы браузерде сақталады.

Тапсырмалар тізімінің API-і

Төрт маршрут: тізім, қосу, бір тапсырма және жою. Содан кейін құжаттама мен тесттер.

6 қадамның 0 қадамы өтілді

  1. 1-қадам. Жоба жасап, FastAPI орнатыңыз

    Алғашқы жобадағыдай жаңа бума және өз виртуалды ортасы. Тырнақшадағы [standard] сөзі FastAPI-мен бірге кейін керек болатынның бәрін орнатады: fastapi командасын, uvicorn серверін және тесттер жұмыс істейтін httpx кітапханасын.

    Windows (PowerShell немесе пәрмен жолы)

    Терминал 
    mkdir fastapi-todo
cd fastapi-todo
python -m venv .venv
.venv\Scripts\activate
pip install "fastapi[standard]"

    macOS және Linux (Терминал)

    Терминал 
    mkdir fastapi-todo
cd fastapi-todo
python3 -m venv .venv
source .venv/bin/activate
pip install "fastapi[standard]"

    Күтілетін нәтиже

    Орнатудың соңғы жолы ұзын: онда 60-қа жуық пакет бар, олардың ішінде fastapi-0.163.1, pydantic-2.14.3, starlette-1.10.0 және uvicorn-0.54.0. FastAPI нұсқасын pip show fastapi командасы көрсетеді:

    Нұсқа нөмірі жаңарақ болуы мүмкін — бұл қалыпты. fastapi[standard] тырнақшасыз жазылса, кейбір терминалдар (мысалы, macOS-тағы zsh) шаршы жақшаларды түсінбейді.

  2. 2-қадам. Алғашқы маршрут: тапсырмалар тізімі

    main.py файлын жасаңыз. @app.get("/tasks") декораторы мекенжай мен GET әдісін функциямен байланыстырады — Flask-тағы @app.get сияқты. Айырмашылық жауапта: функция кәдімгі Python тізімін қайтарады, ал FastAPI оны JSON-ға өзі айналдырады. Тапсырмалар әзірге сервер жадында сақталады.

    main.py 
    from fastapi import FastAPI

app = FastAPI(title="Список задач")

tasks = []

@app.get("/tasks")
def list_tasks():
    return tasks

    Серверді әзірлеу режимінде іске қосыңыз: ол файлды әр сақтаған сайын қайта іске қосылады.

    Терминал 
    fastapi dev main.py

  3. 3-қадам. Pydantic модельдері және тапсырма қосу

    main.py файлын толығымен ауыстырыңыз. Pydantic модельдері деректерді түр нұсқаулары бар кластармен сипаттайды, ал FastAPI солар бойынша сұрауды тексеріп, жауапты құрады. Модель екеу, себебі екі бағыттағы деректер әртүрлі: клиент тек атауды жібереді (TaskCreate), ал нөмір мен «орындалды» белгісін сервер береді (Task).

    main.py 
    from itertools import count

from fastapi import FastAPI
from pydantic import BaseModel, ConfigDict, Field

app = FastAPI(title="Список задач")

class TaskCreate(BaseModel):
    model_config = ConfigDict(str_strip_whitespace=True)

    title: str = Field(min_length=1, max_length=200)

class Task(BaseModel):
    id: int
    title: str
    done: bool = False

tasks: dict[int, Task] = {}
ids = count(1)

@app.get("/tasks")
def list_tasks() -> list[Task]:
    return list(tasks.values())

@app.post("/tasks", status_code=201)
def create_task(data: TaskCreate) -> Task:
    task = Task(id=next(ids), title=data.title)
    tasks[task.id] = task
    return task
    • Field(min_length=1, max_length=200) — атауға шектеулер, ал str_strip_whitespace=True алдымен шеттегі бос орындарды алып тастайды. Тек бос орыннан тұратын атау бос болып қалады да, тексеруден өтпейді — алғашқы жобадағыдай.
    • Функция параметрлеріндегі data: TaskCreate «сұрау денесін JSON ретінде оқып, модель бойынша тексер» дегенді білдіреді. Тексеру өтпесе, функция тіпті шақырылмайды: FastAPI 422 кодымен өзі жауап береді.
    • -> Task және -> list[Task] — функция қайтаратын нәрсе. Осы нұсқау бойынша FastAPI жауапты тексеріп, оны құжаттамада сипаттайды.
    • status_code=201 — «Created» коды: REST ережелері бойынша жаңа жазба 200 емес, 201 деп жауап береді.
    • itertools модуліндегі count(1) әр next(ids) сайын 1, 2, 3… нөмірлерін бір-бірден береді.

    Сұрау жіберейік. http://127.0.0.1:8000/docs ашып, POST /tasks жолын ашыңыз, Try it out басып, Request body өрісіне {"title": "Купить хлеб"} мәтінін жазыңыз да, Execute басыңыз. Содан кейін дәл солай {"title": " "} — үш бос орынды жіберіңіз.

    Күтілетін нәтиже

    Бірінші сұрау: 201 коды және Response body өрісінде жасалған тапсырма:

    {
  "id": 1,
  "title": "Купить хлеб",
  "done": false
}

    Екінші сұрау: 422 коды. Бұл — Pydantic жауабы, create_task функциясы шақырылған жоқ:

    {
  "detail": [
    {
      "type": "string_too_short",
      "loc": [
        "body",
        "title"
      ],
      "msg": "String should have at least 1 character",
      "input": "   ",
      "ctx": {
        "min_length": 1
      }
    }
  ]
}

    loc қатенің қайда екенін көрсетеді: сұрау денесінде, title өрісінде; msg — не дұрыс емес. input ішінде жіберілген мән бос орындарымен көрінеді, бірақ тексерілген бос жол болды. main.py файлын әр сақтаған сайын сервер қайта іске қосылып, тапсырмалар тізімі қайтадан бос болады: ол жадта тұрады.

  4. 4-қадам. Бір тапсырма, жою және 404 коды

    Бір тапсырманы оқу мен жоюды қосайық. main.py файлын толығымен ауыстырыңыз: жаңа бөліктері — find функциясы және соңындағы екі маршрут.

    main.py 
    from itertools import count

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, ConfigDict, Field

app = FastAPI(title="Список задач")

class TaskCreate(BaseModel):
    model_config = ConfigDict(str_strip_whitespace=True)

    title: str = Field(min_length=1, max_length=200)

class Task(BaseModel):
    id: int
    title: str
    done: bool = False

tasks: dict[int, Task] = {}
ids = count(1)

def find(task_id: int) -> Task:
    if task_id not in tasks:
        raise HTTPException(status_code=404, detail="Задача не найдена")
    return tasks[task_id]

@app.get("/tasks")
def list_tasks() -> list[Task]:
    return list(tasks.values())

@app.post("/tasks", status_code=201)
def create_task(data: TaskCreate) -> Task:
    task = Task(id=next(ids), title=data.title)
    tasks[task.id] = task
    return task

@app.get("/tasks/{task_id}")
def get_task(task_id: int) -> Task:
    return find(task_id)

@app.delete("/tasks/{task_id}", status_code=204)
def delete_task(task_id: int) -> None:
    del tasks[find(task_id).id]
    • Мекенжайдағы {task_id} — жол параметрі. task_id: int нұсқауы FastAPI-ді оны санға айналдыруға мәжбүрлейді; /tasks/abc мекенжайы 422 алады.
    • HTTPException(status_code=404, …) функцияны тоқтатып, клиентке код пен хабарламамен жауап береді. Әр маршрутта тексеруді қайталамау үшін іздеу find функциясына шығарылған.
    • Жою 204 No Content деп жауап береді: бәрі сәтті өтті, ал көрсететін ештеңе жоқ, сондықтан жауаптың денесі жоқ. Мұны -> None да айтады.

    /docs ішінде екі тапсырма қосыңыз («Купить хлеб» және «Выучить FastAPI»), содан кейін GET /tasks/{task_id} бетін 1 және 99 нөмірлерімен ашып, 1-тапсырманы DELETE арқылы жойыңыз да, бүкіл тізімді қайта сұраңыз.

    Күтілетін нәтиже

    Қосу 1 және 2 нөмірлі тапсырмаларды қайтарады (201 коды):

    {
  "id": 1,
  "title": "Купить хлеб",
  "done": false
}
    {
  "id": 2,
  "title": "Выучить FastAPI",
  "done": false
}

    1-тапсырма — 200 коды:

    {
  "id": 1,
  "title": "Купить хлеб",
  "done": false
}

    99-тапсырма жоқ — 404 коды және HTTPException хабарламасы:

    {
  "detail": "Задача не найдена"
}

    Жою — 204 коды, дене жоқ, Swagger тек жауап тақырыптарын көрсетеді:

    Code 204

    Тізімде бір тапсырма қалды:

    [
  {
    "id": 2,
    "title": "Выучить FastAPI",
    "done": false
  }
]

    404 жауабына Swagger «Undocumented» деп жазады: маршрут сипаттамасында бұл код жарияланбаған. Оны декоратордың responses параметрімен жариялауға болады, API жұмысына бұл әсер етпейді.

  5. 5-қадам. Автоқұжаттаманы зерттеңіз

    /docs бетін сіз жазған жоқсыз: FastAPI оны кодтан құрастырды. Маршруттарды, параметрлерді, модельдер мен жауап кодтарын ол OpenAPI стандартында сипаттайды — бұл /openapi.json файлы, ал /docs (Swagger UI) мен /redoc (ReDoc) — сол файлды оқуға арналған екі қабықша. «List Tasks» сияқты жазулар функция атауларынан, ал «Список задач» FastAPI(title=…) ішінен алынған. Төмендегі Schemas бөлімін ашыңыз: онда Task және TaskCreate модельдері шектеулерімен бірге берілген.

    /docs пен /redoc безендіруін браузер интернеттен, cdn.jsdelivr.net сайтынан жүктейді. Интернетсіз бұл беттер бос болады, бірақ API-дің өзі жұмыс істейді.

  6. 6-қадам. API-ді тесттермен тексеріңіз

    main.py жанында test_main.py жасап, pytest орнатыңыз. TestClient сұрауларды іске қосылған серверсіз тікелей қосымшаға жібереді. autouse=True бар фикстура тесттер бір-біріне тәуелді болмауы үшін әр тест алдында тізімді тазалайды.

    test_main.py 
    import pytest
from fastapi.testclient import TestClient

import main

client = TestClient(main.app)

@pytest.fixture(autouse=True)
def empty_list():
    main.tasks.clear()

def test_create_and_list():
    response = client.post("/tasks", json={"title": "Купить хлеб"})
    assert response.status_code == 201
    task = response.json()
    assert task["title"] == "Купить хлеб"
    assert task["done"] is False
    assert client.get("/tasks").json() == [task]

def test_empty_title_is_rejected():
    response = client.post("/tasks", json={"title": "   "})
    assert response.status_code == 422
    assert client.get("/tasks").json() == []

def test_missing_task_is_404():
    response = client.get("/tasks/999")
    assert response.status_code == 404
    assert response.json() == {"detail": "Задача не найдена"}

def test_delete():
    task_id = client.post("/tasks", json={"title": "Удалить меня"}).json()["id"]
    assert client.delete(f"/tasks/{task_id}").status_code == 204
    assert client.get(f"/tasks/{task_id}").status_code == 404

def test_id_must_be_a_number():
    assert client.get("/tasks/abc").status_code == 422
    Терминал 
    pip install pytest
pytest -q
    • Тесттер сәтті жауаптарды да (201, 200, 204), қателерді де тексереді: бос атау — 422, тапсырма жоқ — 404, нөмір сан емес — 422.
    • Тапсырма нөмірі тестте санмен жазылмайды, жауаптан алынады (.json()["id"]): санауыш тесттер арасында нөлденбейді.
    • -q жалаушасы қысқа басып шығарады: өткен әр тест үшін бір нүкте.

    Күтілетін нәтиже

    .....                                                                    [100%]
5 passed in 0.31s

    Уақыт сізде басқаша болады. TaskCreate ішінен str_strip_whitespace=True жолын алып тастасаңыз, test_empty_title_is_rejected тесті құлайды: үш бос орын жарамды атау болып шығады.

Өзіңізді тексеріңіз

Алдымен ойша жауап беріп, содан кейін жауапты ашыңыз.

Өрістері дерлік бірдей болса, TaskCreate және Task деген екі модель не үшін керек?

Олар алмасудың екі жағын сипаттайды. Клиент тек атауды жібереді — нөмір мен «орындалды» белгісін ол таңдамауы керек, сондықтан TaskCreate ішінде олар жоқ. Сервер тапсырманы толығымен қайтарады — бұл Task. Егер қабылдау Task арқылы жүрсе, клиент кез келген id жібере алар еді.

Бос атауға сервер неге 400 емес, 422 деп жауап берді?

422 Unprocessable Content коды: сұрау пішіні бойынша дұрыс (бұл нағыз JSON), бірақ ішіндегі деректер сай келмейді дегенді білдіреді. FastAPI Pydantic тексеруінің кез келген қатесіне осылай жауап береді. 400 коды әдетте сұрау түгелдей бұзылғанын білдіреді, мысалы, JSON орнына мәтін үзіндісі келді.

Сервер қайта іске қосылғаннан кейін тапсырмалармен не болады?

Олар жоғалады: tasks сөздігі Flask-тағы алғашқы жобаның 2-қадамындағы тізім сияқты бағдарлама жадында тұрады. Деректер сақталуы үшін дерекқор керек — мысалы, екінші жобадағыдай SQLite.

Жоюдың коды неге 204 және жауабы бос?

204 No Content — «бәрі сәтті, бұдан артық айтатын ештеңе жоқ». Тапсырма енді жоқ, қайтаратын ештеңе жоқ, ал клиентке код жеткілікті. Сондықтан функцияда -> None, ал декораторда status_code=204 тұр.

Функциядан кейінгі -> Task нұсқауы не береді?

FastAPI жауапты модель бойынша тексеріп, тек оның өрістерін өткізеді. Функция қателесіп толық емес деректер қайтарса, сервер 500 қатесімен жауап береді, ал терминалда ResponseValidationError пайда болады — қате клиентке үнсіз жетпейді. Сондай-ақ осы нұсқау бойынша /docs ішінде жауап мысалы шығады.

Өзіндік тапсырма

Тапсырманы орындалды деп белгілейтін немесе белгіні алып тастайтын PATCH /tasks/{task_id} маршрутын қосыңыз. Сұрау денесінде {"done": true} немесе {"done": false} келеді, жауап — өзгертілген тапсырма, жоқ тапсырма үшін — 404. Оған тест жазыңыз.

Шешімін көрсету

Сұрау денесіне арналған модель және жаңа маршрут керек. 4-қадамдағы find функциясы 404 деп жауап береді.

main.py — соңына қосу 
class TaskUpdate(BaseModel):
    done: bool

@app.patch("/tasks/{task_id}")
def update_task(task_id: int, data: TaskUpdate) -> Task:
    task = find(task_id)
    task.done = data.done
    return task
test_main.py — соңына қосу 
def test_mark_done():
    task_id = client.post("/tasks", json={"title": "Сделать"}).json()["id"]
    response = client.patch(f"/tasks/{task_id}", json={"done": True})
    assert response.status_code == 200
    assert response.json()["done"] is True
    assert client.get(f"/tasks/{task_id}").json()["done"] is True
    assert client.patch("/tasks/999", json={"done": True}).status_code == 404

Тексеру: pytest -q 6 passed деп көрсетеді. /docs ішінде жасыл PATCH /tasks/{task_id} жолы пайда болады.

Flask және FastAPI

REST қағидалары бірдей. Айырмашылық — фреймворк қанша жұмысты өзі атқарады. Flask-тағы API мысалы «REST API» бөлімінде.

Екі фреймворктегі бір API
Не керек Flask FastAPI
Сұраудан JSON оқу request.get_json() қолмен Pydantic моделі бар функция параметрі
Деректерді тексеру өз if тексерулеріңізбен, 400 жауабы да қолмен модельдегі шектеулер, 422 жауабы автоматты түрде
Жауапты JSON-ға айналдыру jsonify(…) немесе сөздік кез келген модель нысаны, тізім немесе сөздік
Құжаттама бөлек жазылады кодтан /docs және /redoc
Әзірлеуге арналған сервер flask run --debug fastapi dev (ішінде — uvicorn)

Жиі кездесетін қателер және оларды қалай түзету керек

Хабарламалар FastAPI 0.163 және pytest көрсететіндей берілген. Шешімін көру үшін қатені басыңыз.

«To use the fastapi command, please install "fastapi[standard]"»

To use the fastapi command, please install "fastapi[standard]" Тек FastAPI-дің өзі орнатылған, fastapi командасы мен сервер жоқ. Сол ортада pip install "fastapi[standard]" командасын — тырнақшамен — орындаңыз.

422 «Input should be a valid integer»

{"detail":[{"type":"int_parsing","loc":["path","task_id"],"msg":"Input should be a valid integer, unable to parse string as an integer","input":"abc"}]} Мекенжайда тапсырма нөмірінің орнына мәтін тұр, мысалы /tasks/abc. task_id: int параметрі тек бүтін сандарды қабылдайды.

405 «Method Not Allowed»

{"detail":"Method Not Allowed"} Мекенжай бар, бірақ басқа әдіспен. Мысалы, нөмірсіз DELETE /tasks: жою тек /tasks/{task_id} үшін жарияланған. Әдіс пен мекенжайды /docs ішінде тексеріңіз.

500 қатесі және терминалдағы «ResponseValidationError»

fastapi.exceptions.ResponseValidationError: 1 validation error: {'type': 'missing', 'loc': ('response', 'title'), 'msg': 'Field required', 'input': {'id': 1}} Функция -> Task сай келмейтін деректер қайтарды: мұнда title жоқ сөздік. 3-қадамдағыдай Task моделінің нысанын толығымен қайтарыңыз.

pytest: «ModuleNotFoundError: No module named 'main'»

E ModuleNotFoundError: No module named 'main' Тест main.py файлын таппады. main.py мен test_main.py файлдары бір бумада жатуы керек, ал pytest сол бумадан іске қосылады.

/docs беті бос

Swagger UI безендіруін браузер cdn.jsdelivr.net сайтынан жүктейді. Интернет болмаса немесе сайт бұғатталса, /docs пен /redoc бос қалады, ал /openapi.json және API-дің барлық маршруты жұмыс істейді. Интернетті тексеріңіз немесе 6-қадамдағыдай сұрауды тесттерден жіберіңіз.

Дереккөздер

Код FastAPI 0.163 және Pydantic 2-ге арналған. Барлық қадам Python 3.13, FastAPI 0.163.1 және Pydantic 2.14.3 нұсқасында орындалды, дереккөздер тексерілді: 17.11.2026.

  • FastAPI: алғашқы қадамдар — қосымша, маршрут, fastapi dev
  • FastAPI: сұрау денесі — Pydantic модельдері
  • FastAPI: жол параметрлері — task_id: int
  • FastAPI: жауап моделі — -> Task нұсқауы
  • FastAPI: жауап коды — status_code=201

Әрі қарай не бар

Тапсырмалар әзірге жадта тұрады. API деректерін SQLite-та қалай сақтап, тесттермен тексеру керегін екінші жоба көрсетеді — онда Flask-тағы блог API-і. Осы бөлімдегі REST ережелері оған өзгеріссіз жарайды.
