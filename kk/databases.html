Басты бет / Дерекқорлар

Сайт деректерді қалай сақтайды

Пайдаланушылар, тапсырмалар, тауарлар, пікірлер — қойынды жабылғаннан кейін де сақталуы керек нәрсенің бәрі дерекқорда тұрады. SQL-ды SQLite мысалында талдап, Django-дағы ORM дәл осыны қалай жасайтынын көрсетеміз.

Енді ғана бастап жатырсыз ба? Алдымен «Нөлден» сабақтарын өтіңіз, ал бейтаныс сөздерді сөздіктен қараңыз.

Серверге дерекқор не үшін керек

Python-дағы айнымалылар бағдарлама жұмыс істеп тұрғанда ғана өмір сүреді. Дерекқор деректерді дискіде сақтайды және оларды тез таба алады.

Кестелер

Деректер кестелерде жатады: жол — бір жазба (тауар), баған — бір қасиет (атауы, бағасы).

Бастапқы кілт

Әр жолдың бірегей id нөмірі бар. Сол арқылы жазбаны табуға, өзгертуге немесе жоюға болады.

SQL

Дерекқорға сұрау тілі: SELECT оқиды, INSERT қосады, UPDATE өзгертеді, DELETE жояды.

ORM

Python кластарын кестелерге, ал әдістерді шақыруды SQL-сұрауларға айналдыратын аралық қабат.

SQL іс жүзінде: sqlite3 модулі

SQLite — бір файлдағы дерекқор. Ол Python-ға кірістірілген, оған сервер қажет емес, сондықтан оқу жобалары үшін ең жақсы нұсқа. Кодты файлға сақтап, іске қосыңыз — ол shop.db файлын жасайды.

shop.py 
import sqlite3

conn = sqlite3.connect("shop.db")

conn.execute("""
    CREATE TABLE IF NOT EXISTS products (
        id INTEGER PRIMARY KEY,
        name TEXT NOT NULL,
        price INTEGER NOT NULL
    )
""")

conn.execute("INSERT INTO products (name, price) VALUES (?, ?)", ("Тетрадь", 350))
conn.execute("INSERT INTO products (name, price) VALUES (?, ?)", ("Ручка", 150))
conn.commit()

for name, price in conn.execute("SELECT name, price FROM products WHERE price < ?", (300,)):
    print(name, price)  # Ручка 150

conn.execute("UPDATE products SET price = ? WHERE name = ?", (400, "Тетрадь"))
conn.execute("DELETE FROM products WHERE name = ?", ("Ручка",))
conn.commit()

print(conn.execute("SELECT name, price FROM products").fetchall())  # [('Тетрадь', 400)]
conn.close()

commit() туралы ұмытпаңыз. Өзгерістер (INSERT, UPDATE, DELETE) файлға тек conn.commit() шақырылғаннан кейін түседі. Онсыз байланыс жабылғанда деректер жоғалады.

Басты ереже: f-жолдардың орнына параметрлер

Пайдаланушының мәтінін SQL-ға тікелей қойсаңыз, пайдаланушы сұраудың өзін өзгерте алады. Мұны SQL-инъекция деп атайды — сайттардың ең жиі кездесетін осалдықтарының бірі.

Қауіпті: f-жол 
name = "' OR '1'='1"  # так может ввести пользователь

rows = conn.execute(
    f"SELECT * FROM products WHERE name = '{name}'"
).fetchall()
# вернутся ВСЕ товары: условие стало всегда истинным
Қауіпсіз: ? параметрі 
name = "' OR '1'='1"

rows = conn.execute(
    "SELECT * FROM products WHERE name = ?", (name,)
).fetchall()
# вернётся пустой список: товара с таким названием нет

Дәл осы Django ORM арқылы

Django-да кестені класс-модельмен сипаттайды, ал сұрауларды Python әдістерімен жазады. SQL-ды Django өзі құрастырады және мәндерді әрқашан параметр ретінде қояды — мұнда инъекциядан қорқудың қажеті жоқ.

shop/models.py 
from django.db import models

class Product(models.Model):
    name = models.CharField(max_length=100)
    price = models.PositiveIntegerField()
python manage.py shell 
from shop.models import Product

Product.objects.create(name="Тетрадь", price=350)
Product.objects.create(name="Ручка", price=150)

print(Product.objects.filter(price__lt=300).values_list("name", flat=True))  # <QuerySet ['Ручка']>
Product.objects.filter(name="Тетрадь").update(price=400)
Product.objects.filter(name="Ручка").delete()
SQL-дағы және Django ORM-дағы бірдей операциялар
Әрекет SQL ORM Django
Қосу INSERT INTO products (name, price) VALUES (?, ?) Product.objects.create(name=…, price=…)
Шарт бойынша табу SELECT … FROM products WHERE price < 300 Product.objects.filter(price__lt=300)
Өзгерту UPDATE products SET price = 400 WHERE … Product.objects.filter(…).update(price=400)
Жою DELETE FROM products WHERE … Product.objects.filter(…).delete()

Миграциялар: модель қалай кестеге айналады

Миграция — «дерекқорды қалай өзгерту керек» деген нұсқауы бар файл. Django оны модельдердегі өзгерістер бойынша жасап, содан кейін қолданады. Сөйтіп дерекқор құрылымы әрқашан кодпен сәйкес келеді, оны басқа компьютерде қайталау оңай.

Терминал 
python manage.py makemigrations   # создать миграцию по моделям
python manage.py migrate          # применить её к базе
python manage.py sqlmigrate shop 0001   # показать SQL миграции
Django жасаған SQL 
CREATE TABLE "shop_product" (
    "id" integer NOT NULL PRIMARY KEY AUTOINCREMENT,
    "name" varchar(100) NOT NULL,
    "price" integer unsigned NOT NULL CHECK ("price" >= 0)
);

Назар аударыңыз: PositiveIntegerField CHECK ("price" >= 0) тексерісіне айналды — теріс бағаны сақтауға дерекқордың өзі жол бермейді. Нәтиже Django 6.1 және SQLite-та sqlmigrate командасымен алынған.

Қандай дерекқорды таңдау керек

Дерекқор ауысқанда ORM-мен жазылған код дерлік өзгермейді — қосылу баптаулары ғана өзгереді.

Python жобаларына арналған танымал дерекқорлар
Дерекқор Қашан қолдану керек Ерекшеліктері
SQLite Оқу жобалары, прототиптер, шағын сайттар Бір файл, Python-ға кірістірілген, Django-дағы әдепкі дерекқор
PostgreSQL Пайдаланушылары бар нақты жобалар Бөлек сервер, бір мезгілдегі сұраулар кезінде сенімді жұмыс
MySQL / MariaDB Хостинг оны ұсынғанда Бөлек сервер, хостингтерде кең таралған

Flask-та өз ORM-ы жоқ. Flask-тағы жобаның екінші қадамындағыдай SQL-ды sqlite3 арқылы жазуға немесе Flask-SQLAlchemy кеңейтуін қосуға болады.

Өзіңізді тексеріңіз

Бөлім бойынша төрт сұрақ. Жауап бергеннен кейін түсіндірме шығады.

1. Қай SQL командасы бар жазбаларды өзгертеді?

UPDATE бар жолдарды өзгертеді, INSERT жаңаларын қосады, SELECT тек оқиды.

2. Пайдаланушы енгізген мәтінді sqlite3 сұрауына қалай қауіпсіз қоюға болады?

Параметрлер сұрау мәтінінен бөлек беріледі, сондықтан пайдаланушы енгізгені SQL-ды өзгерте алмайды. F-жол мен жолдарды қосу SQL-инъекцияға жол ашады.

3. Django моделіне өріс қостыңыз. Кесте өзгеруі үшін не істеу керек?

makemigrations модельдің өзгерістері бойынша миграция файлын жасайды, migrate оны дерекқорға қолданады. Дерекқорды жоюдың қажеті жоқ — деректер сақталады.

4. sqlite3-тегі өзгерістер неге сақталмауы мүмкін?

Өзгертетін сұраулар транзакцияда орындалады және файлға тек commit() кейін жазылады.

Дереккөздер

Мысалдар Python 3.13, SQLite және Django 6.1.3-те тексерілді, 06.11.2026.

  • Python: sqlite3 модулі — қосылу, параметрлер, транзакциялар
  • Django 6.1: модельдер — өрістер мен байланыстар
  • Django 6.1: ORM арқылы сұраулар — filter, update, delete
  • Django 6.1: миграциялар
  • OWASP: SQL-инъекция — осалдықтың сипаттамасы
