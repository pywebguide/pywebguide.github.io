Басты бет / Үлгілер мен формалар

Сервер беттерді қалай құрады

Үлгі — деректерге арналған орындары бар HTML. Форма — пайдаланушыдан деректер алу тәсілі. Екі тетікті де талдаймыз; «Іске қосу» батырмасы бар мысалдар тікелей браузерде орындалады.

Jinja үлгілері

Flask Jinja-ны қолданады, ал Django-ның үлгі тілі оған өте ұқсас.

  • {{ мән }} деректерді шығарады және HTML-ді автоматты түрде экрандайды.
  • {% if %} және {% for %} шарттар мен циклдерді қосады.
  • {% extends %} және {% block %} барлық беттерге ортақ қаңқа береді.
Flask: үлгідегі цикл және шарт 
from flask import Flask, render_template_string

app = Flask(__name__)

PAGE = """
<h1>Задачи: {{ tasks|length }}</h1>
{% for task in tasks %}
  <p>{{ loop.index }}. {{ task.title }}{% if task.done %} (готово){% endif %}</p>
{% else %}
  <p>Задач пока нет</p>
{% endfor %}
"""

@app.route("/")
def index():
    tasks = [
        {"title": "Купить ракетку", "done": True},
        {"title": "Прочитать про шаблоны", "done": False},
    ]
    return render_template_string(PAGE, tasks=tasks)

print(app.test_client().get("/").text)

test_client() қосымшаға нақты серверсіз сұрау жібереді. Тесттер де дәл осылай жазылады.

Үлгілердің мұрагерлігі

Тақырып пен төменгі бөлік бір рет сипатталады, ал беттер тек өз блогын ауыстырады.

templates/base.html 
<!doctype html>
<html lang="ru">
<head><title>{% block title %}Сайт{% endblock %}</title></head>
<body>
  <nav><a href="/">Главная</a></nav>
  {% block content %}{% endblock %}
</body>
</html>
templates/index.html 
{% extends "base.html" %}

{% block title %}Задачи{% endblock %}

{% block content %}
  <h1>Мои задачи</h1>
{% endblock %}

Flask-та файлдар templates қалтасында жатады, ал бетті render_template("index.html") қайтарады. Django-да дәл осыны render(request, "index.html") жасайды.

Экрандау неге маңызды

Пайдаланушының мәтінін сол күйінде шығарсаңыз, ол бетке өз скриптін енгізе алады. Мұны XSS деп атайды.

Экрандау және қауіпті safe сүзгісі 
from flask import Flask, render_template_string, request

app = Flask(__name__)

@app.route("/")
def index():
    name = request.args.get("name", "гость")
    safe = render_template_string("<p>{{ name }}</p>", name=name)
    danger = render_template_string("<p>{{ name|safe }}</p>", name=name)
    return f"Правильно: {safe}\nОпасно:    {danger}"

response = app.test_client().get("/", query_string={"name": "<script>alert(1)</script>"})
print(response.text)

|safe сүзгісі қорғанысты өшіреді. Оны тек өзіңіз жазған HTML үшін қолданыңыз.

Flask-тағы формалар

Форма деректері request.form ішінде жатады. Сервер оларды өзі тексеруге міндетті: браузердегі тексерістерді айналып өту оңай.

Flask: форма деректерін тексеру 
from flask import Flask, redirect, render_template_string, request, url_for

app = Flask(__name__)
tasks = []

PAGE = """
{% if error %}<p>{{ error }}</p>{% endif %}
<form method="post"><input name="title"><button>Добавить</button></form>
<ul>{% for task in tasks %}<li>{{ task }}</li>{% endfor %}</ul>
"""

@app.route("/", methods=["GET", "POST"])
def index():
    error = None
    if request.method == "POST":
        title = request.form.get("title", "").strip()
        if not title:
            error = "Введите название"
        elif len(title) > 100:
            error = "Слишком длинное название"
        else:
            tasks.append(title)
            return redirect(url_for("index"))
    return render_template_string(PAGE, tasks=tasks, error=error)

client = app.test_client()
print("Пустая форма:", "Введите название" in client.post("/", data={"title": " "}).text)
response = client.post("/", data={"title": "Первая задача"})
print("После добавления статус:", response.status_code, "переход на", response.location)
print("Задачи:", tasks)

Сәтті POST-тан кейін қайта бағыттау жіберіңіз. Әйтпесе бетті жаңартқанда браузер жіберуді қайталайды да, тапсырма тағы бір рет қосылады.

CSRF-тен қорғану

Бөгде сайт кірген пайдаланушының атынан форманы байқатпай жіберуі мүмкін. Қорғаныс — әр формадағы құпия токен.

Django

Қорғаныс әдепкі бойынша қосулы. POST бар әр формаға {% csrf_token %} тегін қосу керек, әйтпесе сервер 403 қатесімен жауап береді.

Flask

Кірістірілген қорғаныс жоқ. Әдетте Flask-WTF кеңейтуін қосады: CSRFProtect(app) және формадағы токені бар жасырын өріс.

Django-дағы формалар

Форма класы өрістерді сипаттайды, деректерді тексереді және өзін HTML түрінде шығара алады.

tasks/forms.py 
from django import forms

class TaskForm(forms.Form):
    title = forms.CharField(label="Задача", max_length=100)
tasks/views.py 
from django.shortcuts import redirect, render

from .forms import TaskForm
from .models import Task

def index(request):
    form = TaskForm(request.POST or None)
    if form.is_valid():
        Task.objects.create(title=form.cleaned_data["title"])
        return redirect("index")
    return render(request, "index.html", {"form": form, "tasks": Task.objects.all()})
templates/index.html 
<form method="post">
  {% csrf_token %}
  {{ form.as_p }}
  <button>Добавить</button>
</form>
