Басты бет / Жариялау

Сайтты интернетке қалай шығаруға болады

Сервер сіздің компьютеріңізде іске қосылып тұрғанда, сайтты тек сіз көресіз. Алғашқы жобадағы тапсырмалар тізімін PythonAnywhere хостингінде қалай тегін жариялау керегін талдаймыз — ол арнайы Python үшін жасалған және серверді баптауды қажет етпейді.

Не шығады және қандай шектеулер бар

Жариялағаннан кейін қосымша https://ваш-логин.pythonanywhere.com мекенжайында ашылады.

Тегін Beginner тарифі

  • логин.pythonanywhere.com мекенжайындағы бір веб-қосымша
  • Дискіде 512 МБ — SQLite бар оқу жобасына артығымен жетеді
  • Қосымша бір ай жұмыс істейді; содан кейін оны Web қойындысындағы батырмамен ұзарту керек
  • Кодтан интернетке шығу — тек рұқсат етілген тізімдегі сайттарға
  • Консольдердегі кодқа күніне 100 секунд процессор уақыты; сайттың өз жұмысына олар жұмсалмайды

Әрекеттер реті

  1. Кодты GitHub-қа шығару
  2. Оны PythonAnywhere-ге көшіріп, тәуелділіктерді орнату
  3. Веб-қосымша жасап, WSGI-файлды көрсету
  4. Django үшін — мекенжай мен статикалық файлдарды баптау
  5. Reload батырмасын басып, сайтты ашу

Тариф шарттары PythonAnywhere анықтамасынан 2026 жылғы қарашада алынған және өзгеруі мүмкін — өзекті деректер беттің төменгі жағындағы дереккөздерде бар.

Қадамдық нұсқаулық

Командаларда username сөзін PythonAnywhere-дегі логиніңізге, ал USER/REPO мәтінін GitHub-тағы репозиторийіңіздің мекенжайына ауыстырыңыз.

  1. 1-қадам. Жобаны дайындап, GitHub-қа шығарыңыз

    requirements.txt файлы жобаның кітапханаларын тізіп шығады — сервер соның бойынша дәл соларды орнатады. .gitignore файлы репозиторийге ортаны және жергілікті дерекқорды жіберуге жол бермейді. Репозиторийді github.com сайтында алдын ала жасаңыз.

    Терминал (жоба қалтасында) 
    pip freeze > requirements.txt
git init
git add .
git commit -m "Первый проект: список задач"
git branch -M main
git remote add origin https://github.com/USER/REPO.git
git push -u origin main
    .gitignore 
    .venv/
__pycache__/
*.db
db.sqlite3
static/

  2. 2-қадам. Кодты PythonAnywhere-ге көшіріңіз

    pythonanywhere.com сайтында тіркеліп (Beginner тарифі), Consoles қойындысын ашыңыз да, Bash іске қосыңыз. mkvirtualenv командасы ортаны жасап, оны бірден іске қосады.

    Терминал (PythonAnywhere-дегі Bash консолі) 
    git clone https://github.com/USER/REPO.git mysite
mkvirtualenv --python=/usr/bin/python3.13 mysite-venv
cd mysite
pip install -r requirements.txt

    Python 3.13 тек innit жүйелік бейнесінде бар. Команда python3.13 табылмады деп жазса, Account бетіндегі System image қойындысын ашып, innit таңдаңыз.

  3. 3-қадам. Веб-қосымша жасаңыз

    Web қойындысында Add a new web app батырмасын басып, Manual configuration таңдаңыз (Flask немесе Django-ның дайын үлгісін емес — ол бос жоба жасайды) және сол Python 3.13 нұсқасын таңдаңыз. Содан кейін Virtualenv бөлімінде mysite-venv атауын жазыңыз — жол өзі толықтырылады.

  4. 4-қадам. WSGI-файлды баптаңыз

    WSGI-файл серверге қосымшаңыздың қай жерде жатқанын түсіндіреді. Web қойындысындағы Code бөлімінде оған сілтемені ашып, бүкіл мазмұнын өшіріңіз де, өз фреймворкіңізге арналған нұсқаны қойыңыз.

    WSGI-файл: Flask 
    import sys

path = "/home/username/mysite"
if path not in sys.path:
    sys.path.insert(0, path)

from app import app as application
    WSGI-файл: Django 
    import os
import sys

path = "/home/username/mysite"
if path not in sys.path:
    sys.path.insert(0, path)

os.environ["DJANGO_SETTINGS_MODULE"] = "mysite.settings"

from django.core.wsgi import get_wsgi_application
application = get_wsgi_application()

    from app import app жолы «app.py файлынан app объектісін алу» дегенді білдіреді. Файлыңыздың атауы басқаша болса, бірінші сөзді түзетіңіз.

  5. 5-қадам. Тек Django үшін: мекенжай, дерекқор және статика

    mysite/settings.py файлында жөндеу режимін өшіріп, өз мекенжайыңызға рұқсат беріңіз де, статикалық файлдарға арналған қалтаны көрсетіңіз — онсыз әкімші панелі безендірусіз ашылады. Содан кейін командаларды Bash консолінде орындаңыз.

    mysite/settings.py 
    DEBUG = False

ALLOWED_HOSTS = ["username.pythonanywhere.com"]

STATIC_ROOT = BASE_DIR / "static"
    Терминал (PythonAnywhere-дегі Bash консолі) 
    cd ~/mysite
workon mysite-venv
python manage.py migrate
python manage.py collectstatic
python manage.py createsuperuser

    Web қойындысындағы Static files бөлімінде жол қосыңыз: URL /static/, Directory /home/username/mysite/static.

  6. 6-қадам. Қайта іске қосып, тексеріңіз

    Web қойындысындағы жасыл Reload батырмасын басып, https://username.pythonanywhere.com мекенжайын ашыңыз. Сайттың орнына қате шықса, сол қойындыдағы Error log ашыңыз — соңғы жол әдетте себебін айтады.

Сайтты қалай жаңарту керек және неден аулақ болу керек

Терминал: кодты өзгерткеннен кейін жаңарту 
cd ~/mysite
git pull
# для Django, если менялись модели:
python manage.py migrate
# затем кнопка Reload на вкладке Web

Қауіпсіздік

  • Серверде DEBUG = True қалдырмаңыз: қате болғанда келушілер баптауларды және код үзінділерін көреді.
  • settings.py ішіндегі SECRET_KEY ашық репозиторийде жатпауы керек — оны орта айнымалысында сақтаңыз.
  • Нақты деректері бар дерекқорды GitHub-қа жібермеңіз — ол үшін .gitignore ішінде *.db бар.
