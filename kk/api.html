Басты бет / REST API

REST API: сайт деректерді береді

Сервер бетпен емес, деректермен жауап бергенде API керек: JavaScript-тегі сайтқа, мобильді қосымшаға немесе басқа бағдарламаға.

REST-тің негізгі ережелері

Мекенжай деректерді, ал HTTP әдісі олармен жасалатын әрекетті білдіреді.

Тапсырмалар тізіміне арналған HTTP әдістері
СұрауНе істейдіСәтті жауап
GET /tasksТізімді қайтарады200 OK
POST /tasksТапсырма жасайды201 Created
GET /tasks/5Бір тапсырманы қайтарады200 OK
PATCH /tasks/5Өрістердің бір бөлігін өзгертеді200 OK
DELETE /tasks/5Жояды204 No Content

Жауап кодтары

Клиент алдымен кодқа қарайды, содан кейін ғана жауаптың денесін оқиды.

Бәрі жақсы немесе клиент қатесі

  • 200 — сәтті
  • 201 — жасалды
  • 204 — сәтті, жауап денесі жоқ
  • 400 — деректер қате
  • 401 — кіру керек
  • 403 — құқық жоқ
  • 404 — табылмады

Сервер қатесі

  • 500 — қосымша кодындағы қате
  • 502 — веб-сервер қосымшадан дұрыс жауап алмады
  • 503 — сервис уақытша қолжетімсіз

5xx қатесі себепті сұраудан емес, серверден іздеу керек екенін білдіреді.

Flask-тағы API

Flask сөздікті JSON-ға өзі айналдырады. Тізімді jsonify арқылы берген дұрыс.

Flask: тапсырмалар тізімі бар JSON API 
from flask import Flask, jsonify, request

app = Flask(__name__)
tasks = {}
next_id = 1

@app.get("/tasks")
def list_tasks():
    return jsonify(list(tasks.values()))

@app.post("/tasks")
def create_task():
    global next_id
    data = request.get_json(silent=True) or {}
    title = str(data.get("title", "")).strip()
    if not title:
        return {"error": "Поле title обязательно"}, 400
    task = {"id": next_id, "title": title, "done": False}
    tasks[next_id] = task
    next_id += 1
    return task, 201

@app.patch("/tasks/<int:task_id>")
def update_task(task_id):
    task = tasks.get(task_id)
    if task is None:
        return {"error": "Задача не найдена"}, 404
    data = request.get_json(silent=True) or {}
    if "done" in data:
        task["done"] = bool(data["done"])
    return task

@app.delete("/tasks/<int:task_id>")
def delete_task(task_id):
    if tasks.pop(task_id, None) is None:
        return {"error": "Задача не найдена"}, 404
    return "", 204

client = app.test_client()
print(client.post("/tasks", json={}).status_code, "пустая задача")
created = client.post("/tasks", json={"title": "Написать API"})
print(created.status_code, created.json)
print(client.patch("/tasks/1", json={"done": True}).json)
print(client.get("/tasks").json)
print(client.delete("/tasks/1").status_code, "удалена")
print(client.delete("/tasks/1").status_code, "повторное удаление")

Django-дағы API

Қарапайым JSON жауабын кірістірілген құралдармен беруге болады. Үлкен API үшін әдетте Django REST framework алады.

tasks/views.py 
import json

from django.http import JsonResponse
from django.views.decorators.csrf import csrf_exempt
from django.views.decorators.http import require_http_methods

from .models import Task

@csrf_exempt  # только для учебного примера: настоящему API нужна авторизация
@require_http_methods(["GET", "POST"])
def tasks(request):
    if request.method == "POST":
        try:
            data = json.loads(request.body)
            title = str(data.get("title", "")).strip()
        except (json.JSONDecodeError, AttributeError):
            return JsonResponse({"error": "Неверный JSON"}, status=400)
        if not title:
            return JsonResponse({"error": "Поле title обязательно"}, status=400)
        task = Task.objects.create(title=title)
        return JsonResponse({"id": task.id, "title": task.title}, status=201)
    return JsonResponse(list(Task.objects.values("id", "title")), safe=False)

safe=False параметрі керек, өйткені әдепкі бойынша JsonResponse тек сөздікті қабылдайды.

API-ды браузерден қалай шақыруға болады

Бетте мұны fetch функциясы жасайды. Жауап кодын тексеріңіз: fetch 404-ті қате деп санамайды.

JavaScript 
async function addTask(title) {
  const response = await fetch("/tasks", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ title }),
  });

  if (!response.ok) {
    const problem = await response.json();
    throw new Error(problem.error);
  }

  return response.json();
}

Сайт пен API әртүрлі мекенжайларда болса, сервер CORS тақырыптарымен рұқсат бермейінше, браузер жауапты бұғаттайды. Flask-та бұл үшін Flask-CORS кеңейтуі бар.

Мұнда FastAPI қайда

Жоба тек API болса, FastAPI-ға қараңыз: ол деректерді тип кеңестері бойынша тексеріп, құжаттаманы өзі жасайды. REST қағидаттары сол күйі қалады.
