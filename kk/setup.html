Компьютерді дайындау

Алғашқы жобаға дейінгі екі сабақ: Python мен код редакторын қалай орнату керек және терминалдан қалай қорықпау керек. Командалар Windows үшін және macOS пен Linux үшін берілген, өз жүйеңізді таңдаңыз.

Бір нәрсе шықпаса, алғашқы жобаның жиі кездесетін қателерін қараңыз. Таныс емес сөздер сөздікте бар.

2 сабақтың 0 өтілді

  1. 1-сабақ. Python мен код редакторын орнату

    Не үшін. Сабақтарда код тікелей браузерде жұмыс істеді. Ал Flask немесе Django-дағы өз сайтыңызды өз компьютеріңізде іске қосасыз. Ол үшін екі бағдарлама керек: Python-ның өзі және код жазуға ыңғайлы редактор.

    Python. Орнатушыны ресми python.org сайтынан жүктеңіз, 3.12 немесе одан жаңа нұсқасын. Тек сол жерден жүктеңіз: басқа сайттарда Python деп вирус беріп жіберуі мүмкін.

    Windows-тағы ең маңызды нәрсе. Орнатушының бірінші экранында «Add python.exe to PATH» белгісін қойыңыз, содан кейін «Install Now» батырмасын басыңыз. Бұл белгісіз терминалдағы python командасы жұмыс істемейді.

    macOS-та Python-ды сол сайттағы орнатушымен орнатыңыз. Linux-та ол әдетте бұрыннан бар: төмендегі командамен тексеріңіз.

    Орнатуды тексеріңіз. Терминалды ашыңыз (мұны қалай істеу — келесі сабақта) және өз жүйеңіздің қойындысындағы команданы орындаңыз. Нұсқа шығуы керек, мысалы Python 3.13.1.

    Код редакторы. Ыңғайлы тегін редактор — Visual Studio Code. Орнатқаннан кейін ондағы кеңейтімдер бөлімін ашыңыз (сол жақтағы төрт шаршы белгісі) және Microsoft-тың Python кеңейтімін орнатыңыз. Ол кодты түрлі түспен бөліп, қателерді көрсетеді.

    Компьютердегі алғашқы бағдарлама. Бос бума жасаңыз, мысалы pyweb, және оны VS Code-та ашыңыз: «File → Open Folder». hello.py файлын жасап, print("Менің компьютерімнен сәлем!") деп жазыңыз да, оң жақ жоғарыдағы ▶ үшбұрышын басыңыз. Нәтиже төменде, терминалда пайда болады.

    Жиі қате: «Python was not found»

    Windows-та python командасы Microsoft Store-ды ашады немесе мынаны жазады: Python was not found; run without arguments to install from the Microsoft Store… Демек, орнату кезінде PATH белгісі қойылмаған. Орнатушыны қайта іске қосып, «Modify» таңдаңыз да, «Add Python to environment variables» белгісін қойыңыз. Немесе python орнына py командасын қолданыңыз: ол Python-мен бірге орнатылады.

    Жиі қате: macOS-тағы «command not found: python»

    macOS пен Linux-та команда көбіне python емес, python3 деп аталады. python3 --version және python3 hello.py деп жазыңыз.

    Өзіңізді тексеріңіз:

    • төмендегі қойындыдағы команда 3.12 немесе одан жаңа нұсқаны көрсетеді;
    • VS Code-та Python кеңейтімі орнатылған;
    • hello.py файлы іске қосылып, сәлемдесу сөзін шығарады.

    Windows (PowerShell немесе пәрмен жолы)

    Терминал: нұсқаны тексеру 
    python --version
py --version

    macOS және Linux (Терминал)

    Терминал: нұсқаны тексеру 
    python3 --version
    hello.py файлы 
    print("Менің компьютерімнен сәлем!")
print("Python жұмыс істеп тұр.")

  2. 2-сабақ. Терминалдан қорықпаңыз

    Не үшін. Бағдарламашылар компьютерді көбіне тінтуірмен емес, командалармен басқарады: кітапханаларды орнатады, серверді іске қосады, жобалар жасайды. Мұның бәрі терминалда істеледі. Алғашқы жобада ол бірінші қадамнан бастап керек болады.

    Терминал деген не. Бұл — команданы сөзбен жазып, Enter басатын терезе, ал компьютер оны орындап, жауап жазады. Онымен компьютерді абайсызда бұзу өте қиын: осы курстағы командалар қауіпсіз.

    Қалай ашуға болады. Ең оңайы — тікелей VS Code-та: «Terminal → New Terminal» мәзірі немесе Ctrl + ` пернелері. Бөлек: Windows-та «Пуск» батырмасын басып, «PowerShell» деп теріңіз, macOS-та «Терминал» бағдарламасын ашыңыз.

    Сіз қай жердесіз. Терминал әрқашан қандай да бір бумада жұмыс істейді, оның жолы жолдың басында жазылған. Командалар дәл сол жерде орындалады. Бағдарлама «файлды таппаса», көбіне сіз жай ғана басқа бумадасыз.

    Бес негізгі команда:

    • cd бума — бумаға өту, cd .. — бір деңгей жоғары көтерілу;
    • ls (ескі Windows командалық жолында — dir) — бумадағы файлдарды көрсету;
    • mkdir атау — бума жасау;
    • python hello.py — бағдарламаны іске қосу (macOS-та — python3);
    • Ctrl + C — жұмыс істеп тұрған бағдарламаны, мысалы серверді тоқтату.

    Уақытты үнемдейтін екі кеңес. Жоғары бағыттауыш алдыңғы команданы қайтарады, оны қайта терудің қажеті жоқ. Tab пернесі файлдың немесе буманың атауын алғашқы әріптері бойынша толықтырады.

    Жиі қате: файл табылмады

    python hello.py командасы мынадай жауап береді: can't open file 'hello.py': [Errno 2] No such file or directory Демек, сіз басқа бумадасыз. Файлдарды ls командасымен қарап, cd арқылы керек бумаға өтіңіз. VS Code-та терминал бірден жоба бумасында ашылады.

    Жиі қате: бума атауындағы бос орындар

    cd Менің жобаларым жұмыс істемейді: терминал мұны екі бөлек бөлік деп ойлайды. Жолды тырнақшаға алыңыз: cd "Менің жобаларым". Ал ең дұрысы — жоба бумаларын бос орынсыз және латын әріптерімен атаңыз: my-site.

    Өзіңізді тексеріңіз:

    • VS Code-та терминалды ашып, буманың жолын көріп тұрсыз;
    • mkdir командасымен бума жасап, оған cd арқылы өттіңіз;
    • hello.py файлын батырмамен емес, терминалдағы командамен іске қостыңыз.

    Windows (PowerShell)

    Терминал: алғашқы қадамдар 
    mkdir my-site
cd my-site
ls
python hello.py
cd ..

    macOS және Linux (Терминал)

    Терминал: алғашқы қадамдар 
    mkdir my-site
cd my-site
ls
python3 hello.py
cd ..

    Өткен сабақтағы hello.py файлын my-site бумасына салыңыз, әйтпесе іске қосу командасы оны таппайды. Дәл осы — осы сабақтағы «жиі қате».
