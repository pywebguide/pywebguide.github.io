Политика конфиденциальности

Коротко: у сайта нет своей базы данных. Отправленные через форму сообщения публикуются на GitHub и видны всем, а хостинг записывает IP-адреса посетителей. У отдельной версии с аккаунтом есть сервер, и что он хранит, описано ниже.

Кто отвечает за сайт

PyWeb Guide — учебный проект. Автор: Жангужин Е. Е. Связаться с ним можно через раздел Issues на GitHub; сообщения там видны публично, поэтому не указывайте в них личные данные. Без аккаунта GitHub можно написать напрямую: такое письмо видит только автор.

Что хранится в вашем браузере

Сайт использует localStorage — хранилище вашего браузера. На сервер эти записи не передаются, и автор их не видит:

  • pyweb_messages — копии сообщений из формы на странице «Контакты»;
  • pyweb_progress — отмеченные шаги обучения;
  • pyweb_theme — выбранная тема оформления;
  • pyweb_tasks и pyweb_task_* — решённые задачи и черновики решений;
  • pyweb_playground — черновик кода в песочнице;
  • pyweb_exam — лучший результат финального теста;
  • pyweb_os — какую систему (Windows или macOS и Linux) вы выбрали во вкладках с командами.

Сообщения удаляет кнопка «Очистить сохранённые сообщения» на странице «Контакты». Всё остальное, включая кэш, удаляется очисткой данных этого сайта в настройках браузера.

Кроме того, браузер сохраняет копии страниц, стилей, скриптов и файлов Python в своём кэше (Cache Storage), чтобы сайт открывался без интернета и быстрее. Это обычные файлы сайта, ваших данных в них нет.

Файл прогресса со страницы «Мой прогресс» создаётся прямо в браузере и содержит только отметки. Имя для сертификата не сохраняется: лист для печати собирается в браузере и никуда не отправляется.

Что происходит при отправке формы

Форма открывает страницу создания записи в Issues на GitHub с вашим именем и текстом. Пока вы не подтвердите создание на GitHub, ничего не публикуется. После этого сообщение и ваш профиль GitHub видны всем, а обрабатывает их GitHub по своим правилам.

Что записывает хостинг

Сайт размещён на GitHub Pages. По данным GitHub, при посещении сайта IP-адрес посетителя записывается и хранится в целях безопасности. Источник — справка GitHub Pages, подробности — в политике конфиденциальности GitHub.

Версия с аккаунтом

Курс можно проходить и в отдельной версии с аккаунтом по адресу pywebguide.pythonanywhere.com. Аккаунт нужен только для переноса прогресса между устройствами: без него курс работает так же. Эта версия хранит на своём сервере:

  • логин и пароль, если вы зарегистрировались. Пароль хранится только в виде хеша, и прочитать его не может никто, включая автора;
  • ваш прогресс: отмеченные шаги, решённые задачи и лучший результат финального теста. Они сохраняются, только пока вы вошли в аккаунт;
  • сообщения из формы на странице «Контакты»: имя, текст, дату и аккаунт, если вы вошли. Их видит только автор, публично они не появляются;
  • неудачные попытки входа: логин, IP-адрес и браузер. Это защита от подбора пароля: после пяти ошибок вход блокируется на час, а после успешного входа счётчик сбрасывается. Успешные входы не записываются.

Чтобы ограничить число сообщений из формы, сервер в течение часа помнит, сколько их пришло с вашего IP-адреса. Это число хранится только в памяти сервера, а не в базе.

Эта версия ставит два технических cookie: sessionid, чтобы помнить вход (до двух недель), и csrftoken, чтобы защитить формы от подделки. Рекламных и отслеживающих cookie нет.

Сервер размещён на PythonAnywhere, его серверы находятся в США. Как и любой хостинг, он записывает в журналы IP-адрес и браузер посетителей.

Чтобы удалить аккаунт вместе с прогрессом или удалить свои сообщения, войдите в аккаунт и напишите об этом через форму на странице «Контакты» этой версии. Автор удалит данные.

Запуск Python в браузере

Только после нажатия кнопки запуска или проверки кода браузер загружает Python (Pyodide) с сервиса jsDelivr, а для примеров с Flask ещё и пакеты с PyPI. Эти сервисы, как любой сайт, получают ваш IP-адрес и данные браузера. Сам код выполняется на вашем устройстве и никуда не отправляется. Имя для сертификата тоже остаётся в браузере и не сохраняется.

Cookies и статистика посещений

Сайт не устанавливает cookies и не показывает рекламу. Технические cookie версии с аккаунтом описаны выше.

Чтобы понимать, какие страницы читают и где бросают курс, сайт считает посещения через GoatCounter. Он не использует cookies и не узнаёт вас при следующих визитах. Учитываются адрес и заголовок открытой страницы, сайт, с которого вы пришли, страна по IP-адресу, размер экрана, браузер и операционная система. Сам IP-адрес не хранится. Подробности — в политике GoatCounter.

Тем же способом сайт считает учебные события: урок или шаг отмечен пройденным, код запущен в первый раз, задача решена. Имён и ответов в них нет, а передаются те же сведения, что и при открытии страницы. Чтобы не считать событие дважды, список уже отправленных событий хранится в вашем браузере (ключ pyweb_events).

Если в браузере включён запрет отслеживания или блокировщик рекламы, посещение может не учитываться, и сайт от этого работает так же.

Поиск по сайту

Поиск работает в вашем браузере: индекс загружается с этого же сайта, а запросы никуда не отправляются.

Внешние ссылки

На сайте есть ссылки на документацию и другие внешние ресурсы. После перехода действуют правила этих ресурсов.
