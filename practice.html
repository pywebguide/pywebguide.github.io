1. Приветствие

Уровень: Лёгкая

Напишите функцию greet(name), которая возвращает строку Привет, Имя!. Лишние пробелы вокруг имени нужно убрать. Если имя пустое, верните Привет, гость!.

  1. Подсказка 1. Склеить текст с переменной проще всего f-строкой: f"Привет, {name}!".
  2. Подсказка 2. Пробелы по краям убирает name.strip().
  3. Подсказка 3. Пустая строка в условии считается ложью: name or 'гость' вернёт «гость», если имя пустое.
Показать решение
def greet(name):
    name = name.strip()
    return f"Привет, {name or 'гость'}!"

2. Подсчёт слов

Уровень: Лёгкая

Напишите count_words(text): верните словарь, где ключ — слово в нижнем регистре, а значение — сколько раз оно встретилось.

  1. Подсказка 1. Начните с пустого словаря counts = {} и пройдите циклом по словам.
  2. Подсказка 2. text.lower().split() переводит текст в нижний регистр и делит его по любым пробелам и переносам строк.
  3. Подсказка 3. counts.get(word, 0) + 1 увеличивает счётчик, даже если слова ещё нет в словаре.
Показать решение
def count_words(text):
    counts = {}
    for word in text.lower().split():
        counts[word] = counts.get(word, 0) + 1
    return counts

3. Надёжный пароль

Уровень: Лёгкая

Напишите is_strong(password). Пароль надёжный, если в нём не меньше 8 символов, есть хотя бы одна цифра и хотя бы одна буква. Верните True или False.

  1. Подсказка 1. Длину строки даёт len(password).
  2. Подсказка 2. any(ch.isdigit() for ch in password) вернёт True, если в пароле есть цифра.
  3. Подсказка 3. Для букв есть ch.isalpha(). Соедините три условия через and.
Показать решение
def is_strong(password):
    has_digit = any(ch.isdigit() for ch in password)
    has_letter = any(ch.isalpha() for ch in password)
    return len(password) >= 8 and has_digit and has_letter

4. Адрес из заголовка

Уровень: Средняя

Сайты превращают заголовок статьи в часть адреса: Мой первый сайт → moy-pervyy-sayt. Напишите slugify(title) для латиницы: оставьте буквы и цифры в нижнем регистре, всё остальное замените дефисом. Несколько дефисов подряд склейте в один, дефисы по краям уберите.

  1. Подсказка 1. Пройдите по символам title.lower(): буква или цифра (ch.isalnum()) остаётся, остальное становится "-".
  2. Подсказка 2. Склеить части без лишних дефисов поможет "-".join(...) по непустым кускам после split("-").
  3. Подсказка 3. Если пишете через модуль re: re.sub(r"[^a-z0-9]+", "-", text).strip("-").
Показать решение
def slugify(title):
    chars = [ch if ch.isalnum() else "-" for ch in title.lower()]
    parts = "".join(chars).split("-")
    return "-".join(part for part in parts if part)

5. Сумма покупок

8. Самое длинное слово

Уровень: Средняя

Напишите longest(words): верните самое длинное слово из списка. Если таких несколько, верните первое из них. Для пустого списка верните пустую строку.

  1. Подсказка 1. Храните лучшее слово в переменной best = "" и сравнивайте длины через len().
  2. Подсказка 2. Чтобы при равной длине осталось первое слово, сравнивайте строго: len(word) > len(best).
Показать решение
def longest(words):
    best = ""
    for word in words:
        if len(word) > len(best):
            best = word
    return best

9. Без повторов

Уровень: Средняя

Напишите unique(items): верните список без повторов. Порядок первых появлений должен сохраниться.

  1. Подсказка 1. Проверить, есть ли элемент в списке, можно через item not in result.
  2. Подсказка 2. Через set() повторы уйдут, но порядок может измениться, поэтому здесь нужен цикл.
Показать решение
def unique(items):
    result = []
    for item in items:
        if item not in result:
            result.append(item)
    return result

10. Инициалы

Уровень: Средняя

  1. Подсказка 1. full_name.split() делит строку на слова и сам убирает лишние пробелы.
  2. Подсказка 2. Первая буква слова — part[0], заглавной её делает .upper(). Соберите части через " ".join(...).

    parts = full_name.split()
    return " ".join(part[0].upper() + "." for part in parts)

11. Разбор адреса

Уровень: Средняя

Напишите parse_query(query). Она превращает строку a=1&b=2 в словарь {"a": "1", "b": "2"}. Части без знака = пропускайте. Значение может содержать =.

  1. Подсказка 1. Сначала разделите строку на пары: query.split("&").
  2. Подсказка 2. Пару без = пропустите проверкой if "=" in part.
  3. Подсказка 3. part.split("=", 1) делит только по первому знаку =, остальные остаются в значении.
Показать решение
def parse_query(query):
    result = {}
    for part in query.split("&"):
        if "=" in part:
            key, value = part.split("=", 1)
            result[key] = value
    return result

12. Простой маршрутизатор

Уровень: Средняя

Допишите handle(method, path). Она ищет обработчик в словаре ROUTES и возвращает пару «код, текст». Если адреса нет, верните (404, "Not Found"). Если адрес есть, но метод не подходит, верните (405, "Method Not Allowed").

  1. Подсказка 1. Проверьте по порядку: сначала есть ли адрес, потом есть ли метод.
  2. Подсказка 2. path not in ROUTES означает, что такого адреса нет: это 404.
  3. Подсказка 3. Методы адреса лежат в ROUTES[path]. Если метода там нет — 405, иначе верните 200 и текст.
Показать решение
ROUTES = {
    "/": {"GET": "Главная"},
    "/tasks": {"GET": "Список задач", "POST": "Задача создана"},
}

def handle(method, path):
    if path not in ROUTES:
        return 404, "Not Found"
    if method not in ROUTES[path]:
        return 405, "Method Not Allowed"
    return 200, ROUTES[path][method]

13. Проверка данных формы

Уровень: Сложная

Напишите validate_user(data). Функция принимает словарь и возвращает список ошибок. Поле name обязательно, поле age должно быть целым числом от 1 до 120. Тексты ошибок: "name" и "age". Если всё верно, верните пустой список.

  1. Подсказка 1. Поля может не быть: data.get("name", "") вернёт пустую строку вместо ошибки.
  2. Подсказка 2. Целое число проверяет isinstance(age, int), диапазон — 1 <= age <= 120.
  3. Подсказка 3. В Python True тоже считается int. Отсейте его отдельно: isinstance(age, bool).
Показать решение
def validate_user(data):
    errors = []
    if not str(data.get("name", "")).strip():
        errors.append("name")
    age = data.get("age")
    if not isinstance(age, int) or isinstance(age, bool) or not 1 <= age <= 120:
        errors.append("age")
    return errors

14. Ответ в JSON

Уровень: Средняя

Напишите tasks_json(tasks). Функция получает список словарей и возвращает строку JSON только с задачами, у которых done равно False. Кириллица должна остаться читаемой. Импорт уже есть.

15. Свой шаблон

Уровень: Средняя

Шаблон — текст с пропусками. Напишите render(template, data): она заменяет каждый пропуск {{ имя }} на значение из словаря data. Пробелы внутри скобок могут быть или не быть. Если ключа в словаре нет, подставьте пустую строку.

  1. Подсказка 1. Найти все пропуски поможет регулярное выражение r"\{\{\s*(\w+)\s*\}\}".
  2. Подсказка 2. re.sub(шаблон, функция, текст) вызывает функцию для каждого найденного пропуска и подставляет её ответ.
  3. Подсказка 3. Внутри функции имя пропуска лежит в match.group(1), а значение достаёт str(data.get(имя, "")).
Показать решение
import re

def render(template, data):
    def value(match):
        return str(data.get(match.group(1), ""))
    return re.sub(r"\{\{\s*(\w+)\s*\}\}", value, template)

16. Страницы списка

Уровень: Средняя

Длинный список показывают по частям. Напишите paginate(items, page, per_page): верните элементы страницы номер page (нумерация с 1). Если страницы с таким номером нет или номер меньше 1, верните пустой список.

  1. Подсказка 1. Первый элемент страницы стоит на месте (page - 1) * per_page.
  2. Подсказка 2. Срез items[start:start + per_page] сам обрежется, если элементов меньше.
  3. Подсказка 3. Номер страницы меньше 1 проверьте отдельно, иначе отрицательный срез вернёт лишнее.
Показать решение
def paginate(items, page, per_page):
    if page < 1:
        return []
    start = (page - 1) * per_page
    return items[start:start + per_page]

18. Тип файла

Уровень: Средняя

Сервер сообщает браузеру тип файла в заголовке Content-Type. Напишите content_type(filename): для .html верните text/html, для .css — text/css, для .js — text/javascript, для .json — application/json, для остальных — application/octet-stream. Регистр букв в имени не важен.

  1. Подсказка 1. Расширение — это часть после последней точки: filename.rsplit(".", 1)[-1].
  2. Подсказка 2. Приведите имя к нижнему регистру через .lower() и возьмите тип из словаря через .get() с запасным значением.
Показать решение
def content_type(filename):
    types = {"html": "text/html", "css": "text/css", "js": "text/javascript", "json": "application/json"}
    extension = filename.lower().rsplit(".", 1)[-1]
    return types.get(extension, "application/octet-stream")

19. Адрес с параметрами

Уровень: Средняя

Напишите build_url(path, params): добавьте к пути параметры из словаря. Из "/search" и {"q": "flask", "page": 2} должно получиться /search?q=flask&page=2. Если словарь пустой, верните путь без знака вопроса.

  1. Подсказка 1. Пары ключ и значение даёт params.items(). Каждую превратите в строку f"{key}={value}".
  2. Подсказка 2. Соедините пары через "&".join(pairs) и добавьте к пути после знака ?.
Показать решение
def build_url(path, params):
    if not params:
        return path
    pairs = [f"{key}={value}" for key, value in params.items()]
    return path + "?" + "&".join(pairs)

20. Разбор cookie

Уровень: Средняя

Напишите parse_cookie(header): превратите строку заголовка theme=dark; lang=kk в словарь {"theme": "dark", "lang": "kk"}. Для пустой строки верните пустой словарь. В значении может встретиться знак =.

25. Безопасный вывод

Уровень: Средняя

Напишите escape_html(text): замените знак & на &amp;, < на &lt;, > на &gt;. Тогда текст пользователя покажется на странице как текст и не станет тегом.

  1. Подсказка 1. Замену делает text.replace("<", "&lt;"). Результат нужно сохранить: строки не меняются на месте.
  2. Подсказка 2. Начните со знака &. Иначе он заменится второй раз внутри уже готовых &lt;.

def escape_html(text):
    text = text.replace("&", "&amp;")
    text = text.replace("<", "&lt;")

26. Похоже на почту

Уровень: Сложная

Напишите is_email(value): грубая проверка адреса почты. В адресе нет пробелов, ровно один знак @, перед ним есть хотя бы один символ, а после него есть точка, которая стоит не в начале и не в конце.

  1. Подсказка 1. Сколько раз встречается символ, считает value.count("@").
  2. Подсказка 2. Разделите адрес на две части: name, domain = value.split("@"), и проверьте каждую отдельно.
Показать решение
def is_email(value):
    if " " in value or value.count("@") != 1:
        return False
    name, domain = value.split("@")
    if not name or "." not in domain:
        return False
    return not domain.startswith(".") and not domain.endswith(".")

27. Безопасная вставка

Уровень: Средняя

Напишите add_task(db, title): она добавляет строку в таблицу tasks и возвращает её id. Используйте параметр ?: текст с кавычкой не должен ломать запрос.

  1. Подсказка 1. Запрос на вставку: INSERT INTO tasks (title) VALUES (?).
  2. Подсказка 2. Значения передаются вторым аргументом кортежем: db.execute(запрос, (title,)). Запятая после title обязательна.
  3. Подсказка 3. execute возвращает курсор, а номер новой строки лежит в cursor.lastrowid. Не забудьте db.commit().
Показать решение
import sqlite3

db = sqlite3.connect(":memory:")
db.execute("CREATE TABLE tasks (id INTEGER PRIMARY KEY, title TEXT)")

def add_task(db, title):
    cursor = db.execute("INSERT INTO tasks (title) VALUES (?)", (title,))
    db.commit()
    return cursor.lastrowid

28. Выборка с условием

Уровень: Лёгкая

Напишите active_titles(db): верните список заголовков, у которых done = 0, отсортированный по алфавиту.

  1. Подсказка 1. Нужен запрос SELECT title FROM tasks с условием WHERE done = 0.
  2. Подсказка 2. Сортировку по алфавиту даёт ORDER BY title в конце запроса.
  3. Подсказка 3. Каждая строка результата — кортеж, заголовок в нём первый: [row[0] for row in rows].
Показать решение
import sqlite3

db = sqlite3.connect(":memory:")
db.execute("CREATE TABLE tasks (title TEXT, done INTEGER)")
db.executemany("INSERT INTO tasks VALUES (?, ?)", [("Б", 0), ("А", 0), ("В", 1)])

def active_titles(db):
    rows = db.execute("SELECT title FROM tasks WHERE done = 0 ORDER BY title")
    return [row[0] for row in rows]

29. Сколько осталось

Уровень: Лёгкая

Напишите count_active(db): верните число задач, у которых done = 0. Считать должна база, а не Python.

  1. Подсказка 1. Строки считает запрос SELECT COUNT(*) FROM tasks WHERE done = 0.
  2. Подсказка 2. .fetchone() вернёт одну строку-кортеж, число в ней первое: row[0].
Показать решение
import sqlite3

db = sqlite3.connect(":memory:")
db.execute("CREATE TABLE tasks (id INTEGER PRIMARY KEY, title TEXT, done INTEGER)")
db.executemany("INSERT INTO tasks (title, done) VALUES (?, ?)", [("Buy bread", 1), ("Learn Flask", 0), ("Write tests", 0)])

def count_active(db):
    row = db.execute("SELECT COUNT(*) FROM tasks WHERE done = 0").fetchone()
    return row[0]

30. Удалить выполненные

Уровень: Лёгкая

Напишите delete_done(db): удалите все выполненные задачи (done = 1) и верните, сколько строк удалено.

  1. Подсказка 1. Запрос на удаление: DELETE FROM tasks WHERE done = 1.
  2. Подсказка 2. Число удалённых строк лежит в cursor.rowcount. Не забудьте db.commit().
Показать решение
import sqlite3

db = sqlite3.connect(":memory:")
db.execute("CREATE TABLE tasks (id INTEGER PRIMARY KEY, title TEXT, done INTEGER)")
db.executemany("INSERT INTO tasks (title, done) VALUES (?, ?)", [("Buy bread", 1), ("Learn Flask", 0), ("Write tests", 0)])

def delete_done(db):
    cursor = db.execute("DELETE FROM tasks WHERE done = 1")
    db.commit()
    return cursor.rowcount

31. Отметить выполненной

Уровень: Средняя

Напишите mark_done(db, task_id): поставьте задаче с этим номером done = 1. Верните True, если такая задача была, и False, если её нет. Остальные задачи менять нельзя.

  1. Подсказка 1. Запрос на изменение: UPDATE tasks SET done = 1 WHERE id = ?. Без WHERE изменятся все строки.
  2. Подсказка 2. Сколько строк изменилось, показывает cursor.rowcount.
Показать решение
import sqlite3

db = sqlite3.connect(":memory:")
db.execute("CREATE TABLE tasks (id INTEGER PRIMARY KEY, title TEXT, done INTEGER)")
db.executemany("INSERT INTO tasks (title, done) VALUES (?, ?)", [("Buy bread", 1), ("Learn Flask", 0), ("Write tests", 0)])

def mark_done(db, task_id):
    cursor = db.execute("UPDATE tasks SET done = 1 WHERE id = ?", (task_id,))
    db.commit()
    return cursor.rowcount == 1

32. Поиск по тексту

Уровень: Сложная

Напишите search(db, text): верните заголовки задач, в которых встречается text, в порядке id. Текст передавайте через параметр ?, чтобы кавычка в поиске не сломала запрос.

  1. Подсказка 1. Поиск по части строки делает WHERE title LIKE ?, а знак % означает «любые символы».
  2. Подсказка 2. Знаки процента добавьте к значению, а не к запросу: ("%" + text + "%",).
Показать решение
import sqlite3

db = sqlite3.connect(":memory:")
db.execute("CREATE TABLE tasks (id INTEGER PRIMARY KEY, title TEXT, done INTEGER)")
db.executemany("INSERT INTO tasks (title, done) VALUES (?, ?)", [("Buy bread", 1), ("Learn Flask", 0), ("Write tests", 0)])

def search(db, text):
    rows = db.execute("SELECT title FROM tasks WHERE title LIKE ? ORDER BY id", ("%" + text + "%",))
    return [row[0] for row in rows]

33. Первый маршрут

Уровень: Лёгкая

Добавьте маршрут GET /hello/<name>, который возвращает JSON {"message": "Привет, имя!"}.

  1. Подсказка 1. Маршрут объявляют декоратором над функцией: @app.get("/hello/<name>").
  2. Подсказка 2. Имя в угловых скобках адреса и имя аргумента функции должны совпадать: def hello(name):.
  3. Подсказка 3. Если вернуть словарь, Flask сам превратит его в JSON: return {"message": f"Привет, {name}!"}.
Показать решение
from flask import Flask

app = Flask(__name__)

@app.get("/hello/<name>")
def hello(name):
    return {"message": f"Привет, {name}!"}

34. Фильтр в адресе

Уровень: Средняя

Сделайте GET /tasks, который возвращает JSON-список задач из TASKS. Если в адресе есть ?done=1, верните только выполненные, если ?done=0 — только невыполненные. Без параметра верните все.

  1. Подсказка 1. Параметр из адреса читает request.args.get("done"). Если его нет, будет None.
  2. Подсказка 2. Параметр приходит строкой: сравнивайте с "1", а не с числом.
  3. Подсказка 3. Список словарей Flask превращает в JSON сам, если вернуть его из функции.
Показать решение
from flask import Flask, request

app = Flask(__name__)
TASKS = [
    {"title": "Купить хлеб", "done": True},
    {"title": "Выучить Flask", "done": False},
]

@app.get("/tasks")
def tasks():
    done = request.args.get("done")
    if done is None:
        return TASKS
    return [task for task in TASKS if task["done"] == (done == "1")]

35. Создание записи

Уровень: Сложная

Сделайте POST /items. Он читает JSON с полем title. Если поля нет или оно пустое, верните {"error": "title"} с кодом 400. Иначе добавьте заголовок в список items и верните {"title": ...} с кодом 201.

  1. Подсказка 1. Маршрут для отправки данных объявляют через @app.post("/items").
  2. Подсказка 2. request.get_json(silent=True) or {} не падает, если прислали не JSON, а даёт пустой словарь.
  3. Подсказка 3. Код ответа ставится вторым значением: return {"error": "title"}, 400.
Показать решение
from flask import Flask, request

app = Flask(__name__)
items = []

@app.post("/items")
def create_item():
    data = request.get_json(silent=True) or {}
    title = str(data.get("title", "")).strip()
    if not title:
        return {"error": "title"}, 400
    items.append(title)
    return {"title": title}, 201

36. Одна запись или 404

Уровень: Сложная

Сделайте GET /tasks/<int:task_id>. Если задача с таким номером есть в словаре TASKS, верните её JSON. Если нет, верните {"error": "not found"} с кодом 404.

  1. Подсказка 1. <int:task_id> в адресе превращает часть пути в число и передаёт его в функцию.
  2. Подсказка 2. TASKS.get(task_id) вернёт None, если такой задачи нет.
  3. Подсказка 3. Для отсутствующей задачи: return {"error": "not found"}, 404.
Показать решение
from flask import Flask

app = Flask(__name__)
TASKS = {
    1: {"id": 1, "title": "Купить хлеб"},
    2: {"id": 2, "title": "Выучить Flask"},
}

@app.get("/tasks/<int:task_id>")
def task_detail(task_id):
    task = TASKS.get(task_id)
    if task is None:
        return {"error": "not found"}, 404
    return task

  1. Подсказка 1. Маршрут только для GET объявляют так: @app.get("/health").

from flask import Flask

@app.get("/health")
def health():

38. Число в адресе

Уровень: Лёгкая

Сделайте GET /square/<int:n>: верните JSON с числом и его квадратом, например {"n": 4, "square": 16}. Адрес /square/abc должен давать 404.

  1. Подсказка 1. <int:n> в адресе пропускает только числа и передаёт в функцию уже число, а не строку.
  2. Подсказка 2. Функция должна принимать аргумент с тем же именем: def square(n):.
Показать решение
from flask import Flask

app = Flask(__name__)

@app.get("/square/<int:n>")
def square(n):

39. Обязательный параметр

Уровень: Средняя

Сделайте GET /search. Если в адресе есть непустой параметр q, верните {"q": значение}. Если параметра нет или он из одних пробелов, верните {"error": "q"} с кодом 400.

  1. Подсказка 1. Параметр читает request.args.get("q", ""): второе значение вернётся, если параметра нет.
  2. Подсказка 2. Код ответа ставится вторым значением: return {"error": "q"}, 400.
Показать решение
from flask import Flask, request

app = Flask(__name__)

@app.get("/search")
def search():
    q = request.args.get("q", "").strip()
    if not q:
        return {"error": "q"}, 400
    return {"q": q}

40. Удаление по номеру

Уровень: Сложная

Сделайте DELETE /tasks/<int:task_id>. Если задача есть в словаре TASKS, удалите её и верните пустой ответ с кодом 204. Если её нет, верните {"error": "not found"} с кодом 404.

  1. Подсказка 1. Маршрут для удаления объявляют через @app.delete(...). Из словаря элемент убирает del TASKS[task_id].
  2. Подсказка 2. Пустой ответ с кодом: return "", 204.
Показать решение
from flask import Flask

app = Flask(__name__)
TASKS = {1: "Buy bread", 2: "Learn Flask"}

@app.delete("/tasks/<int:task_id>")
def delete_task(task_id):
    if task_id not in TASKS:
        return {"error": "not found"}, 404
    del TASKS[task_id]
    return "", 204
