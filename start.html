Python с нуля

13 уроков для тех, кто никогда не программировал. Код запускается прямо на этой странице: нажимайте «Запустить», меняйте его и запускайте снова. Ошибиться не страшно, ничего не сломается.

При первом запуске браузер загружает Python, это займёт несколько секунд. Незнакомые слова есть в словаре.

0 из 13 уроков пройдено

  1. Урок 0. Как устроен этот курс

    Зачем. Прежде чем писать код, полезно понять три вещи: что такое программа, почему мы учим Python и как заниматься на этой странице.

    Что такое программа. Программа — это инструкция для компьютера. Она похожа на рецепт: повар выполняет шаги по порядку, сначала режет, потом варит. Компьютер тоже выполняет команды по очереди, сверху вниз.

    Почему Python. Код на Python читается почти как обычный текст на английском, в нём мало лишних знаков. На Python делают сайты, обрабатывают данные и автоматизируют скучную работу. Поэтому его часто выбирают первым языком.

    Как заниматься. В каждом уроке есть объяснение, примеры и задания. Нажмите «Запустить» под примером, и Python выполнит код прямо здесь, в браузере. Код можно менять как угодно: компьютер не сломается.

    Задания с проверкой. Напишите решение и нажмите «Проверить». Если не получается, откройте подсказки по одной. Готовое решение тоже есть, но сначала попробуйте сами.

    Прогресс. Отметка «Урок пройден» сохраняется в этом браузере. Незнакомые слова ищите в словаре.

    Попробуйте: запустите оба примера справа. Это уже настоящие программы.

    Частый вопрос: нужно ли что-то устанавливать?

    Нет. Python загрузится в браузер сам при первом запуске, это займёт несколько секунд. Устанавливать Python на компьютер понадобится позже, для своего проекта, и об этом будет отдельный урок.

    Частый вопрос: нужно ли хорошо знать математику и английский?

    Нет. Хватит школьной арифметики. Английских слов в Python немного, их значение мы объясним в уроках.

    Коротко:

    • программа — это команды, которые компьютер выполняет по очереди, сверху вниз;
    • код здесь запускается прямо в браузере, устанавливать ничего не нужно;
    • ошибаться не страшно: пробуйте, меняйте и запускайте снова.
    Пример 1. Рецепт по шагам
    print("Шаг 1: беру чашку")
print("Шаг 2: наливаю чай")
print("Шаг 3: пью чай")
    Пример 2. Python умеет считать
    print(2 + 2)
print("2 + 2")

    Во втором примере первая строка считает, а вторая печатает текст как есть: всё, что в кавычках, Python не вычисляет.

  2. Урок 1. Первая программа

    Зачем. Любая программа, даже большой сайт, складывается из простых команд. Начнём с самой главной — с команды, которая показывает результат.

    Команда print выводит на экран то, что стоит в скобках. Текст пишут в кавычках: print("Привет!"). Числа можно писать без кавычек: print(2026).

    Порядок. Каждую команду пишут с новой строки. Python выполняет их сверху вниз: что выше, то и напечатается раньше.

    Несколько значений. В одном print можно перечислить несколько значений через запятую. Python сам поставит между ними пробелы: print("Мне", 16, "лет") печатает Мне 16 лет.

    Пустая строка. print() без ничего в скобках печатает пустую строку. Так удобно отделять одну часть вывода от другой.

    Комментарии. Всё, что стоит после знака #, — заметка для человека. Python её пропускает. Комментарии помогают объяснить, что делает код.

    Попробуйте: напишите в кавычках своё имя и нажмите «Запустить». Потом поменяйте две строки местами и посмотрите, как изменится вывод.

    Частая ошибка: забыли кавычку или скобку

    Кавычки и скобки всегда идут парой. Если написать print("Привет), Python не найдёт конец текста: SyntaxError: unterminated string literal Проверьте, что у каждой открывающей кавычки и скобки есть закрывающая.

    Частая ошибка: Print с большой буквы

    Python различает большие и маленькие буквы. Print и print для него разные слова, и первого он не знает: NameError: name 'Print' is not defined Команды Python пишутся маленькими буквами.

    Коротко:

    • print(...) показывает результат: текст в кавычках, числа без кавычек;
    • команды выполняются сверху вниз, каждая с новой строки;
    • # начинает комментарий, а кавычки и скобки всегда идут парой.
    Пример 1. Первые команды
    # Это комментарий: Python его пропустит
print("Привет!")
print("Это моя первая программа")
    Пример 2. Несколько значений
    print("Меня зовут", "Аружан")
print("Мне", 16, "лет")
print()
print("Учусь программировать с", 2026, "года")

  3. Урок 2. Числа: Python как калькулятор

    Зачем. Сайты постоянно считают: цену в корзине, баллы за тест, сколько дней осталось до экзамена. Поэтому сначала научимся считать.

    Действия. Python складывает +, вычитает -, умножает * и делит /. Результат можно сразу напечатать: print(2 + 3).

    Целые и дробные числа. Бывают целые числа, например 7, и дробные, например 7.5. Дробную часть отделяют точкой, а не запятой. Обычное деление / всегда даёт дробное число: 10 / 2 равно 5.0.

    Деление нацело и остаток. Представьте 17 конфет, которые раскладывают по 5 штук в коробку. 17 // 5 отвечает, сколько получится полных коробок: 3. 17 % 5 отвечает, сколько конфет останется: 2.

    Степень и порядок действий. 2 ** 3 — это 2 в кубе, то есть 8. Порядок действий как в математике: сначала умножение и деление, потом сложение и вычитание. Скобки меняют порядок: (2 + 3) * 4 равно 20.

    Округление. round(3.14159, 2) оставляет два знака после точки: 3.14.

    Число и текст — разные вещи. 2 + 2 даёт 4, а "2" + "2" даёт "22": это склеенный текст, а не сумма.

    Попробуйте: посчитайте, сколько минут в неделе. Затем проверьте, как работает остаток: что даст 10 % 3?

    Частая ошибка: запятая вместо точки

    В дробном числе нужна точка. Если написать print(2,5), ошибки не будет, но Python поймёт это как два числа и напечатает 2 5. Правильно: print(2.5).

    Частая ошибка: деление на ноль

    На ноль делить нельзя и в Python. Команда print(5 / 0) остановит программу: ZeroDivisionError: division by zero Проверьте, что делитель не равен нулю.

    Коротко:

    • + - * / — обычные действия, дробную часть отделяют точкой;
    • // — сколько целых раз, % — остаток, ** — степень;
    • числа пишут без кавычек: "2" в кавычках — это уже текст.
    Пример 1. Калькулятор
    print(7 + 5)
print(7 - 5)
print(7 * 5)
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 10)
    Пример 2. Покупка в магазине
    print("Три тетради по 450 тенге:", 3 * 450)
print("С ручкой за 200:", 3 * 450 + 200)
print("Сдача с 2000:", 2000 - (3 * 450 + 200))
print("Средняя оценка:", round((5 + 4 + 5) / 3, 1))

  4. Урок 3. Переменные: как запомнить значение

    Зачем. Программа должна помнить данные: имя ученика, баллы за тест, сумму в корзине. Для этого есть переменные.

    Что такое переменная. Переменная — это коробка с подписью. В коробку кладут значение, а потом обращаются к нему по подписи. name = "Аня" значит: положи текст "Аня" в коробку с подписью name.

    Знак = в Python означает «положить», а не «равно». Слева пишут имя коробки, справа — что в неё кладут.

    Значение можно менять. score = score + 10 значит: возьми, что лежит в score, прибавь 10 и положи обратно. Короче то же самое пишут так: score += 10.

    Как называть переменные. Используйте латинские буквы, цифры и знак _. Имя не может начинаться с цифры. Выбирайте понятные имена: user_age лучше, чем a.

    Типы значений. У каждого значения есть тип: str — текст, int — целое число, float — дробное. Узнать тип помогает type(...). Превратить одно в другое помогают int("16"), str(16) и float("2.5").

    Ввод с клавиатуры. На компьютере input("Как вас зовут? ") спрашивает человека и ждёт ответа. Ответ всегда приходит текстом, поэтому число получают так: int(input()). В браузере на этом сайте input() не работает, поэтому значения мы записываем прямо в код. А на сайтах данные приходят из форм, о них будет отдельный урок.

    Попробуйте: поставьте своё имя и возраст и запустите снова. Добавьте к баллам ещё 5.

    Частая ошибка: опечатка в имени

    Если создать name, а потом написать nmae, Python не поймёт, о чём речь: NameError: name 'nmae' is not defined Проверьте, что имя написано везде одинаково, вплоть до буквы.

    Частая ошибка: число в виде текста

    "16" + 1 не сработает: слева текст, справа число. TypeError: can only concatenate str (not "int") to str Сначала превратите текст в число: int("16") + 1 даёт 17.

    Коротко:

    • переменная — коробка с подписью: name = "Аня", знак = значит «положить»;
    • значение можно менять: score += 10;
    • тип узнают через type(), меняют через int(), str(), float().
    Пример 1. Коробки с данными
    name = "Аня"
age = 18
score = 0

print("Меня зовут", name)
print("Через год мне будет", age + 1)

score = score + 10
score += 5
print("Баллы:", score)
    Пример 2. Текст или число
    age_text = "16"
age = int(age_text)

print(type(age_text))
print(type(age))
print("Через год:", age + 1)
print("Склейка текста:", age_text + "1")

  5. Урок 4. Строки: работа с текстом

    Зачем. На сайте почти всё — текст: имя ученика, заголовок, сообщение в форме. Чтобы работать с текстом, нужно уметь его хранить, склеивать и исправлять.

    Что такое строка. В Python текст называется строкой. Это буквы, которые стоят в ряд, как бусины на нитке. Строку пишут в кавычках: "Привет".

    Кавычки — это границы текста. Без них Python подумает, что Привет — имя переменной, и сообщит об ошибке.

    Склеить строки можно знаком +: "Привет, " + "Аружан" даёт Привет, Аружан. Пробел ставьте сами: Python его не добавит.

    f-строка — самый удобный способ вставить значение в текст. Представьте открытку с пропуском для имени. Буква f перед кавычками говорит Python: «здесь есть пропуски». Сами пропуски — фигурные скобки: f"Привет, {name}!". Python подставит туда значение переменной.

    Методы — это команды, которые есть у каждой строки. Их пишут через точку:

    • .strip() убирает лишние пробелы в начале и в конце;
    • .title() делает первую букву большой: аружан → Аружан;
    • .upper() делает все буквы большими, .lower() — маленькими.

    Длина и буквы по номерам. len(name) считает, сколько в строке символов. А взять одну букву можно по её номеру в квадратных скобках. Номера начинаются с нуля: name[0] — первая буква, name[1] — вторая.

    Попробуйте: в первом примере поставьте своё имя с лишними пробелами — результат не изменится. Замените .title() на .upper(). Во втором примере поменяйте город и возраст.

    Частая ошибка: склеить текст с числом

    Строку и число нельзя сложить знаком +. Команда print("Мне " + 18) остановит программу с ошибкой: TypeError: can only concatenate str (not "int") to str Python не понимает, что вы хотели: сложить числа или склеить текст. Используйте f-строку: print(f"Мне {18}"). Она сама превратит число в текст.

    Частая ошибка: строка не меняется сама

    Метод не исправляет строку, а возвращает новую. Поэтому после name.strip() в name останутся старые пробелы. Результат нужно сохранить: name = name.strip().

    Коротко:

    • текст в кавычках — это строка, склеивают строки знаком +;
    • f-строка подставляет значения в текст: f"Привет, {name}!";
    • методы .strip(), .title(), .upper() возвращают новую строку, len() считает символы, name[0] даёт первую букву.
    Пример 1. Приводим имя в порядок
    name = "   аружан   "

clean = name.strip()
print(clean.title())
print("Символов в имени:", len(clean))
print("Первая буква:", clean[0].upper())
print("Привет, " + clean.title() + "!")
    Пример 2. Открытка с пропусками
    name = "Ерлан"
city = "Астана"
age = 16

print(f"Привет, {name}!")
print(f"Ты из города {city}, и тебе {age} лет.")
print(f"Через год тебе будет {age + 1}.")

    Задание: бейдж участника

    Уровень: Лёгкая

    Имя и город уже записаны в переменные, но с лишними пробелами. Напечатайте бейдж: имя большими буквами, затем из и город. Должно получиться АРУЖАН из Алматы.

    Задание посложнее: короткое имя

    Уровень: Средняя

    В журналах имя часто пишут коротко: фамилия, а потом первая буква имени с точкой. Имя и фамилия уже записаны, но маленькими буквами и с пробелами. Напечатайте Сейтказы А.

    1. Подсказка 1. Сначала уберите пробелы и сохраните результат: first = first.strip(), и так же для last.
    2. Подсказка 2. Фамилия с большой буквы — last.title(). Первая буква имени — first[0], большой её сделает .upper().
    3. Подсказка 3. Соберите ответ f-строкой: print(f"{...} {...}."). Не забудьте точку в конце.
    Показать решение

last = "сейтказы  "
first = first.strip()

  6. Урок 5. Условия: если так, то вот так

    Зачем. Сайт всё время выбирает: пустить ли пользователя, засчитать ли ответ, хватает ли денег на покупку. Для выбора есть условия.

    Слово if значит «если». После него пишут условие и двоеточие. Строки под ним с отступом в четыре пробела выполнятся, только если условие верно.

    Слово else значит «иначе». Его строки выполнятся, если условие неверно. А elif — это «а если нет, то проверь вот это». Таких проверок можно написать сколько угодно, Python пойдёт по ним сверху вниз и остановится на первой верной.

    Отступ показывает, какие строки относятся к условию. Это не украшение: без отступа Python не поймёт, что выполнять.

    Сравнения. > больше, < меньше, >= и <= — больше или равно и меньше или равно. Равенство проверяют двумя знаками: ==. Не равно — !=. Сравнивать можно и текст: password == "qwerty".

    Правда и ложь. Ответ на сравнение — True (верно) или False (неверно). Проверьте сами: print(5 > 3) напечатает True.

    Несколько условий. and — «и»: верно, когда верны оба. or — «или»: хватает одного. not переворачивает ответ.

    Попробуйте: в первом примере поставьте температуру 10, потом 30. Во втором поменяйте возраст и разрешение родителей.

    Частая ошибка: один знак = вместо двух

    Один знак = кладёт значение в переменную, а сравнивают двумя: ==. Если написать if x = 5:, Python сразу подскажет: SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?

    Частая ошибка: забыли отступ или двоеточие

    После условия нужно двоеточие, а строки внутри — с отступом в четыре пробела. Иначе Python остановится: IndentationError: expected an indented block after 'if' statement on line 2 Поставьте двоеточие и сдвиньте строку вправо клавишей Tab или четырьмя пробелами.

    Коротко:

    • if — если, elif — а если, else — иначе; после условия двоеточие и отступ;
    • равенство проверяют через ==, а один = кладёт значение в переменную;
    • and — оба условия, or — хотя бы одно, not — наоборот.

  8. Урок 7. Циклы: одно действие много раз

    Зачем. Сайт показывает ленту из сотни записей, но код для одной записи пишут один раз. Повторять его для каждой будет цикл.

    Цикл for значит «для каждого». for fruit in fruits: читается так: «для каждого фрукта в списке фруктов сделай…». Python берёт элементы по одному, кладёт очередной в переменную fruit и выполняет строки с отступом.

    Повторить несколько раз помогает range. range(5) даёт числа 0, 1, 2, 3, 4 — пять штук, начиная с нуля. range(1, 6) даёт числа от 1 до 5: последнее число в диапазон не входит.

    Накопление. Частый приём: завести переменную до цикла и менять её внутри. Например, total = 0, а в цикле total += price. После цикла в total будет сумма.

    Цикл while значит «пока». Он повторяет строки, пока условие верно. Он нужен, когда заранее неизвестно, сколько будет повторов: например, копить, пока не наберётся нужная сумма.

    Выйти раньше можно командой break: цикл сразу закончится.

    Попробуйте: в первом примере добавьте свой фрукт и поменяйте range(1, 4) на range(1, 11). Во втором поменяйте сумму, которую откладываете в неделю.

    Частая ошибка: бесконечный цикл

    Если внутри while ничего не меняется, условие всегда верно, и цикл не закончится никогда. Программа «зависнет». Проверьте, что в цикле меняется переменная из условия: например, есть money += 150.

    Частая ошибка: на одно число меньше

    range(1, 10) даёт числа от 1 до 9, а не до 10. Ошибки Python не покажет, просто в ответе не будет последнего числа. Чтобы дойти до 10, пишите range(1, 11).

    Коротко:

    • for x in список: повторяет строки с отступом для каждого элемента;
    • range(1, 6) — числа от 1 до 5, последнее не входит;
    • while условие: повторяет, пока условие верно, и внутри обязательно что-то должно меняться.
    Пример 1. Для каждого

total = 0

    total += price

  9. Урок 8. Функции: своя команда

    Зачем. Одно и то же действие часто нужно в разных местах: посчитать цену со скидкой, поприветствовать пользователя. Чтобы не копировать код, ему дают имя и вызывают по этому имени.

    Что такое функция. Функция — это ваша собственная команда. Вы уже пользовались готовыми: print, len, round. Теперь научимся делать свои.

    Как описать. Слово def начинает описание. Дальше имя функции, скобки и двоеточие: def greet(name):. Строки функции пишут с отступом, как в условиях и циклах.

    Параметры — это пустые места в скобках. Когда функцию вызывают, их заполняют значениями: greet("Аня") кладёт "Аня" в name.

    Описать ещё не значит выполнить. Код внутри def работает только тогда, когда функцию вызывают: имя и скобки, greet("Аня").

    return отдаёт результат. Функция как кофемашина: вы даёте ей зёрна, она возвращает кофе. return — это «вот готовый результат, забирай». Его можно сохранить в переменную или использовать дальше: total = price_with_discount(1000, 10).

    print и return — разные вещи. print только показывает значение на экране. return возвращает его в программу, чтобы с ним можно было работать дальше.

    Значение по умолчанию. def greet(name="гость"): — если имя не передали, будет «гость».

    Попробуйте: вызовите greet со своим именем. Во втором примере поменяйте скидку и посмотрите, как изменится итог.

    Частая ошибка: print вместо return

    Если функция печатает результат, а не возвращает его, работать с ним дальше нельзя: функция вернёт пустое значение None. Попытка прибавить к нему число закончится так: TypeError: unsupported operand type(s) for +: 'NoneType' and 'int' Внутри функции пишите return, а печатайте уже результат: print(f(3)).

    Частая ошибка: забыли скобки при вызове

    print(greet) без скобок не вызывает функцию, а печатает что-то вроде <function greet at 0x…>. Чтобы функция сработала, нужны скобки: greet() или greet("Аня").

    Коротко:

    • def имя(параметры): описывает функцию, а выполняется она при вызове имя(...);
    • return возвращает результат, print только показывает;
    • у параметра может быть значение по умолчанию: name="гость".
    Пример 1. Приветствие

    return f"Привет, {name}!"

print(greet("Марат"))
print(greet())

  10. Урок 9. Словари: найти значение по названию

    Зачем. У пользователя сайта есть имя, возраст, город. Хранить их удобно не по номерам, как в списке, а по названиям: «имя — Аружан», «город — Алматы». Для этого есть словари.

  11. Урок 10. Ошибки: как их читать и ловить

    Зачем. Ошибки бывают у всех, даже у опытных программистов. Пользователь вводит буквы вместо числа, нужной записи нет, пропал интернет. Хорошая программа в таких случаях не «падает», а спокойно объясняет, что не так.

    Как читать сообщение об ошибке. Python пишет несколько строк, и самая важная из них — последняя. В ней тип ошибки и короткое объяснение, например ValueError: invalid literal for int(). Строка с line 3 показывает, где искать. На этом сайте под ошибкой ещё появляется подсказка «Что это значит».

    Ошибки, которые вы уже встречали:

    • SyntaxError — код написан неправильно: нет кавычки, скобки, двоеточия;
    • NameError — такого имени нет, часто это опечатка;
    • TypeError — действие не подходит к типу, например текст плюс число;
    • IndexError и KeyError — нет элемента с таким номером или ключом;
    • ValueError — значение не подходит: int("abc").

    Поймать ошибку помогает try и except. Это значит: «попробуй сделать это, а если случится такая ошибка, сделай вот это». Программа при этом не остановится.

    Ловите конкретную ошибку: except ValueError:, а не все подряд. Иначе except спрячет и настоящую опечатку, и вы долго не поймёте, почему программа работает не так.

    Попробуйте: в первом примере добавьте в список свой ответ, например "двадцать". Во втором поделите на ноль и посмотрите, что ответит функция.

    Частая ошибка: ловить вообще всё

    Пустой except: без названия ошибки поймает что угодно, даже опечатку в имени переменной. Программа «молча» сделает не то, и найти причину будет трудно. Всегда пишите, какую ошибку ждёте: except ValueError:.

    Частая ошибка: читать сообщение сверху

    Новички часто пугаются длинного сообщения и читают его первую строку. Начинайте с последней: там написано, что случилось, например ValueError: invalid literal for int() with base 10: 'abc' Это значит «'abc' нельзя превратить в целое число».

    Коротко:

    • в сообщении об ошибке главное — последняя строка: тип ошибки и объяснение;
    • try: — попробовать, except Тип: — что делать, если случилась такая ошибка;
    • ловите конкретные ошибки, а не все сразу.
    Пример 1. Ответы из анкеты
    answers = ["16", "abc", "20", ""]

for text in answers:
    try:
        age = int(text)
        print("Возраст:", age)
    except ValueError:
        print(f"«{text}» — это не число, пропускаю")
    Пример 2. Безопасное деление
    def divide(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return "на ноль делить нельзя"

print(divide(10, 4))
print(divide(10, 0))

  12. Урок 11. Модули: готовые инструменты

    Зачем. Не нужно писать всё самому. Вместе с Python идёт целая библиотека готовых инструментов: случайные числа, математика, даты. Эти наборы называются модулями.

    Как подключить. Модуль подключают командой import в начале программы: import random. После этого его инструменты доступны через точку: random.randint(1, 6).

    Взять одну вещь можно так: from datetime import date. Тогда пишут просто date, без названия модуля.

    Три полезных модуля:

    • random — случайности: randint(1, 6) бросает кубик, choice(список) выбирает случайный элемент;
    • math — математика: sqrt(16) — квадратный корень, pi — число π;
    • datetime — даты: date.today() — сегодняшняя дата, а разность двух дат показывает, сколько между ними дней.

    Модули из интернета. Кроме встроенных, есть тысячи модулей от других людей, их называют пакетами. Их устанавливают командой pip install. Так ставят Flask и Django, об этом расскажем в первом проекте.

    Попробуйте: запустите первый пример несколько раз: ответы будут разными. Во втором поменяйте дату события на свой день рождения.

    Частая ошибка: забыли import

    Если сразу написать random.randint(1, 6), не подключив модуль, Python его не знает и даже подскажет, в чём дело: NameError: name 'random' is not defined. Did you forget to import 'random'? Добавьте import random в начало программы.

    Частая ошибка: опечатка в названии модуля

    Название модуля должно быть точным. import randon закончится ошибкой: ModuleNotFoundError: No module named 'randon'

    Коротко:

    • модуль — набор готовых инструментов, его подключают через import;
    • import random и random.randint(), или from datetime import date и просто date;
    • встроенные модули идут с Python, остальные ставят через pip install.
    Пример 1. Кубик и жребий
    import random
import math

print("Выпало на кубике:", random.randint(1, 6))

students = ["Аружан", "Ерлан", "Дана", "Марат"]
print("Отвечать идёт:", random.choice(students))

print("Корень из 144:", math.sqrt(144))
print("Число пи:", round(math.pi, 4))
    Пример 2. Сколько дней осталось
    from datetime import date

today = date.today()
new_year = date(today.year + 1, 1, 1)

print("Сегодня:", today)
print("До Нового года дней:", (new_year - today).days)

  13. Урок 12. Как это связано с сайтами

    Зачем. Вы прошли основы Python. Теперь соединим их: посмотрим, как из этих кирпичиков получается сайт.

    Как работает сайт. Вы набираете адрес в браузере, и браузер отправляет запрос на сервер. Сервер — это компьютер, на котором работает программа, например на Python. Она смотрит на адрес, выбирает нужную функцию, и та возвращает ответ: текст страницы. Подробнее — на странице «Как работает сайт».

    Где здесь ваши уроки:

    • функции — каждая страница сайта: функция получает запрос и возвращает страницу;
    • словарь — «адрес → функция»: так сайт выбирает, что показать;
    • f-строки — подставляют данные в страницу: «Привет, {name}!»;
    • списки и циклы — лента записей, список задач, товары в каталоге;
    • условия — вошёл ли пользователь, правильный ли пароль;
    • ошибки — страница «404: не найдено» вместо падения сайта;
    • модули — Flask и Django, готовые инструменты для сайтов.

    Flask. Во втором примере тот же сайт на Flask. Строка @app.route("/") говорит: «этот адрес открывает эту функцию». По сути это тот же словарь адресов, только Flask заводит его за вас.

    Попробуйте: в первом примере поменяйте адрес на "/", потом на "/tasks", потом на несуществующий. Добавьте в список своё дело.

    Частая ошибка: нет такой страницы

    Если открыть адрес, которого нет в словаре, pages[address] упадёт с KeyError. Настоящий сайт так не делает: он показывает страницу «404: не найдено». В примере это делает pages.get(address, not_found).

    Коротко:

    • сайт — программа: получает адрес и возвращает страницу;
    • страницы — функции, адреса — ключи словаря, данные подставляются f-строками;
    • Flask и Django делают то же самое, только удобнее; дальше вы соберёте на них первый проект.
    Пример 1. Сайт из функций и словаря
    tasks = ["купить хлеб", "сделать уроки"]

def home():
    return "Главная страница"

def task_list():
    lines = ""
    for task in tasks:
        lines += f"- {task}\n"
    return f"Мои дела ({len(tasks)}):\n{lines}"

def not_found():
    return "404: страница не найдена"

pages = {"/": home, "/tasks": task_list}

address = "/tasks"
print("Вы открыли:", address)
print(pages.get(address, not_found)())
    То же самое на Flask
    from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Главная страница"

print("Сайт ответил:", app.test_client().get("/").text)

    Задание посложнее: ответ сервера

    Уровень: Средняя

    Напишите функцию handle(address), как у настоящего сервера. Если адрес есть в словаре pages, она вызывает нужную функцию и возвращает её ответ. Если адреса нет, возвращает 404: страница не найдена.

    1. Подсказка 1. Проверьте адрес словом in: if address in pages:.
    2. Подсказка 2. Достаньте функцию и сразу вызовите её: return pages[address]().
    3. Подсказка 3. Иначе: return "404: страница не найдена".
    Показать решение
    def home():
    return "Главная страница"

def contacts():
    return "Наши контакты"

pages = {"/": home, "/contacts": contacts}

def handle(address):
    if address in pages:
        return pages[address]()
    return "404: страница не найдена"
