Подготовка компьютера

Два урока перед первым проектом: как установить Python и редактор кода и как не бояться терминала. Команды даны для Windows и для macOS с Linux, выберите свою систему.

Если что-то не получается, загляните в частые ошибки первого проекта. Незнакомые слова есть в словаре.

0 из 2 уроков пройдено

  1. Урок 1. Установка Python и редактора кода

    Зачем. В уроках код работал прямо в браузере. Но свой сайт на Flask или Django запускают на своём компьютере. Для этого нужны две программы: сам Python и редактор, в котором удобно писать код.

    Python. Скачайте установщик с официального сайта python.org, версию 3.12 или новее. Скачивайте только оттуда: на других сайтах под видом Python могут подсунуть вирус.

    Самое важное на Windows. На первом экране установщика отметьте галочку «Add python.exe to PATH», а потом нажмите «Install Now». Без этой галочки команда python в терминале работать не будет.

    На macOS поставьте Python установщиком с того же сайта. В Linux он обычно уже есть: проверьте командой ниже.

    Проверьте установку. Откройте терминал (как это сделать — в следующем уроке) и выполните команду из вкладки вашей системы. Должна появиться версия, например Python 3.13.1.

    Редактор кода. Удобный бесплатный редактор — Visual Studio Code. После установки откройте в нём раздел расширений (значок из четырёх квадратиков слева) и поставьте расширение Python от Microsoft. Оно подсвечивает код и подсказывает ошибки.

    Первая программа на компьютере. Создайте пустую папку, например pyweb, и откройте её в VS Code: «File → Open Folder». Создайте файл hello.py, напишите print("Привет с моего компьютера!") и нажмите треугольник ▶ справа вверху. Результат появится внизу, в терминале.

    Частая ошибка: «Python was not found»

    На Windows команда python открывает Microsoft Store или пишет: Python was not found; run without arguments to install from the Microsoft Store… Значит, при установке не отмечена галочка PATH. Запустите установщик ещё раз, выберите «Modify» и отметьте «Add Python to environment variables». Или используйте команду py вместо python: она ставится вместе с Python.

    Частая ошибка: «command not found: python» на macOS

    На macOS и в Linux команда часто называется python3, а не python. Пишите python3 --version и python3 hello.py.

    Проверьте себя:

    • команда из вкладки ниже показывает версию 3.12 или новее;
    • в VS Code стоит расширение Python;
    • файл hello.py запускается и печатает приветствие.

    Windows (PowerShell или командная строка)

    Терминал: проверка версии 
    python --version
py --version

    macOS и Linux (Терминал)

    Терминал: проверка версии 
    python3 --version
    Файл hello.py 
    print("Привет с моего компьютера!")
print("Python работает.")

  2. Урок 2. Терминал без страха

    Зачем. Программисты часто управляют компьютером не мышкой, а командами: устанавливают библиотеки, запускают сервер, создают проекты. Всё это делают в терминале. В первом проекте он понадобится с первого шага.

    Что такое терминал. Это окно, где вы пишете команду словами и нажимаете Enter, а компьютер выполняет её и пишет ответ. Сломать им компьютер случайно очень трудно: команды из этого курса безопасны.

    Как открыть. Проще всего — прямо в VS Code: меню «Terminal → New Terminal» или клавиши Ctrl + `. Отдельно: на Windows нажмите «Пуск» и наберите «PowerShell», на macOS откройте программу «Терминал».

    Где вы находитесь. Терминал всегда работает в какой-то папке, её путь написан в начале строки. Команды выполняются именно там. Если программа «не находит файл», чаще всего вы просто не в той папке.

    Пять главных команд:

    • cd папка — перейти в папку, cd .. — подняться на уровень выше;
    • ls (а в старой командной строке Windows — dir) — показать файлы в папке;
    • mkdir имя — создать папку;
    • python hello.py — запустить программу (на macOS — python3);
    • Ctrl + C — остановить работающую программу, например сервер.

    Две подсказки, которые экономят время. Стрелка вверх возвращает предыдущую команду, не нужно набирать её заново. Клавиша Tab дописывает название файла или папки по первым буквам.

    Частая ошибка: файл не найден

    Команда python hello.py отвечает can't open file 'hello.py': [Errno 2] No such file or directory Значит, вы не в той папке. Посмотрите файлы командой ls и перейдите в нужную папку через cd. В VS Code терминал сразу открывается в папке проекта.

    Частая ошибка: пробелы в названии папки

    cd Мои проекты не сработает: терминал решит, что это две отдельные части. Возьмите путь в кавычки: cd "Мои проекты". А ещё лучше называйте папки проектов без пробелов и латиницей: my-site.

    Проверьте себя:

    • вы открыли терминал в VS Code и видите путь к папке;
    • создали папку командой mkdir и перешли в неё через cd;
    • запустили hello.py командой из терминала, а не кнопкой.

    Windows (PowerShell)

    Терминал: первые шаги 
    mkdir my-site
cd my-site
ls
python hello.py
cd ..

    macOS и Linux (Терминал)

    Терминал: первые шаги 
    mkdir my-site
cd my-site
ls
python3 hello.py
cd ..

    Файл hello.py из прошлого урока положите в папку my-site, иначе команда запуска его не найдёт. Как раз это и есть «частая ошибка» из этого урока.
